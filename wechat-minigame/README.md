# 江湖有回声 · 微信横屏小游戏

本目录为 2026-11-13 的移动端开发快照，启动标记 `mobile-experience-1113c`。可以直接在微信开发者工具以「小游戏」导入；仓库根目录配置也指向本目录。正式存档使用微信本地 `jianghu-wx:` 命名空间，与网页版独立。

## 构建

```sh
npm ci
npm run check
```

`check` 先离线构建，再运行移动端检查。`dist/game.js` 为 ES2017 产物，资源已在 `packages/resources/` 分包中，不需要 Python 服务、WebView 或外部模型服务。开发者工具不需要另外构建 npm。修改后重新编译并生成新预览二维码，避免手机继续运行旧预览包。

## 当前操作与表现

- 左侧轻触后显示浮动摇杆，拖远疾跑，松开淡出；右侧拖动转动视角。
- 底部中央为蹲行、点穴、探查、套索；右下为跳跃、拔刀及战斗动作。
- 靠近人物显示小型「对话」入口。纯对白轻点画面继续；实际回应选项仍需选择，拖动长文不翻句，关闭会取消当前对白。
- 任务目标显示在左上，点击可查看任务与线索；日志默认收起，在江湖菜单「记录」中查看。
- 气血、体力变化后短暂显示小条，满值隐藏。默认探索尽量清屏。
- 志莽行书题字、霞鹜文楷正文、思源宋体数值及原水墨图标保留。题字使用原字体轮廓，避免手机字体回退。
- 默认自动画质，场景与 HUD 分别控制像素密度；保留手动画质选择。近处/交谈人物及时更新，中远处骨骼降频，世界规则与结算继续正常运行。
- 背景音乐、环境、动作音效与已录制人物配音共用声音开关。切后台停声；微信仅提供音量 value 的接口有渐变兼容处理。未录制台词保留字幕，不换为统一朗读。

## 结构

- `engine/`：原游戏规则、场景和资源的移动端快照；目前不自动跟随本体更新。
- `runtime/`：微信平台桥接、隔离 DOM、Canvas HUD、触控与资源清单。
- `resources/`：已优化的音频、字体和图片。
- `packages/resources/`、`dist/`：可直接预览的构建产物。
- `tests/`：移动端检查；`engine/tests/` 保留原规则测试。
- `tools/build.mjs`：离线构建；字体、图像 QA 工具的额外依赖见各工具注释。

当前主包 2,305,788 字节，资源 18,630,085 字节，合计低于 20 MiB；精确报告见 `dist/build-report.json`。依赖、本机私有配置和测试输出不提交。

## 验证与边界

本快照 85 项移动端检查通过，涵盖启动、包内资源、存档命名空间、触控/对白、防误触、五档布局、帧间隔、像素隔离、音频循环及生命周期。布局尺寸为 1280×850、1024×768、800×600、844×390、667×375。没有将自动检查当成 iPhone Air 的实测帧率或声音听感；最新 BGM 兼容修复需手机重新预览试听。

主角 `sumiro-motion.local.json` 在原分支中已经受版本管理，本快照保留匹配优化模型的动作包，避免检出后重新构建丢失动作。其既有来源和许可待核实说明仍见 [迁移记录](docs/MIGRATION.md)；本次是开发分支保存，没有上传微信正式版本、审核或发布。

独立加载页及 NPC 首次姿态保护仍在另一验收副本，本快照未纳入。当前功能细节见 [移动界面](docs/MOBILE-INK-UI.md)、[性能](docs/MOBILE-PERFORMANCE.md)、[对白、HUD 与音频](docs/MOBILE-EXPERIENCE.md)。后续本体与移动端的维护方式见仓库根目录 `WECHAT.md`。

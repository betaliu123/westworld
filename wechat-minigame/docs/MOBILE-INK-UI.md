## 构建

npm ci 后 npm run build。修复 Windows 路径分隔符导致的引擎平台注入和资源 URL 问题。
修改字体源文件后运行 tools/convert-mobile-fonts.py（需 fonttools[woff]），再构建；原字体和许可证保留在 resources/fonts。
修改标题字体源后还需运行 python tools/build-title-outlines.py；日常构建只使用已生成的 runtime/title-outlines.js，不要求 Python。
构建复用更小的 gzip 产物前先核对解压后字节与源码完全一致；不改变模型、动作和贴图质量。
tools/optimize-resource-gzip.py 是可选离线无损压缩命令，需要 Python zopfli；已优化资源随项目保留。删除所有预压缩资源后重建若超出 20 MB，先运行该命令再重新 build。

# 西部世界 · Westworld Demo

一个用 **Three.js** 做的网页版「西部世界」互动 Demo。核心目标不是堆画面，而是**让这座小镇显得活着**——尤其是 NPC 要生动：他们有性格、有日程、有情绪，会对玩家做出可信的反应。

## 玩法

- 在程序化生成的西部小镇里自由行动，昼夜循环、动态天光、夜晚亮灯的窗户与路灯、星空与月亮。**地图约为早期版本的 3 倍大**，镇外围还有公园、湖泊、森林等人烟稀少的自然景观带。
- **重要场所全镇唯一**：酒馆/银行/警长办公室/杂货店/旅馆各仅一栋且外观差异化（教堂尖塔、银行石柱、警徽金星、定制招牌色），其余空位由无招牌填充楼补齐；可进入的重要场所**室内更大、NPC 更多**，他们闲聊日常、**传闻情报、甚至讨论报纸头条**。
- **NPC 会报警**：殴打/撞人被 NPC 记恨后，他们会**一路跑到警长办公室报案**（通缉上升）；跑不掉时会先夺门而出再报案。每个 NPC 只掉一次落物，无法刷钱。
- **分级提示**：强相关事件（被反击/中弹/警长出动/被捕）显示在顶部中央，弱相关（NPC 捡东西/受惊逃跑/进出房间）归入左侧小栏，同类提示 3 秒内自动合并计数，不再刷屏。
- **智能 NPC + 日程作息**：每个 NPC 有随机性格（胆量 / 攻击性 / 贪婪 / 社交 / 财富）、职业，以及**按时段、按职业的作息日程**——白班职业白天上班，歌女等夜班职业白天在家睡觉、夜里去酒馆；连闲聊内容都随时段变化。情绪状态机（平静 → 游荡 → 受惊 → 逃跑 / 愤怒反击 → 倒地）+ 群体恐慌连锁。
- **NPC 有自己的家**：主街两侧散布着带烟囱的民居，**一家人 / 情侣住在一起**（1~3 口一户）。夜里他们会真的走回家、上床睡觉（能看到 Zzz 气泡）；清晨再出门上班。
- **入室行窃**：每一栋民居都可以进去偷东西——后墙的藏物柜有发光金锁标记，搜刮得现金。**夜里看窗户灯光就能推测屋里有没有人**：黑着灯随便偷，亮着灯小心惊醒屋主（依性格被反击或吓逃），被发现会大涨通缉并登上报纸。
- **右上角小地图**：俯视显示街道、建筑（可进入的金色）、你已购的房产（蓝色）、自然景观，以及**追捕你的警长（红色闪烁点）**；室内时显示"在室内"。
- **NPC 对话交互（重做）**：靠近按 `F` 对话，弹出**耐心倒计时条**——磨蹭太久对方会不耐烦走人。选项含正向（问候 / 称赞 → 加荣誉、可能给情报或消息费）与负向（威胁；**🔫 勒索抢劫**：依对方胆量屈服交钱 / 拔枪反抗 / 惊逃报警）。
- **帮派势力**：镇上有三个帮派（红隼帮 / 黑蹄会 / 银矿兄弟会），过半 NPC 有帮派归属。你与某帮派成员友好或施暴，会**影响你在该帮派的声望**（且敌对帮派声望反向变动）。点右侧 🏴 查看帮派关系。
- **战斗与掉落**：可攻击 NPC，被击倒后掉落 💵现金 / 🔑跑车钥匙（召唤临时跑车）/ 📱手机（查看聊天记录，部分藏**大八卦**可投稿换钱）。
- **声望系统（荒野大镖客式）**：**荣誉值**（善行升、暴力降）+ **通缉度 0~5 星**。**通缉越高，来围剿你的警长越多**（3★→2 人、4★→3 人、5★→5 人）、开枪伤害越高；你可疾跑 / 开车 / 绕出视野甩脱，被贴身抓住则当场逮捕（罚款 + 清通缉）。
- **报纸 / 新闻系统**：你的行为（抢劫、撞人、善举、置业）会登上《小镇纪事报》，有新头条时弹提示；手机里的独家线报可**投稿换稿酬**。
- **死亡惩罚**：血量归零在**医馆苏醒**，扣医药费 + 短暂虚弱；通缉时被顺势收押。
- **载具与撞击**：可驾车，**高速把 NPC 撞飞**（掉落、扣血、恐慌、登报）。
- **可进入的建筑**：酒馆 / 银行 / 警长办公室 / 杂货店门口有发光地垫，按 `E` 进入，室内 NPC 会**走动、闲聊、有反应**（与室外统一），按 `E` 从门口离开。
- **买房进阶**：地图上 6 栋**大宅可就近购买**（门口金色地垫，按 E 买）——买下后可**进入自己的家**，小地图显示**蓝色小屋专属图标**；商店里两款房产（街边小屋/郊外庄园）同样是**实体房**，集市买地契即解锁。可购买多套。
- **音效与 BGM**：全程 WebAudio 合成——风声、热闹的市集人声底噪（交谈 / 笑声 / 吆喝 / 马嘶 / 木门）、脚步 / 拳击 / 金币 / 引擎 / 枪声 / 撞击、NPC 六种情绪人声，以及西部风循环 BGM。
- **长线循环**：现金 → 买车、买房（永久资产）。

## 操作

| 按键 / 操作 | 动作 |
|------|------|
| `WASD` | 移动 / 驾驶 |
| 鼠标 | 转视角（需先点击画面锁定鼠标） |
| `Shift` | 疾跑（可拉开与警长的距离） |
| `Space` | 跳跃 |
| 左键 / `J` | 攻击 |
| `E` | 交互（拾取 / 上下车 / 进出建筑 / 买房进屋 / **进民居行窃**） |
| `F` | 与附近 NPC 对话（含勒索抢劫） |
| 右上角图标 或 `M`/`Tab`/`N`/`G`/`P` | 集市 🛒 / 手机 📱 / 报纸 📰 / 帮派 🏴 / 静音 🔊 |
| `Q` / `E` | 手机界面内翻页 |

## 运行

本项目为**零构建**静态项目，使用 CDN 上的 Three.js（ES Module importmap）。由于浏览器对 ES Module 有同源要求，需通过静态服务器启动：

```bash
cd westworld-demo
python serve.py        # 默认 8080 端口
# 然后浏览器打开 http://localhost:8080
```

Windows 下也可直接双击 `启动游戏.bat`。

> ⚠️ 推荐用项目自带的 `serve.py` 而不是 `python -m http.server`：后者不禁缓存，
> 浏览器可能跑旧版本的 JS（改了代码不生效）。`serve.py` 对所有响应发 no-store。
> 若用其它服务器遇到"改动不生效"，请硬刷新（Ctrl+F5）。

需要联网以从 CDN 加载 Three.js。

## 结构

```
src/
├── main.js              # 启动装配 + 主循环
├── core/                # Engine / Input / Sky(昼夜+星空月亮) / MathUtils
├── world/               # Town(布局/日程地点/自然景观) / Homes(民居生成) / Buildings / Props
│                        # Interiors(可进入室内+活化NPC+民居房间)
├── entities/            # Player / NPC(含回家睡觉) / CharacterMesh(男女造型) / Sheriff / SheriffSquad
├── systems/             # NPCManager(家庭分配) / AIBrain(决策+日程+勒索+居家) / Combat / Loot
│                        # Economy(含房产) / Vehicle / PhoneData / Reputation(声望+帮派) / Audio
└── ui/                  # HUD / Dialogue(气泡) / Phone / Newspaper / Conversation(耐心条)
                         # Minimap(小地图) / Gangs(帮派界面)
```

设计与技术方案见 `artifacts/specs/tech/`。

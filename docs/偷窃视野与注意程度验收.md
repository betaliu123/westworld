# 偷窃视野与注意程度

2026-11-11，本轮改动以 v2 新章为主；保留 v1 回归入口。

## 已接通的规则

- 随身偷窃分开判断手法与目击。背后保留原手法检定；身侧余光降低把握。清醒且能反抗的物主正面盯着伸手时，确定拦截，不掷假骰。无法反抗但仍清醒的人可以看见搜取，不能把“看见”误作“有能力拦住”。
- 旁人按真实距离、身体朝向、头部转向和遮挡观察。手法成功仍可被看见；睡眠、倒地、点穴失去意识、隔墙及背对时不能凭空目击。低矮遮挡使用从眼睛到蹲姿伸手高度的视线，破坏或开门后同步失去遮挡效力。
- 蹲行停留在余光里，注意程度逐渐提高，NPC 会实际转向玩家；离开视线后回落。仅仅被看见蹲行不会扣关系、增加嫌疑或产生犯罪证据。
- 随身行囊的确认动作先伸手，约 0.95 秒时重查距离、物品和现场，随后结算。期间的真实目击保留到本次结算，不能趁对方再转走就洗掉。浏览与取消选物不掷骰；移动收手、死亡、打开阻断操作的面板、离开页面或动作被替换，不提前转物或奖励。跳过检定表现不加快伸手结算。
- 无人目击的随身偷窃失手只让物主察觉衣物被碰动并调查，不自动认定玩家。睡者可被碰醒，但不会直接知道背后是谁。目击后的具体问责、身份归因、物品来历继续走既有系统。
- 食摊、书案、钱币、纲货等沿用各自物品动作，其基础偷窃预览与目击读取同一现场朝向与注意数据。新章差役服预览也接入现场；无人看见的失败不再凭空让补衣人喝止、扣关系或增加嫌疑。它们尚未全部迁入本轮随身偷窃的持续伸手采样，不能宣称所有物品动作演出都已统一。

## 界面

- 蹲行与随身伸手时，在附近可见且清醒的相关 NPC 头上显示至多三个 22px 笔意眼形标记：收眼、半眼、睁眼分别表示未看向这里、余光留意、正看这里。状态同时用形状、深浅、中文无障碍说明和悬停说明区分。
- 标记跟随人物模型高度，不占固定 HUD 提示位置；让位于问责图标、检定浮字、属性浮字、对白和其他详细面板。起身、远离、遮挡、睡眠或离场后隐藏。
- 删除了成功后固定的“别惊动他”自语，避免已经被旁人看见却仍声称隐蔽，也避免默认性别。注意程度用图形呈现，没有增加头顶状态长句或常驻说明栏。
- 行囊继续显示身法与真实成功率，另给一行现场风险。确定被拦截直接写结果；搜取成功与被旁人目击分别表达。
- 确定拦截不再重复显示两句同义风险提示。伸手期间的检定表现保留移动、起身和打开详细面板的输入，动作完成后才恢复普通结果展示的输入限制。

## 验证结果与边界

- `tests/theft-sight.test.js` 新增 14 项行为测试：前后/身侧差异、身体与头部转向、遮挡及破坏、旁人目击、失败无错误处罚、睡者醒来、浏览取消、伸手途中转身与保留目击、中断无奖励、一次结算、注意增长消退、真实转向、无力反抗搜取、低矮掩体及差役服失败。
- 全量 `node --test tests/*.test.js`：633 项通过，0 失败；包含原有物品、教学、NPC 生活、读档和乔装归因回归。另补 `tests/check-reveal-input.test.js`，验证伸手尚未结算时允许移动与起身，普通检定和已结算结果仍保留原输入限制。主要改动文件通过 Node 语法检查。
- 试用地址：`http://127.0.0.1:8091/?playtest=theft-qa`，使用项目既有独立试玩存档键。新夹具增加“背后 / 正面 / 余光回头 / 旁人目击 / 伸手时转身 / 手法失败”按钮。
- 浏览器恢复后，实测背后下手只掷骰一次、转移一只钱袋；正面及伸手途中转身均不掷骰、不转物，并由物主当面问责。背后得手但旁人在看时，保留旁人目击；无人目击的手法失败，物品不转移且记录为无目击。夹具固定成功/失败骰用于验证路径，不用于测算概率分布。
- 余光状态会实际转身并变为睁眼，行囊预览随之改为“伸手必被拦住”。起身键曾被检定表现拦截，现已修复，并通过真实 Z 起身、W 移动复测：两者均中止伸手，钱袋余额保持 16、持有数量不增、实际掷骰为 0。
- 已检查 1280×850、1024×768、800×600 的行囊与长对白。眼形标记跟随人物头顶，与行囊不相交；小窗口行囊可滚到确认按钮，关闭按钮保持可见。对白与角色详细面板打开时标记隐藏；起身探索时标记数量为 0。行囊与对白的可见文字计算样式没有小于 14px 或禁用字体。截图见下表；临时视口已恢复。
- 试玩捕获的页面错误为 0。浏览器日志中存在扩展脚本自身的警告与错误，来源均为 `chrome-extension://`，未发现游戏页面错误。
- 没有修改声音或调用付费生成；没有覆盖玩家正式存档。

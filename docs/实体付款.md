# 实体付款第一批
锦衣客付茶钱、玩家在食摊购买吃食、NPC 在食摊购买吃食共用 placePayment。扣款后生成桌上铜钱，不立即增加收款人的钱袋。至少留六秒可操作时间，收款人到达桌旁、伸手一秒后收取，头顶显示实际增加的钱数。

钱币可直接点击，也使用通用最近交互点/Alt 高亮。Z 蹲行后偷取共用身法检定和现场目击，成功将数额加入玩家的钱；失败钱留在原地。掌柜到场发现钱不见只表达疑问，不能自动指认玩家。死亡、点穴、腹痛和危险会中断收钱。账面扣款、实体、收取状态持久保存，取钱和读档不重复奖励。旧存档已经 paid 的茶钱不重复生成。

本轮未迁移势力差钱、任务工钱、演奏打赏和普通礼金；这些后续复用同一流程，不声称所有世界交易均已实体化。

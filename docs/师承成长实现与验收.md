# 师承、技艺与地方声望

更新：2026-11-11。分支：511wuxia。

## 玩家实际经历

入城前可从杜老捕看手法，按他的交代到驿舍取真实伤药，回来交药后直接接授艺，不必重新开交谈。杜示范，玩家依次认肩井、落指、收力；成功学成正面点穴，右下角出现能力说明并强调点穴按钮，可立即进入瞄准状态。

瘸张一条线把落脚和探查串起来：在乞丐窝歇下，用一份真实干粮换消息，探查茶棚边的役夫与铁担，再请教眼力。换得的姓名、轮值、差役服或水门消息写入任务与事实；姓名可真实参与冒用路引判定，探查不能无凭据读出皇族身份。

入城后，苏晚的授艺取决于桥边的事情是否妥善处理。学习要听节拍、按空格跟完三拍；学成给一支实际竹笛，后续高档教学不重复送。卖艺仍需要持笛，熟练能吸引更多听众，精通可在客栈附近献艺获得实体赏钱。

押运工钱的事处理后，可以向林青舟或段赤川请教武艺。先按 R 格挡两次，再左键还招；两人师承分别偏守与攻。档内练满后继续请教；熟练开启适时格挡与反击，精通反击能短暂缴械。人物强弱仍共用武器、护具与武艺公式。

阿青需要玩家先帮忙研药，再教医毒。购买药材要付真实钱币，药案上依次辨叶、研药、收包；完成后获得背包中的泻药、解毒药或迟发散。解毒要递给附近实际中毒者，消耗物品并恢复状态、增加信任；迟发药随食物和茶水分装保存，真正吃喝后才开始计时。

## 授艺覆盖

| 技艺 | 师父 | 已接入的能力 |
| --- | --- | --- |
| 点穴 | 杜老捕 | 背后短定身 → 正面十息 → 哑穴与长定身 → 隔数步出手 |
| 妙手 | 燕七、梅掌舵 | 外露物 → 系紧钱袋 → 袖中物 → 暗送物件 |
| 眼力 | 瘸张、杜老捕 | 外观 → 行囊与腰牌 → 有事实支持的破绽 → 看破借衣乔装 |
| 乐器 | 苏晚 | 赠笛、跟拍、卖艺 → 留客分心 → 客栈献艺 |
| 妆扮 | 刻字人、宋青禾 | 模仿举止 → 年貌修饰 → 延缓身份露馅 |
| 医毒 | 阿青 | 辨毒与配泻药 → 解毒与隐蔽投药 → 延时发作 |
| 武艺 | 周伍长、林青舟、段赤川、顾钦差、梅掌舵 | 格挡 → 反击与刀势分歧 → 缴械 |

每一档先观摩，再满足师父自己的相关经历。高档要求上一档心得 30，信任达到熟练 6、精通 12。心得只能填满本档，不能靠刷行为自动升档。师门温习每天同档最多三次有效心得，每次 5；重复温习不加城市声望或四项基础属性。

观摩和跟练采用专门的双人镜头，检查树冠、摊棚和实体障碍；无清晰机位时临时避让前景，结束后恢复。移动、Esc、距离过远、死亡或冲突都会终止，未做完三步不发奖。

## 地方与势力

临溪关和关内街道共用“临溪镇”名声。汴京独立记账，目前未到达时显示“未至”，不是已开放的新城市。

小地图标出官府大堂、赤砂堂、青竹会驻地；识破刻字人的身份后才显示无相门联络处。点击小地图下方声望即可打开舆图，查看各地数值与各势力的态度，点击驻地可前往。师门认可只加该势力，押犯交案、押运和献艺等行为各有去重的地方后果。

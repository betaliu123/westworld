# 行动牌：送食、救治、寻仇

2026-11-11。本轮接入新章 `chapterVersion: 2`。行动牌使用现有救急牌、人情余波的牌记录、因果簿和存档，不要求玩家先问话或接任务，不推进正常线索牌序。

## 三个模板

| 模板 | 本地前提 | 场景节拍 | 实际结果 |
| --- | --- | --- | --- |
| 送食（救急） | 饱食 ≤20；附近 NPC 亲眼看见，持有可交付的实体食物，对当前认定的身份没有敌意。宋茶娘、杜老捕、阿青、柳掌柜可出于怜悯，其他人需好感 ≥8 | 走到玩家身侧 → 头顶小标记等待交互 → 询问来意、说明困境 → 接受后伸手递物 → 告别 → 返回原处、恢复日程 | 同一份食物转入行囊；收到不等于吃下。原主、转移记录、毒性与因果编号保留 |
| 救治（救急） | 气血 <40；阿青亲眼看见，自己能行动且有真实伤药；现场没有冲突，不优先于她看见的更重伤者 | 小跑靠近 → 头顶小标记等待交互 → 询问来意、说明伤情 → 接受后下蹲伸手包扎约4秒 → 告知欠药 → 离开 | 耗用一份伤药，气血实际 +30，上限100。未还欠药已达2份时，改为简单包扎 +8。每次留下一份欠药 |
| 寻仇（余波） | 青竹会或赤砂帮成员对认定身份好感 ≤−15；有亲历或目击的犯罪事实编号；同势力附近有能行动、愿同行的真实同伴。与玩家好感 ≥15 的同伴不参加 | 走去当面召集1至2人 → 一同寻找最后看到的玩家位置 → 小标记等待交互 → 点出旧怨 → 玩家回应“那就领教”后动手 → 败退或收手离开 | 共用 NPC 武器、技艺、护甲与玩家格挡伤害公式。只向实际到达攻击距离且视线通畅的目标出手，不由模板直接扣固定血量 |

寻仇每天对同一候选只作一次35%的排期抽取，失败结果也存档；浏览、取消、重新加载不重抽。该概率用于事件排期，不是玩家能力检定。救急优先于寻仇，三个模板合计每天最多主动来访一次；一次发起即占当天额度。一次旧怨按前因、发起人和认定身份去重。

## 中断、记忆与后续

- 新增[援助底线](NPC援助底线与亲近关系.md)：NPC 已知当前认定身份伤害自己或亲近的人，立即停止主动援助；只发现亲人受困则优先走近查看，不全知指认。发牌、等待、接受和交付共用检查，不等隔天，松绑与读档不清除已知事实。

- NPC 到达后原地等候，不自动弹对白、不自动交付、回血或开打。头顶显示无底板的笔墨对话小标记，使用 `ui-icons.js` 的现有图形与规范色彩；仅附近可触及、视线通畅时显示，危险或对白期间隐藏。
- 交互提示优先选择身边正在等候的来访者。按 E 或点击交互入口仍先展开紧凑菜单，浏览不切镜头；选择“询问来意”或交谈才开始正式对白，原有通用交谈与出示入口保留。
- 来意听完在同一轮提供接受、婉拒、暂不回应；寻仇提供“那就领教”和暂不回应。Esc、关闭或暂不回应保留等待，既不结算也不消耗物品；明确婉拒援助后 NPC 收回东西离开，日志准确记录婉拒。每轮最多三个选项，显示与执行共用距离、遮挡、身份、需求和实际库存检查。
- 等候不按短计时自动结束，附近走动后仍可回来回应；离开超过18米、危险或身份改变则中断。接受后才靠近至实际接触距离，再递物、包扎或交战。身体表现使用已有骨骼动作和简模药箱、绷带、食物，不锁住玩家在动作期间的移动。
- 走开、被定住、倒地、受拘束、危险、被拘押、身份改变或失去目标会中断。到达与交付分别记账；尚未完成包扎不耗药、不回血。交付后离开不会回收已给物品。
- NPC 只追踪刚看到的位置，失去视线后不持续读取玩家位置。原面貌造成的旧怨不会在卸妆后改记给真实玩家。
- 寻仇会先当面转述前因给同伴，记录来源为“听说”。同伴不会获得未揭露的真实玩家身份。
- 来访说明走玩家主动发起的正式对白；召集同伴与收场台词走现有单人冒泡与语音调度；不新增音色或付费生成。旁白与数字结算仍静默。原因、实际交付/回血、取消结果进入因果簿。
- 阿青人物详情显示当前身份所欠的伤药。现有“帮阿青研药”可偿还一份欠药，真实完成操作后才产出伤药并销账；重复结算不再发药，偿还不重复刷好感。旧版 v2 已有的欠药数量保留。
- 寻仇正在交战时，针对实际参与者的还击视为自卫；伤害照常，不额外制造玩家主动袭击的目击或通缉。攻击旁人、事件结束后追打仍走普通规则。
- 来访占用参与者的日常行动，暂缓进食、送茶、收款和其他闲谈；环境伤害、危险反应、定身与死亡仍生效。堵路会重新寻路，来访期间不使用回出生点传送保底。

## 保存与实现边界

`deck.actions` 保存活跃事件、交互版本、等待/接受状态、阶段、已过时间、目标物品、原位置、招集成员、最后目击位置、排期结果与去重键。旧版 v2 尚未结算的 announce/listen/act 阶段幂等转为 waiting，不沿用此前自动倒计时；已经完成的赠物和治疗保持原结果。等待中读档仍需主动交互，接受后包扎中读档继续剩余动作时间。物品或回血结算标记与结果一起写入存档。旧 v1 保留原实现，不迁入新章；v2 不再使用“听完救急对白立即回血”的旧入口。

本轮完成的是这三个主动行动模板。阿青尚不会经转述从远处被请来、自动复苏已倒地玩家或在本模板内给其他 NPC 完成治疗；看见更重伤者只会撤下对玩家的救助候选。寻仇目前依托两帮现有成员，不临时生成打手，也未扩展为所有职业的社交招募网。离线失败不影响事件规则，本轮没有给 AI 增加物品、伤害、奖励或身份决定权。

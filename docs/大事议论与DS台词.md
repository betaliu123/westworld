# 大事议论与 DS 台词

实现日期：2026-11-11 至 2026-11-12。

花石纲失窃被发现或被目击后，知情人的日常议论转为这件大事。消息由实际相近、无遮挡且能正常说话的人转述；茶棚里的人听到后，才会换成相应议论。没有目击、尚未发现的失物不会凭空成为全镇新闻。

## 已接入的事实

| 话题 | 入口与最初知情者 |
| --- | --- |
| 纲货失窃 | 成功取走后的冻结目击记录；或押运人实际靠近货车发现缺货 |
| 脚夫工钱 | 已成功垫付并留收据的剧情结果；先由当面参与的角色知情 |
| 伤人事件 | 已有案情记录的目击者、发现者和收到报告的官差 |
| 实际收押 | 实际拘押的官差、或嫌犯押送到场后接收的顾钦差 |

只有消息本身进入氛围系统。嫌犯、易容归因、证据、关系、名声、物品、奖励和线索仍由原规则处理。氛围议论不授予调查线索，不揭露锦衣客、刻字人等角色的秘密身份。

## 时效与表现

- 每个事件默认持续两个游戏日；前半段全局间隔至少 24 游戏秒，后半段至少 48 秒，同人至少间隔 70 秒。休息跨日会消耗有效期。
- 同一事件、传播来源、已说句子、近期重复抑制、冷却与到期时间均保存在 `worldNews`。再听说、再次取货或读档不会重启有效期。
- 活跃大事优先于附近普通闲话；茶棚的旧花石纲催押段在已封车或失窃后停止。未听过的其他线索仍保留原入口。
- 仍使用现有场景冒泡，没有增加正式对白菜单、说明栏或新 HUD 面板。已知姓名使用已知信息投影，未知人物不提前报出真实姓名。
- 同屏一次一人；死亡、重伤、束缚、拘押、哑穴、睡眠、溺水、危险反应等状态不能主动议论。当前对白、动作、战斗、余波招呼与救急来访优先。
- 冒泡真正显示后才记已读并写入一次江湖见闻。离场、被打断、切档和过期会使排队中的旧句失效。

## DS 的职责

本次实际调用项目配置的 `deepseek-v4-flash`：四次请求中，第一次格式解析失败，随后三次完成四个话题的生成。保留了 72 条经过逐句编辑检查的台词：四类事实 × 六种口吻 × 每类三句。原始请求、模型参数、回复和编辑记录见 `docs/offline/world-news-lines.json`。

运行时 `/api/director` 的 `world_atmosphere` 模式每事件至多请求一次，只编排已审阅的候选 ID。模型自由返回的文字、人物、奖励与额外 ID 都不会执行或显示；不传玩家存档、真实行为者或秘密身份。网络失败立即沿用本地台词，迟到结果只影响尚未播出的候选，不替换正在显示的句子。

扩写命令为 `python tools/world_news_lines.py --generate`；已有批次会拒绝覆盖，需先显式归档。生成后逐句审核，将 `review` 设为 `approved`，再运行 `python tools/world_news_lines.py --import-reviewed`。生成不会在游戏循环中执行。新增大事类型需增加公开事实模板、台词并接入 `recordWorldNews`，不能仅把一个隐藏剧情标志直接广播给全城。

## 验收与边界

- 规则测试覆盖未发现失窃、失败尝试、当面传播与遮挡、失能与恢复、读档和休息过期、无额外奖励、旧章隔离、DS 离线与迟到、候选过滤、已读时机及普通闲话让位。
- 最后一次全量回归为 817/817 通过；`npm run check` 与 Python 语法检查通过。过程中的旧副账断言曾失败，最新工作区回归已通过。
- 独立试玩与临时浏览器存储：1280×850、1024×768、800×600 冒泡均在屏内且不与检查的 HUD 区域相交；字号 16px、使用既有文楷字体；浏览器脚本错误为零。玩家正式存档哨兵保持不变。
- 浏览器验证将模型请求拦截为本地响应，确认每事件只请求一次、额外恶意台词不会播放；离线生成阶段已真实调用 DS。新增句子本轮未生成配音，沿用字幕与已有声音调度。
- 本轮实现事件议论、近处转述和场景冒泡，未增加报信专属行走任务、多人对谈镜头、公告演出或新语音。
- 截图与浏览器报告位于 `cc_task/2026-11-11-world-news/`，包括三档议论截图和 `exploration-1280.png`。浏览器场景将已发现失窃的押运人置于茶棚测试传播，不宣称覆盖完整押运人报信行走演出。

可见文字调整：撤下受大事影响期间的普通闲话和已失效的催押消息；未新增按钮标题、常驻说明或重复结果提示。

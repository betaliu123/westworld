# 07 · 产业与股市

## 负责什么

经济系统两件套：**产业经营**（投资/抢夺/岗位/收益/卧底分流）与**股市**（5 支股票，可在银行或手机交易，受新闻/玩家行为影响）。

## 关键文件

- `factions/BusinessSystem.js` —— 产业逻辑
- `config/businessData.js` —— 产业/岗位/能力定义
- `ui/BusinessUI.js` —— 产业面板（帮派面板「产业」tab）
- `ui/StockMarket.js` —— 股票交易面板（银行 + 手机复用）
- `factions/StockNewsService.js` —— 股市新闻 / 小道消息 / 玩家行为影响

## 产业

### 两种获取
- **投资**（和平）：小股/大股/独资，扣钱包拿股份每日分成；独资接管中立产业；黑蹄会产业只能抢
- **抢夺**（暴力）：弹窗先给战力预估（优势/势均力敌/劣势），再选投入人手；成功夺业+通缉，失败损失钱+黑蹄会热度上升

### 收益公式
```
岗位产出 = baseIncome×0.4 × 角色匹配(1.0/0.6) × 能力 × 忠诚(≥0.3) × 产业等级
卧底在岗 → 实际入账×0.5，另 50% 流回黑蹄会（账面看不出，面板显示"异常流失"）
帮派净收入 = Σ产出 − 维护费（薪水由 settleIncome 已扣）
账房任命 → 产业收益 +10%
```

### 岗位
账房/护卫/跑腿/打手/柜面，每个产业 1~4 个岗位，可派人（一人一岗）。

## 股市

- **5 支股票**：银矿/铁路/银行/枪械/农业
- **交易渠道**：银行股票面板 + **手机「股市」tab**（`Tab` 打开手机 → 📈 股市）
- 日结算 `settleDay`：基础波动 + 新闻类别敏感度 + 黑蹄会活跃度 + **玩家行为影响**

### 玩家行为影响（P13）
- 在商铺杀人/抢劫 → 对应股票第二天下跌（如赌场杀人→银行股跌，枪械店杀人→枪械股涨）
- `VENUE_STOCK` 映射商铺→股票，`PLAYER_ACTION_STOCK_IMPACT` 定义数值
- 每天 `settleDaily` 用 DS（flash）生成股市新闻（报纸）+ 提前一天的小道消息（手机）

## 配置修改

产业/岗位：`config/businessData.js`；股票定义：`config/gameData.js` 的 `STOCK_DEFS`；股市新闻模板/映射：`StockNewsService.js`。

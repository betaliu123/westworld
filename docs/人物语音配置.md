# 人物配音与增量生成

本轮采用经试听确认的 MiniMax `speech-2.8-hd`，通过雷火网关调用。锦衣客、官兵、宋茶娘沿用已听过的音色与参数；其余人物是待逐步试听的配音分配，不代表已全量录制。

## 唯一配置与调用

- 音色与表演参数：`assets/audio/voice-cast.json`。
- 首批真实台词：`src/voice-lines.js`；实际游戏也引用这些字符串，禁止再维护一份容易过期的配音文案。
- 成品索引：`assets/audio/npc/manifest.json`，逐条保留人物、可见台词、完整调用参数、哈希、文件、时长与来源。
- 调用：`POST https://ai.leihuo.netease.com/minimax/v1/t2a_v2`；Authorization 只在 Python 服务端读取 `TTS_API_KEY`（未设置时沿用本项目雷火 `LLM_API_KEY`），不交给浏览器或写入 manifest。

```json
{
  "model": "speech-2.8-hd",
  "text": "城门查得这样紧……<#0.35#>你是怎么进来的？(chuckle)",
  "stream": false,
  "output_format": "hex",
  "language_boost": "Chinese",
  "voice_setting": {
    "voice_id": "male-qn-jingying",
    "speed": 0.94,
    "vol": 1,
    "pitch": 0
  },
  "audio_setting": {
    "sample_rate": 32000,
    "bitrate": 128000,
    "format": "mp3",
    "channel": 1
  }
}
```

普通对白默认**省略 emotion，由模型自动表达**。守卫强硬问责用 `angry`；不要因为官兵人设就让所有闲谈都发怒。2.8 支持 happy、sad、angry、fearful、disgusted、surprised、calm。声音指导文字是制作备注，不发送成要读出来的台词。停顿、轻笑、叹息只对精确匹配的已编排台词使用，改台词后不会误套旧表演。

## 本次游戏接入

1. 初见锦衣客、宋茶娘、刻字人、赵行商、温素笺，按各自音色播放招呼。锦衣客照看后的感谢、发现偷窃的反应、入城后的追问也有预生成语音。
2. 保留已批准的三段试听，复用参数完全一致的锦衣客重逢、守卫问责片段。宋茶娘“这盏茶，我请你”只留在试听库；游戏当前照看结果没有真实赠茶，因此使用真实结算台词“多谢……这一回我记着。”，不凭配音制造虚假承诺。
3. 正式对白使用完整句段，不把一条录音拆成几页同时播放。切到下一句、Esc、关闭声音、玩家倒地、NPC 失声/倒地、页面切后台时停止。普通冒泡只播放已有缓存，避免不停生成叫卖声。
4. 同时最多一位说话。对白优先，进入正式交谈立即停掉氛围对白；冒泡按录音时长延长，远离或遮挡后停声。没有录音/网络失败保留字幕，行动与检定照常结算。
5. 声音默认开启，由“进入/继续”点击解锁浏览器音频；右上声音按钮可关闭，记住用户设置。没有新增游戏 HUD。取消旧的浏览器统一中文朗读，避免不同人物突然串成同一音色。

## 台词变化如何重生成

缓存键是 **人物 ID + 模型 + 文本/表演标记 + voice_setting + language_boost + audio_setting** 的 SHA-256。改字、改音色、改语速、改情绪或模型都失效；参数与台词不变就复用。旧录音留作记录，不会因为旧文件仍在而误播。

- **本地试玩**：正式对白第一次遇到新文本时，浏览器向本机 `/api/voice` 请求；服务端查缓存，缺失才生成。迟到的录音只缓存，若已跳过该句则不补播。只允许本机调用生成接口，局域网/静态发布照常播放已有录音。
- **限制试用量**：每次启动服务最多 12 个新生成请求（含失败尝试），`TTS_MAX_NEW_CLIPS` 可调整；已有缓存无限复用。超额保留字幕。不会整城一次性生成，也不会每帧请求。
- **修改首批编排台词后提前生成**：`python tools/npc_voice.py --limit 8`。只生成缺失/已变条目。
- **边改边补**：`python tools/npc_voice.py --watch --limit 8`。总额度达上限即停止；不是每次扫描另算额度。
- **静态发布**：打包 `assets/audio/npc/`、引用到的 audition 音频、`voice-cast.json`。静态站点无法调用模型，需先生成要发布的对白。自定义动态对白在本机首次说出时可补录，不等于静态站已全量有声。

刷新页面读取最新音色配置及索引；改台词无需清除玩家存档。生成工具绝不修改游戏存档。离线、缺少 key、额度耗尽都不能播放旧文本的音频作为替代。

## 验收范围

检查内容哈希跨 Python / JavaScript 一致、缓存命中不重复调用、改字/参数会失效、并发相同请求只生成一次、字幕和声轨一致、快速跳句不串音、静音与失声停止、未知性别不默认男声。音色是否符合人物仍以实际听感为准。

2026-11-10 验收：316 项 Node 测试、4 项 Python 缓存测试通过；11 个文件通过解码/时长检查（10 条游戏对白及 1 条仅试听对白）。实际浏览器验证了三人连续对白、退出停声和静音字幕；游戏载入原存档无控制台错误。`/tests/npc-voice-preview.html` 使用同一套声音和对白组件，播放不会调用生成接口。编辑监听器与本地服务共用文件锁，避免同时补录同一句产生重复请求。

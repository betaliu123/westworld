# 套索与事后盘查（2026-11-11）

## 可玩流程

- 新章及已有 v2 档一次性获得一根可回收的麻绳套索和基础套索能力，不要求先接任务。v1 不发绳、不迁入新章。
- 点右下套索图标，再点场景中的 NPC。六米内、绳路无遮挡可抛索；确认后才演出和检定，成功后实际牵行。近身可改为捆住手脚，也可松绑收绳。
- NPC 被点定身穴或倒地时，靠近交互可直接「近身捆绑」，无需再次抛索检定。动作完成前移动、受伤、目标走远或绳路被挡，会中断结算。
- 原地捆住后，按 Z 蹲下，交互打开真实行囊搜取衣物。取得衣服、穿上衣服、知道姓名和持有凭据分别处理；不复制物品，不自动赠送身份。
- 牵行受绳长、障碍和 NPC 身体状态限制。固定后日程、战斗、换班与卡死保底不能把人带走；环境伤害仍生效。定身未解或倒地者不能站起跟走。
- 正式榜文或拘传条件成立时可合法押送；人物实际带到清醒、未受束缚的交接人面前才结算一次差钱。普通捆人仍可被目击、被记住，松绑不洗去证据。

## 事后调查

- 未在当场结案的伤人、偷窃、破坏、动过吃喝会留下事发位置及具体目击者的记忆。目击者经过一段时间后走到可应答的官差身边报案；正在危险反应、失声或受束缚时不能完成报案。
- 无人目击的倒地现场，要有人实际走近、朝向现场且视线无遮挡才发现。发现结果不生成作案者姓名、面貌或衣着证言。
- 实际失窃的随身物品，失主恢复行动后会发现缺失；货摊物品需失主回到可见范围。已经归还或未偷成功不会凭空报失。此类发现同样不提供作案者身份。
- 现场目击过但追人未果的官差，在直接冲突结束后可回到原事发地调查。捕快实际走回现场并在周边巡查；被墙挡住不瞬移。
- 捕快近处看见玩家逗留后才会问话。收到的具体证言中面貌、衣着相符，或本人听过仍有效的身份传闻，会更快引来盘问，也会增加解释难度。其他官差不会自动共享这份知识。
- 盘查演出包括质疑、最多三个回应、真实检定、玩家解释和官差回答。预览与结算使用同一规则；取消不掷骰，同轮答复和读档不会重复结算。
- 解释失败会延长现场调查，并留下限时疑点，使之后的解释更困难。它本身不等于定罪。成功暂时免重复问话，不删除物证、证言或通缉。

## 实现边界

- 场景已实现抛索、可见牵绳、手腕/脚踝绳结与行走跟随；原地固定为捆住手脚，尚未实现把绳端系到任意树桩、马背拖拽或布娃娃绳索物理。
- 沿用现有气血归零的倒地/恢复规则；现场调查可发现倒地者，没有新增永久尸体、验尸、尸体搬运和完整审判系统。
- 调查基础巡查约 150 秒，解释失败可延长；物证及问话记录保留在存档。没有全城全知搜捕，也没有仅凭服饰风格判罪。
- 套索用自绘绳圈图标进入现有技能区，保留中文 aria-label 与悬停用途说明；没有新增常驻教学文字或独立悬浮提示区。绑缚/搜取的文字只在具体操作处出现。本轮不改人物音色与离线配音素材。

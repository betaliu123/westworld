# NPC 援助底线与亲近关系

2026-11-11，新章 v2。修复“绑了宋青禾，宋茶娘仍因玩家饥饿主动送包子”的矛盾。

## 即时规则

- 好感与已知伤害分开保存。NPC 已知某身份袭击、非法捆绑自己或亲近的人，或当面动过其吃喝，就停止对该身份的主动送食、救治；正好感不能抵消这条底线。
- 发牌、启动、等待交互、接受和完成身体动作时共用事实检查。开始送食后再发生伤害，尚未交付的吃食留在 NPC 身上；包扎中止不耗药、不回血、不新增欠药。已经完成的赠物不回收。
- 目击当场记下；转述只传给实际收到该条余波的 NPC。日切、松绑、送礼或有限的道歉好感修复不删除伤害事实。夜间推演不负责决定白天是否愿意帮忙。
- 归因使用目击者当时认定的身份，转述保留原身份和来源。卸妆不把别人面貌下的旧事追记给真实玩家；未识破的新面貌仍按对方所知处理。
- 合法拘传、自卫不进入主动伤害记录。一般偷窃、普通物件破坏等仍走原有好感与问责规则，本轮不把所有小过失永久变成拒绝援助。

## 亲近关系与观察

`src/npc-bonds.js` 保存独立于玩家情报的真实关系：本轮种入宋茶娘—宋青禾、梅掌舵—梅知意两组已确定的亲属；也读取带来源的实际 `family / friend / partner` 关系。不会因为同势力或同职业就当作亲友，不把这些内部关系自动暴露给人物图。

NPC 近处亲眼发现亲人被绑、倒地或伤重，会暂停援助、进食、收钱和送茶，真正寻路走到亲人附近，转向并短声询问。没看见施害过程，只知道“人受困”，不凭空知道是谁干的。位置只按视线更新，失去视线后前往最后看到的位置，短暂寻找后可恢复日程。

观察检查距离、朝向、遮挡、睡眠与意识；行动仍受受击、定身、拘束、环境伤害与危险反应打断，失声时不说话。到达后一句话按事件存档去重，不持续刷屏。没有新弹窗、固定 HUD 或强制对话；沿用现有近处冒泡和语音调度。

## 保存与边界

`people[id].harmKnowledge` 持久保存目标、认定身份、伤害类型、事实编号、来源和亲历/转述类型。按人、目标、身份、类型合并，因果簿裁剪后也不会失忆。旧 v2 只从已有目击名单、冻结身份和实际转述记录补录，幂等且不改好感、不发奖；不把无目击的记录猜成所有人都知道。v1 不改变。

`people[id].concern` 保存亲人受困的观察与最后见到的位置。已知事实阻止主动援助；仍保留一般交互入口。本轮没有实现 NPC 自动解绳、现场医疗操作、完整报官救援链或专门的信任重建任务，不将“走近查看、求助喊话”写成“已救出亲人”。

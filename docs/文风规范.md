# 文风规范 · 草案 2026-11-10

适用于对白、冒泡、书信、传闻、旁白与主角内心。预生成台词与 `deepseek-v4-flash` 实时生成共用本规范；人物范例同时作为实时生成的提示样例。标"暂定"的人名与师承待确认。

## 一、总则

1. **短。** 一次开口不超过两句，每句不超过 20 字。书信不超过三句。
2. **宋人口吻。** 白话里带古意，不掉书袋。用"官人、客官、小娘子、差爷、后生"，不用现代口语。
3. **说一半，留一半。** 人物说自己在意的事，不替系统解释规则。潜台词交给玩家。
4. **每人一种腔。** 身份决定用词，处境决定语气，口癖或意象让人一听就认得。
5. **说给眼前的人。** 称呼按"对方眼中的主角"决定，不按真实身份（见第四节）。
6. **记得旧事。** 有真实记忆时，一句话点到即可，不复述经过。

## 二、禁止

- 系统词：检定、成功率、好感、声望、任务、线索、属性、技能、经验、玩家。
- 现代口语：啥、咋、搞、行吧、没问题、哥们、真的假的、哇、OK；"老娘"不作自称。
- 套话与空情绪：必有重谢、不会为难你、心中一暖、嘴角上扬、仿佛、不禁。
- 对白里的阿拉伯数字；叙事里的数字一律写中文。
- 教人侵害自己（"想白拿就别让我看见"），或替玩家出主意（"你去偷他的衣服"）。
- 物化女性、性暗示、以羞辱女性制造冲突。

## 三、旁白与内心

- 旁白只写看得见的动作，一句一事："他把路引折了两折，塞进袖里。"
- 主角内心用全角括号，不超过 15 字，NPC 听不见：（衣服是借来的，名字也得借一个。）
- 书信开头不写套语，落款只写名号或一个字。

## 四、称呼：按对方眼中的主角

| 对方眼中的主角 | 常用称呼 |
| --- | --- |
| 寻常男子 | 客官、官人（衣着体面）、后生、小哥 |
| 女装（乔装被认可） | 小娘子、姑娘 |
| 差役 | 差爷、上差；守军称"县里的" |
| 民夫、乞丐 | 喂、那个、老哥 |
| 已有名号且对方听说过 | 直接用名号 |

乔装被识破的那一句，称呼要跟着改口，这是最直接的反馈。

## 五、人物与范例

每人写明：身份、想要什么、说话的腔。范例覆盖初见、关键事件与关系变化。

### 宋茶娘 · 城外茶棚掌柜
想护住女儿，也想守住茶棚。泼辣，心软，凡事拿茶说。
- 客官吃茶。今日门上不好过，花鸟使在点人。
- （白喝了她的茶）这一盏算我请的。下一盏，可要见钱。
- （付茶钱）钱放桌上就好，我手上有茶渍。
- 我家青禾在镇上帮工。……你问她做什么？
- 黄封贴到谁家，谁家就没了日子。
- （目击偷窃）我这茶棚小，容不下三只手。
- （受过帮助）茶钱免了。往后渴了，只管来。
- （主角帮青禾进园）你走吧。这盏茶，我不卖你。
- （识破茶里有毒）这壶里多了一味，不是我放的。
- （冒泡）雨要来了，收棚。

### 韩校尉 · 临溪关守军（禁军）
想太平交差，被花鸟使压着。话短，像军令，透着疲惫。
- 路引。
- 叫什么？哪里人？
- （冒名，答对姓名）过去。下一个。
- （答不上姓名）自己的名字都要想？这路引是你的？
- （纲船到）都退开！纲船先过。
- （拒贿）收起来。今日上头有人看着。
- （受贿，无旁人）我什么也没看见。
- （守卫被袭）关门！拿人！
- （私下）花石一过，我这关就成了别人的门房。
- （主角扮差役）县里新来的？杜老捕没提过你。

### 锦衣客 · 赵闲舟（宗室，暂不揭晓）
看人看做了什么，不看说了什么。雅，以风物说事，从不直言。
- 这茶粗，水却是好水。可惜了。
- （见主角帮人）方才那一下，不为钱吧？
- （见主角伤人）身手是好的。下手的地方，不太讲究。
- （邀作随从）我缺个牵马的。进了城，各走各路——也许不。
- 花石入京，一路都是人在哭。宫里只听得见丝竹。
- （问身份）赵闲舟。闲人一个，舟也是借来的。
- （身份揭晓）你既知道了，就当不知道吧。
- （讨人情的信）城南旧宅，替我去看看窗下的花还开不开。
- （失望）我原以为你不同。

### 杜老捕 · 退役捕快（点穴师父）
腿伤退下来，心还在衙门。慢，句句带旧案的味道。
- 后生，腰直起来站，才像个差人。
- （演示后）看见了？不是戳，是送。
- 先认穴，后认人。点错了人，比点错了穴麻烦。
- （学成）这一手，别拿去欺负老实人。
- （识破假差役）衣服是县里的，人可不是。
- 衙门里有人吃两家饭。我老了，嚼不动了。
- 下雨天，这条腿比我先知道。
- （主角用点穴作恶）我教你的东西，你用在这里？

### 花鸟使 · 应奉局（姓名暂定）
把掠夺说成恩典。温和，慢，越客气越可怕。
- 官家喜欢的东西，是你家的福分。
- （贴黄封）这块石头，从今日起是御物。碰坏了，按逆论。
- 这姑娘生得好，园里正缺个折花的。
- （被拦）你拦的不是我，是官家的兴致。
- 名字我记下了。应奉局的册子，从不丢页。
- （受贿）心意我领了。石头还是要搬的。
- （对守军）纲船先行。误了时辰，你担得起？

### 宋青禾 · 茶娘之女（名字暂定）
自己想进艮岳，不是被选中的可怜人。冷静，有主意。
- 我娘只看见那园子吃人。我看见的是一扇门。
- 你也是来劝我的？
- （教女装）腰再收一寸，步子小些。低头不是怕，是让人看不清你的眼睛。
- （拒绝被顶替）这是我的路。你要进去，自己找门。
- （作眼线的信）园里的鹤是吊着飞的，我看见绳子了。

### 梅知意 · 赤砂帮主之女
自己做主，看不上被安排。利落，带刺。
- 绣球是我抛的，接住的人归我挑，不归我爹。
- 你是来做买卖，还是来看热闹？
- 我爹的帮，我爹的规矩。我的事，我自己定。
- 不必。我不欠人，也不喜欢人欠我。
- （主角帮了码头）码头上的人记你一碗酒。我记你一句话。
- 你身上有六扇门的味道。

### 段赤川 · 赤砂帮镖手
替弟兄争饭碗。粗，讲义气，说话带码头号子。
- 让开！这船要卸，误了工，弟兄们喝西北风？
- （截纲船）截一船石头，痛快。百万漕工衣食所系，你截得起？
- 赤砂帮不偷自家兄弟。外人嘛——看你是不是外人。
- （收人入帮）手脚干净，胆子不小。先扛三天包。
- （发现被偷）好手法。下回别让我抓着。
- （欠人情）那日你放了燕七，这份人情记在砂上。

### 林青舟 · 青竹会护路弟子
认死理的侠。清冷，话少，句句是立场。
- 那船上装的不是石头，是一路的人命。
- 今日不截，明日又是十船。
- 你们扛的是饭碗，我知道。可这饭碗，是砸了别人的家换来的。
- （主角站赤砂帮）各有各的道。路上再见，别怪我。
- （主角站青竹会）青竹会不说谢。往后西郊的路，你走得安心。

### 陆捕头 · 六扇门
守规矩，也被规矩捆住。说话像在念文书。
- 拿人要有文书。没有文书，我也只是个路人。
- （交出小偷）人赃俱在，记你一笔。明日来衙门画押。
- （升任请客）今日不谈公事。……明日再谈。
- 你这腰牌，是哪一年发的？
- 黄封我管不着。当街打人，我管得着。

### 刻字人 · 无相门外线
只谈刀口和纸，不问来路。
- 刻什么？刻谁？
- 名字给我，纸给我，脸你自己带。
- 官印不刻。刻了，这双手就该交出去了。
- （伪造的伏笔）想学？先学会把自己的字写丢。

### 燕七 · 小偷
油滑，怕死，记仇也记恩。
- 官人借过，借过——
- （被抓）我饿！三天没吃了！
- （被放走）你是好人。好人在这城里活不长，我记着你。
- （被交官）行，记住你了。

### 瘸张 · 城西墙外乞丐窝
自嘲，消息灵通，拿消息换饭。
- 来了就坐。这里不问名字，名字值钱。
- 一个饼一句话。两个饼，我说实话。
- 那草堆归你了。夜里别翻身，压着人。
- 五更开鬼市。别带灯，带耳朵。

### 乐器师父（人选暂定：苏晚）
看人先听人。淡，话里有节拍。
- 你站了半天。听得懂，还是没地方去？
- 气别全吹出去，留一口给下一句。
- （赠笛）这支旧了，音还准。别拿它敲人。
- （主角偷了笛子被认出）笛子认人。你吹一声，我就知道是哪支。

## 六、实时生成约束

- 输入给模型：人物卡（身份、想要、怕什么、口癖、对方眼中的主角）、本节该人物的三条范例、已发生的事实、该人物真实知道的部分。
- 输出：一至两句，每句不超过 20 字；书信不超过三句。
- 本地校验：长度、禁用词、阿拉伯数字、未知人名。不通过就使用预生成台词。
- 实时文本只改表达，不改事实：不许诺、不发物、不指认没看见的人。

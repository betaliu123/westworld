# 势力入职首版
官府大堂位于城东北 (10,-23)，赤砂堂位于城东 (23,-5)。小地图有“官”“帮”。建筑正面开放，可走入交谈。

六扇门：杜老捕的引荐检定，或获得税课线索后向锦衣客求引荐，取得闲舟引荐玉符。向顾钦差“出示”玉符，物品保留，验认记录保存，再申请入职。获得实体腰牌。领取燕七拘传令后可在 NPC 对话中亮牌拿人，膂力检定成功后跟随，到钦差面前交差一次奖励 20 文。未有文书不能对无辜者使用此入口；普通攻击仍触发犯罪。

赤砂帮：可直接拜访梅掌舵；也可在绛云楼与梅知意交谈得引荐。身法考核成功入外堂，一次性身法 +6、偷窃历练 +30，并获得外堂牌。当前单一正式身份，不同时担任捕快和帮众；退出/叛帮未实现。

玩家与直属首领进入组织图，梅知意的父女关系在当面获知后展示。仍可自由偷窃、交谈、送物、攻击两位首领，无剧情无敌。

范围：首件拘传案、招募与被动成长已实现；未实现通用犯罪审判、复杂官阶、动态帮派战争和长期升迁。拘传后的燕七留在大堂值房等候核问。

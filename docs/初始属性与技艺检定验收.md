用户确认：采用新开局属性和技艺成长曲线；旧存档作废，不做迁移。

各出身总和 200。点穴、妙手、眼力、武艺仍从粗通开始，其他技艺未学会。属性决定长处，技艺档位决定主要成长与能力准入。

## 实际规则

`round(50 + (属性−50)/2 + (档位−1)×12 + min(心得,30)/30×4 − 难度 + 现场修正)`，最后限定 5–95。整个表达式仅取整一次。不会为档位 0；能否执行另按技能与世界事实判断。确定性搜取及已探查缓存不掷骰，阻断预览不给百分比。

| 行动 | 属性 / 技艺 | 难度 |
| --- | --- | --- |
| 外露物品、食摊、书摊、桌上钱币 | 身法 / 妙手 | 物件基础 0 |
| 系紧的钱袋 | 身法 / 妙手 | 10，且须入门 |
| 袖中物件、挑着的货物 | 身法 / 妙手 | 15；袖中物件须熟练 |
| 衣架差役服 | 身法 / 妙手 | 10 |
| 暗送物件 | 身法 / 妙手 | 15，且须精通 |
| 点定身穴 | 身法 / 点穴 | 目标实际武艺每高于粗通一档 +10 |
| 点哑穴 | 身法 / 点穴 | 在定身穴难度上 +12，且须熟练 |
| 探查 | 机敏 / 眼力 | 普通人 0，锦衣客 25 |
| 共用的混入药粉入口 | 身法 / 医毒 | 物件基础 0；拥有药粉但未学医毒承受档位 0 劣势 |

偷窃附近、可见且能行动的物主额外抵抗：实际武艺高于粗通每档 5，与机敏超过 50 部分的一半（最多 15）取较高者。物主不在场或隔墙不会影响地上散物概率。熟睡 +15、打盹 +10、实际正在吃喝 +15；偷窃现场真实听曲 +15。警告、交战、调查、搜索状态 −20，优先于分心奖励；这些修正不叠加。仅有吃饭日程不算正在吃东西。

身法 60、零心得、普通目标与外露物品，粗通至精通为 **55/67/79/91%**。钱袋入门为 **57%**，正在吃食时 **72%**。机敏 50 的普通探查为 **50/62/74/86%**。

成功与目击分别结算，不因为概率上升抹除目击事实。预览不掷骰、不转移物品；确认时重新检查当前事实，结果持有发放心得之前的概率。心得封顶、来源去重、不自动升档。点穴保留背后、哑穴与体力门槛；精通实际允许六米，探查三点五米，入口与瞄准共用距离和遮挡检查。

## 存档和界面

- 正式、关卡预览改用各自 v3 存档键，试玩追加独立后缀。仍是第二章，另写入 `balanceVersion: 1`。旧 v1/v2 不读取、不迁移；提示旧档作废并开新局，浏览器旧键不必物理删除。
- 三种动作都显示实际能力、成功率和难度描述。阻断时只显示原因；缓存查看不显示虚假的 100% 检定。
- 粗通探查可回看已得到的外表观察，但不能看到尚未解锁的身份、行囊或钱财。
- 瞄准提示使用纸色、墨字、16px，限制宽度并自动换行，瞄准时收起竞争的小地图区。取消后恢复。
- 没有新增常驻操作说明栏；门槛原因只放当前行动旁。此前偷窃修复已移除面板底部的常驻按键说明。

# 现场冲突与主动投降

用户已确认：袭击先走战斗、逃跑、求援，增加战斗中的投降悬浮按钮与快捷键。

- v2 袭击保留问责事实，初始阶段为 conflict，不自动打开对白。武艺、职责、亲近关系和伤势决定还击或逃离，目击者先避险再沿原报案链求援。
- 战斗时 G /「投降」按钮共用入口。取消尚未命中的挥刀、清除连击与移动输入；附近可接收者实际接近后打开既有问责。附近无合格对象、隔墙、失能者不能接收。
- 投降不掷骰、不清证据、不回血、不重置赔偿或回应次数。关闭问责恢复冲突；官差问责提供到案入口。低血量本身不拘押，原有官差近身命中制服须实际造成伤害。
- 自动问责、身份盘问、调查对白让位于冲突。普通偷窃等既有分支及 v1 保持兼容。
- HUD 加入 hud-context-actions，短文案「G 投降」，不增独立 fixed 坐标，详细面板和对白期间隐藏。

# 人物称呼统一

用户确认：普通人物第一次正式交谈自动结识，不逐人询问姓名。陌生时以可观察称呼区分人物，冒泡去掉姓名行；所有入口使用同一称呼。

## 规则

- 普通 NPC 正式对白开始显示时记入 `facts.knownNames` 与来源，重复显示、读档不重复结算。E 菜单、话题浏览、探查、环境冒泡、旁听和内心想法不授予姓名。
- 赵成、锦衣客与燕七保留原有介绍/化名/身份确认条件。普通姓名、势力背景与秘密身份独立；持有衣服、路引不等于读懂姓名。
- 所有人物名称入口使用 `npc-names.js`：E、Canvas 名字牌、菜单、对白、冒泡、资料、行囊、送物、盘问、人物关系与记录。NPC 的世界内部 ID 和行为者归因不改。
- 无姓名冒泡只显示正文，已知姓名改用现有墨色。普通陌生人物资料注明“姓名：未相识”；势力未知仍保留问号。
- 已有 v2 档从已完成的正式对白或已听话题补认普通人物。仅 `metPlayer`、探查、菜单浏览或尚未完成的对白不能补认。原有 v1 键与正常玩家存档不做删除、重置。

## 验证

专项覆盖：陌生/已识两条路径、浏览不结识、探查不获姓名、普通初次回应、读档、重复无奖励、隐秘身份、路引未读与第三方明确介绍。

试玩入口为 `tests/npc-names-preview.html`，使用 `npc-names-qa` 独立存档。三档尺寸与画面验收记录见 `docs/qa/2026-11-12-人物称呼统一.md`。

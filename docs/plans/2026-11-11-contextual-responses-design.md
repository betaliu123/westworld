# 特殊状态回应：本地候选库设计

日期：2026-11-11。本文保留接入前的候选设计与基础盘点；后续已接入范围、验证结果和待扩展项见 [验收记录](../qa/contextual-responses/验收记录.md)，不能把下文全部候选当作已上线功能。

## 本轮约定

- 用预写台词和本地条件即时选择回应，不调用实时生成。后续根据试玩效果决定是否补充生成能力。
- 特殊选项统一显示为 `【触发原因】具体说法或意图`。标签解释为什么能这样说，不透露玩家尚未知晓的人物身份、关系或证据。
- 优先用当前乔装、真实势力身份、与对方有关的关系和经历，再考虑身体、技能等状态；直接相关的物证与紧急危险优先。
- 正式入职可以成为依仗。正常亮明身份与借势压人分开；滥用身份可能带来关系损失、地方恶名、门内处分，直至除名。
- 本文遍历 64 个基础候选、12 个组合变体与不能生成选项的边界。不是把所有候选同时摆到屏幕上，也不承诺一次实现全部扩展系统。

## 已核实的工程基础

| 现有来源 | 可利用的事实 | 实现边界 |
| --- | --- | --- |
| `src/complaints.js` | 偷窃、袭击、破坏、动手脚的当面问责；赔偿对象与金额 | 当前四项固定；问责对象中还需补全物品、前因、身份与证据快照，不能只读类型 |
| `src/aftermath-encounters.js` | 亲见与传闻余波、前因编号、回应去重、行为者身份 | 目前辩解、道歉、暂缓为固定回应；新的分支尚未接入 |
| `src/appearance.js`、`src/disguise-encounter.js` | 衣物、易容面貌、认定身份、熟悉该面貌的人、传闻接收者、识破记录 | 熟悉一张脸不等于朋友、盟友或愿意担保；名字知识与玩家关系不能跨身份借用 |
| `src/faction-career.js`、`src/court-street.js` | 六扇门和赤砂帮正式入职、引荐、腰牌、拘传令、捕头任命 | 尚未发现完整的滥权处分、停职、除名流程；其他势力不能仅凭授艺认定入职 |
| `src/reputation.js` | 地方与势力分别记账、归因、来源去重 | 具体 NPC 知不知道名声仍需传播证据；门内认可不等于整个势力的社会声誉 |
| `src/ecosystem.js`、`src/simulation.js` | 气血、体力、饱食、病症、物品、钱、位置 | 有数值不代表 NPC 自动知道原因；暂停追问、赊账等完整结果仍需接通 |
| `src/item-meaning.js` | 原主、转移方式与目击者、归还结算、因果记录 | 原主与当前合法归属不能混同；内部转移记录不是 NPC 自动掌握的证据 |
| `src/npc-persona.js`、`src/care-rule.js` | 人物风格、好感、信任、照看记忆和部分受害印象 | 好感不等于信任；照看布尔值不足以代表可消费、可归因的一次欠情 |
| `src/factions.js` | 玩家已知人物与组织关系投影 | 组织关系不是朋友关系；隐藏组织与人物不能从后台关系图直接带入选项 |
| `src/apprenticeship.js`、`src/skills.js` | 已完成的具体教学、技能档位与来源 | 获得授艺不等于正式拜师、入门、组织授权；补救要有实际动作 |

下表的“基础”表示已有相关状态，可优先接入，**不表示特殊回应已实现**；“补证”表示还需结构化的前因、知识、关系或传播记录；“扩展”表示必须先补齐相应行动/制度才能开放。所有候选仍需接入预览、结算、对白与存档。

## A. 身体与当前处境（8 项）

| 编号 | 标签与候选说法 | 出现条件 | 作用、代价与后续 | 基础程度 |
| --- | --- | --- | --- | --- |
| A01 | 【气血低】我已经撑不住了，容我缓一口气再说。 | 活着且气血不高于最大值的 30%；不谎称具体伤因 | 请求短暂缓和、先救治；保留看守、追责与物品归属。气血阈值是初版设计值 | 基础 |
| A02 | 【体力不支】我不走，先让我喘匀这口气。 | 体力不高于 20/100；能够说话；不能只因蹲行就判断虚弱 | 请求留在原地歇息；同一前因不反复换取停顿 | 基础 |
| A03 | 【身体不适】我腹中疼得厉害，能否先找人看看？ | 病症已发作、玩家确已感到不适；潜伏毒性不算 | 求助、核验身体情况；不自动指认投毒者，不直接解除嫌疑 | 基础 |
| A04 | 【饥饿】这口饭我确实想拿，能否让我做点事换？ | 饱食不高于 20/100；争议对象确为食物 | 承认拿取，谈赊食或实际帮工；不适用于钱袋、首饰。无可执行帮工时只保留求情版本 | 基础 |
| A05 | 【盘缠不足】我眼下赔不起，能否容我筹钱？ | 玩家实际可支配钱少于本次真实赔偿额 | 请求有期限的宽限；承诺不能立即结清。赊欠系统接通前，不生成对方已经答应的结果 | 基础 |
| A06 | 【已收兵刃】刀已经收了，我愿把事情说清。 | 已通过实际动作收刀；对方看见；此后没有继续攻击 | 降低眼前冲突强度，不抵消既有伤害；拔刀再收不能循环刷信任 | 补证 |
| A07 | 【刚受袭击】方才是他先伤人，请先听听在场的人。 | 记录到真实伤害、先后顺序和可核实证人；仅低气血不足以支持 | 请求核验起因；先受袭击不自动允许之后所有攻击 | 补证 |
| A08 | 【刚经救治】我才缓过来，愿在这里等你把人请来。 | 有近期救治/复苏记录，尚未恢复；玩家实际知晓该过程 | 以接受看守换取暂缓问话；不能用未记录的昏迷解释之前全部行为 | 补证 |

| B07 | 【熟悉往来】上回那桩货账，你我可以当面核对。 | 玩家确实知道具体往来，对方也亲历，当前借用的身份与该往来相符 | 用细节支持身份解释；知道秘密不是必然骗过，不能补造共同经历 | 补证 |

## 标签与对白表现

1. 选项首部一律用全角 `【】`；一个主要原因优先，确有组合价值时最多两个。示例：`【气血低】我已经撑不住了，容我缓一口气再说。`
2. 【卖可怜】是策略，不是触发原因，因此不作为主标签；用【气血低】【身体不适】。同理，用【六扇门】而不是【特殊威慑】。
3. 名字来自玩家已知信息投影。不能显示【王爷旧交】【无相门同门】来提前揭密。只认识化名时使用化名。
4. 标签只出现在选项，不作为主角开口的台词，不送入配音文本。按现有音色和内容哈希规则处理声音；本轮不生成新配音。
5. 标签不能声称尚未确认的事实。仅穿差役服标【差役服】，真实入职才标【六扇门】，已失效身份不能继续显示在职标签。
6. 显示真实能力、成功率及这次成功能争取到什么；“同意先治伤”“愿意听证人”不能概括成“成功脱罪”。确定性核验不展示随机成功率。
7. 金钱、物品、人情等代价在选择前说明。地方/势力名声的已知确定代价可明示；未来告状尚未发生，只提示可能的后果，不伪造确定扣分。
8. 同一轮浏览或取消不掷骰、不扣款、不用掉人情；没有新事实时反复开关面板不换一套更容易的选项。

## 本地筛选和每轮数量

### 条件校验

每条候选都要有：适用场景、触发标签、玩家所知、NPC 所知、涉及人物/物品/前因、可执行结果、风险、优先级、稳定编号、成功/拒绝/失败的本地台词，以及重复结算键。上述字段是拟新增的数据契约，不表示当前存档已经具有这些信息。

筛选顺序：

1. 确认存活、意识、距离、遮挡与当前事件仍可交谈。着火、溺水等需先由危险反应处理，不能停下世界等玩家读长对白。
2. 取得该 NPC 在本次前因中冻结的行为者与当前认人状态，分开读取各身份的关系和名声。
3. 检查触发事实及双方的知识边界，排除矛盾和未实现的行动。
4. 区分本次目标：当场问责、身份盘问、事后关系修复、纪律问询。不能把事后“接受道歉”用作现场放行结果。
5. 同意图去重：A01 与 X01 只保留更具体者；D03 与 D07 若出自同一次照看，不重复占位、加成或结算。
6. 生成稳定排序，玩家确认后重查相关实物、距离、身份及记录。条件失效就说明变化，不偷偷换选项或改判定。

### 默认优先级

- P0：真实险情、确定性矛盾、能直接核实本案的关键证据。原主当面识破不被高关系选项覆盖。
- P1：本案相关的当前身份、有效职权、共同熟人、具体人情、共同经历；不能只因所属势力大就置顶所有场景。
- P2：气血/病症等身体状态，以及能履行的归还、赔偿、救助或修复方案。
- P3：地方名声、一般信任与较弱的场合解释。
- P4：普通辩解、认错、暂不回应等基础回应。

相关性优先于层级：低气血求暂停在救命时进入 P0；与当前偷窃无关的账本不能挤掉归还赃物；朋友与对方有仇也不能自动加成。

### 三个选项与保底

- 默认同屏是两条最相关特殊回应，加一条符合现场的承担/暂缓选项；不足两条时以真实可用的基础回应补位，不凑空话。
- 事后余波保留“暂不回应”；当面拘捕中的 Esc 只是关闭界面，不能让玩家凭取消解除看守或消案。
- 多条有用候选可按“说明来历”“请人说和”“商议补偿”收成语义明确的导航入口；导航不掷骰、不说台词、不切镜头，不另列第 4 句纯回应。每层仍至多三项，返回/关闭用已有图标。
- 例：同时有物证、六扇门与朋友时，可以显示【路引在身】验看、【六扇门】按规矩处理、请人说和；“请人说和”展开共同熟人、引荐人与认错/接受处置，基础承担路径必须可达。
- 已提出的赔偿金额、邀证、借势要求，在同一事件内接同意/拒绝；不要求退出重新找 NPC。
- 攻击仍由通用身体动作承担；本轮不靠新增“动手”按钮扩写对话，也不在未验证通用动作前移除现有唯一入口。

## NPC 接话不止分成功/失败

本地台词按人物身份与眼前事实编写；现有 persona 可作回退分组，但重要角色有专用措辞。不要随机拼接会改变结算含义的句子。

| 请求 | 愿意缓和的接话 | 守规矩的接话 | 已受骗的接话 |
| --- | --- | --- | --- |
| 气血低求暂停 | 先坐下。伤处缓一缓，东西的事再说。 | 可以先看伤，人不能离开。 | 我可以等，东西先放在我看得见的地方。 |
| 请共同熟人核实 | 我愿听她怎么说。 | 可以请来，先说清她看见了什么。 | 别拿她的名字替自己担保，她得亲口说。 |
| 正常亮六扇门身份 | 腰牌给我验一眼，事情慢慢说。 | 既在门里，更该依规矩留名。 | 这牌子是真的，你说的话还得再核对。 |
| 六扇门借势施压 | 我今日先退开，这话我会记住。 | 身在六扇门，更不能拿身份压人。 | 又拿门里的名头来？我会把经过禀明。 |

“我会禀明”必须接真实的报告意图与可执行路径；路径/报告系统未接通时，换成不承诺已发生后续的台词，不用喊话假装制度已经运行。

## 势力依仗与长期处分

### 正常提名与滥用权势

- 正常证明身份、持相关文书办事、请求组织调解，不因“提了势力名字”自动扣分。
- 借身份逼迫受害者放弃追究、要求免赔、越权索取财物，属于可记录的滥用。对方怕而退让不等于信任或原谅。
- 六扇门看是否越权、侵害无辜、伪造公务；赤砂帮可关注借帮名侵吞、破坏已承诺的往来、反复让同门担责。具体组织必须有已设定的规则，不能所有势力套相同道德扣分。
- 门内“对玩家的认可”、临溪“对该行为者的名声”、NPC “对该身份的关系”分别记录。此次不新增整个组织社会声誉的大系统。

### 建议纪律流程（待实现）

1. **事件发生**：保存前因、说了什么/做了什么、目击人、当时认定的身份、使用的名号和实际损失。压人成功也可能留下不利记录。
2. **具体人决定报告**：受害者/目击者按职责、信任、畏惧和路径决定是否告状；可当面抵达负责人、托实际传话者或走已实现的信件渠道。
3. **报告真正到达**：负责人获知有限内容。传闻可引发询问，不能立即等同查实。无人传递时不凭空全组织扣分。
4. **核实并告诫**：轻微且首次查实的滥用，门内认可下降并收到具体告诫；玩家可解释、出示证据、认错、提出实际补救。
5. **再犯或严重违纪**：查实后暂停特定权限、取消担保/任命资格，明确恢复条件。处分不是新台词，相关动作入口确实受限。
6. **除名**：告诫后仍有独立且查实的重复滥用，或足以直接除名的严重行为，由有权限者作出并通知。取消正式成员状态、任职与授权；组织树、选项、门禁等读取同一状态。

初版不把“提三次六扇门”当作三次违规，也不把势力声望跌过一条线当作自动除名。处分由有来源的已核实事件推动，声望记录其结果。具体数值随玩法测试校准。

### 归因、实物与防重复

- 同一前因可有多份报告，但同一项处分只结算一次；连续冲突不能按每句威吓、每刀重复罚到除名。
- 冒充赵行商时的负面行为先按各目击者当时的认定记录。后来发现疑点可新增调查与证言，不能追溯重写所有人的旧记忆。
- 仅穿差役服或持偷来的腰牌，不能给玩家增加正式入职事实，也不能扣一个尚不存在的玩家门内身份信用。冒名举报先查行为者。
- 正式玩家若在易容状态下主张真实身份，先完成认人/验牌或明确冒险自报，再调用本人门内信誉；不能同时享受隐匿身份与真实身份免查的好处。
- 除名使腰牌/文书失效，不让实体凭空消失。实际缴回、扣押、遗失分别记录；未知除名消息的人仍按自己掌握的信息反应。
- 不回收早已学会的普通技能、已获得的无关物品。入职奖与既有任务结算幂等，除名后重入也不能刷奖励；重入流程未做时不许诺。
- 本地事件记录应把证据、处分与关系变化分别编号。交钱、道歉、医治只能改变适用部分，不删除通缉、伤害和历史。

## 不做成特殊对话的状态

- **死亡、昏迷、失声、隔墙够不到**：限制可说话/可听见，而不是产生一条假装能正常交谈的特殊台词。
- **仅数值较高**：风仪、臂力本就参与适当检定，不为每个属性阈值复制“更强辩解”。有实际技能用途再开放行动。
- **性别、异性装束、外貌风格**：不默认带来犯罪、羞辱、撒娇特权或固定情感效果。称谓按真实已知身份处理。
- **后台隐藏身份/毒性/关系**：不是玩家或 NPC 的知识，不能据此生成标签。未揭晓秘密不进入 DOM、tooltip 或候选数据投影。
- **背包没钱**：只能说明付不起，不能编造“被抢”“全家有病”“欠赌债”。
- **拿到文件**：不等于读过；读过不等于 NPC 知道玩家已读，更不等于能拿它证明所有事情。
- **曾经见过/同组织**：不等于好友、欠情或愿意作保；第三方没有明确答应，就只能请求联系和核实。
- **未实现的天气、负重、酒醉、婚恋、亲属、豪宅、完整拜师**：不靠漂亮台词假装这些系统已存在。未来有真实玩法价值再扩展。
- **无事实变化的换装、读档、退出再进**：不重置失信、露馅、重复求情和已完成处分。

## 优先接入顺序

1. 共用事件上下文和本地候选入口：当面问责、身份盘问、事后余波读取同一事实，分别结算合适结果。
2. 最可感知的一组：A01/A02/A03/A05、B01/B02/B05/B06、C01/C02/C03/C05/C06/C08、E05/E07、F01/F02/F03。已有信号先接通；其中 C02 必须同时具备可信的报告/纪律后果，不能只有施压收益。

## 验证清单

- 同一场偷窃问责，分别用满血/低气血、原貌/易容、未入职/在职/停职/除名、有朋友/没朋友、有文书/无文书比较候选与结果。
- 原主当面、熟人听过传闻、仅穿差役服、持别人腰牌、自己正式在职但易容，均不混淆三类身份。
- 真正共同熟人、双方只见过、朋友在场但没看见、看见但拒绝作证，分别处理。
- 真正付清与钱尚在桌上；托付与偷来；读过账目与仅持有；物已归还与尚在身上，分别处理。

## 试听要判断什么

- 街市：人群是否像日常生活；叫卖有没有播音腔、现代背景杂音；作为背景是否过密。
- 溪畔：流水是否自然、鸟叫是否过于规律；久听是否疲劳。
- 锦衣客：克制、从容、有试探意味，避免新闻播音与过分霸道。
- 宋茶娘：亲切利落、在忙自己的生意，避免刻意撒娇。
- 当前模型调用和文件解码已验证；人物表演是否合适，以实际试听决定，不把模型标签当作质量结论。

## 选定后的接入顺序

1. **环境底声**：街市、茶棚、溪流、树林、夜间分区，随玩家位置和昼夜平滑交叉淡入。可辨叫卖从底声里拆出；底声不塞任务情报。
2. **实际声源**：摊主叫卖、碗盏、脚步、河水绑定所在实体。使用 Three.js 音频监听器和空间声源，带距离衰减、方向及简化遮挡；远处与隔墙不能清晰听见关键对白。
3. **人物对白**：每个 NPC 固定基础音色，再按友好、怀疑、问责等状态调整语气。已有确定台词预生成并缓存；动态台词按“人物＋文本＋语气＋模型版本”缓存，禁止每帧请求或重复计费。
4. **调度**：正式对白优先于氛围。近处叫卖最多一人，同句有较长冷却；正式对白时环境暂降约 8–10 dB，结束后缓慢恢复。中断对话、死亡、离场和切页及时停声。声音总开关之外分环境、对白、音乐音量。
5. **音乐**：后续单独试一条疏淡的琴箫主题。探索不持续铺满配乐；关键人物、线索或危险出现时短暂进入，再退回真实环境声。音乐不要和卖艺、NPC 乐器演奏重复叠加。
6. **语音与文字一致**：只读实际说出口的话；括号内心想法、系统日志、检定数字不作为外放语音。语音不能提前泄露隐藏身份。音频失败保留字幕，不阻塞行动和结算。
7. **生成在服务端或离线工具运行**：浏览器游戏只拿成品音频；个人 API 密钥不得进入仓库、静态资源或前端请求。上线前检查平台输出使用条款。

## 素材来源与选择

- [Seed Audio 1.0 官方介绍](https://seed.bytedance.com/en/blog/from-speech-to-audio-creation-introducing-the-seed-audio-1-0-audio-creation-model)：支持文本控制的语音与环境音。此次通过雷火网关生成两段环境小样。
- [Seed 音频生成协议](https://docs.volcengine.com/docs/doubao-voice/audio-generation-http?lang=zh)：网关使用 /openspeech/api/v3/tts/create。
- [雷火 MiniMax 配套技能](https://skill-market.leihuo.netease.com/skills/detail?id=1662)、[官方同步语音协议](https://platform.minimax.cn/docs/api-reference/speech-t2a-http)：网关使用 /minimax/v1/t2a_v2。此次使用系统音色，没有复刻真人声音。
- [ElevenLabs 音效工作台](https://elevenlabs.io/docs/eleven-creative/playground/sound-effects)：可作为后续短音效、循环音的对照方案；本轮未调用，不能据此断言比现有小样好。
- [Freesound](https://freesound.org/help/faq/)：适合补充真实溪流、鸟鸣、风与器物录音；逐条核对授权，优先 CC0，CC BY 留署名，商业发布不选 CC BY-NC。
- [Sonniss GameAudioGDC](https://sonniss.com/gameaudiogdc/)：[当前许可](https://sonniss.com/gdc-bundle-license/)允许嵌入游戏等作品，不能作为独立素材库转售或再分发，也禁止用于训练或增强 AI 技术。适合筛选脚步、布料、器物、战斗细节；本轮没有下载大型合集。

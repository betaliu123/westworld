# 世界交互反馈检查

|入口/动作|反馈处理|
|---|---|
|背包、快捷栏拖药到茶壶/杯/包子|同一 poisonItem 判定，fieldCheck 真实骰值→右下演出；成功/失败与目击分别表述；药粉只消耗一次|
|蹲行点击 NPC 扒窃|同一 check 输出演出；失败目标喊话，成功主角自语|
|偷摊上食物|同一 check 输出演出；仅真实目击者反应，失败无人见只表示失手|
|暗中放入行囊|同一 check 输出演出；失败 NPC 抗议，成功后保留延迟发现冒泡|
|购买|不掷骰；摊主近处回应，交易结果入日志|
|送物/出示|保留真实转移；新增具体送物原因记录；拒收时附近清醒 NPC 冒泡，取消/无效/太远不让 NPC 凭空开口|
|点穴|现有真实结果检定；补成功受制/失败抗议对白|
|破坏/攻击/动过吃喝|同一目击事件近处两人以内喊话；连续事件抑制刷屏，死亡/被点住者不目击|
|进食/喝茶/治疗/放下/拾取/摇树/泼水/火攻|保留场景动作与本地结果；不等待 AI；远处台词过滤不再吞掉玩家操作日志|
|发现被塞物品/吃喝中毒|已有本地 NPC 反馈直接播放，未知原因不能指认玩家|

所有冒泡在检定结束后才开始计时；日程闲话不抢占行动反馈。隐蔽成功时仅近距离（1.6）正面且无遮挡的观察者能识别；未看到的无声动作不触发隔墙调查。检定特效音效服从声音开关。

回归：检定精确一次、近处目击成功、远处/背对隐蔽成功、失败未消耗、无效请求不掷骰、购买不检定、放入行囊真检定、目击原因入行动记录。

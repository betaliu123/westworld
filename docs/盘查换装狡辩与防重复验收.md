# 盘查换装狡辩与防重复验收

日期：2026-11-11。

## 修复内容

原实现把“配合核对”和“告辞”都记成 `success: true`，并覆盖之前失败的疑点、给予与说服成功相同的冷却；所有现场又使用固定的衣着面貌质疑与选项。

- 有目击证言、已听闻的身份传闻或上次失败疑点时，第二项改为有真实检定的“狡辩：不是我，你们认错人了”。当前真实衣物与收到的衣着描述不同，则改为“狡辩：衣着都不同，你认错人了”。
- 官差按掌握的事实分别质疑面貌、衣着或旧疑点。衣物不符而面貌仍相符时，明确说“衣裳与报案说的不同，可这面貌仍有几分相似”。没有收到证言的官差不能引用它。
- 换装狡辩在统一风仪／易容检定中获得衣着不符的 12 点情境修正，其他面貌、传闻与旧疑点仍计入；预览与执行共用公式。真实示例中，普通解释 16%，指出衣着不符的狡辩 28%。
- 无具体指认时保留普通配合询问；配合和告辞只记录表态，不产生成功检定，不清除旧疑点，不消除证据、通缉或缩短调查。
- 按案件、官差、实际面貌、衣着描述和该官差收到的证言记录已答情况。同一条件答过后不重新弹问、不再掷骰；同款衣物的新实体、重新敷同一面貌、读档都不重置。条件真正变化后仍受原有短暂冷却约束，新的证言可触发后续问话。
- 旧存档按原有面貌序号记录的冷却和失败疑点继续生效，读取预览不修改存档。失败记录在之后的配合或告辞中保留。
- 完整表现为：官差质疑 → 选项与概率 → 统一检定效果 → 玩家实际否认 → 官差按结果回应。取消、重复开菜单不掷骰，菜单期间换装或切换存档会中止旧选项。

## 验证

- 全套测试：685 项通过，0 失败；语法检查通过。补充对白上下文后，相关 24 项回归再次通过。
- 新增 9 项回归覆盖换装收益与预览一致、仅按所知证言判断、配合／告辞不能洗掉失败、重复和读档防重、换回同款衣物、相同面貌重新易容、不同官差知识、新证言、旧档兼容与对白检定事件。
- 独立试玩 `playtest=lasso-qa`，不操作正式玩家存档。三档 1280×850、1024×768、800×600 验证新选项、概率、官差前句与关闭入口；小窗口选项区可滚动。
- 浏览器实际点击第二项：成功与失败各执行一次，观察到主角“不是我，认错人了”和不同官差回应。失败后追问面貌疑点，调查延长至 03:00；再次触发本案均未打开新的回应、掷骰计数保持 1。
- 试玩记录游戏错误 0；控制台仅见浏览器扩展自身错误。未新增 HUD 容器、字体、图标或配音资产；有指认时撤下旧“留下说法，配合核对”入口，使用当前证据对应的短回应。

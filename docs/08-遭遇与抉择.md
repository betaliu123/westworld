# 08 · 遭遇与抉择

## 负责什么

把"故事树的抉择节点"从"定点投放"改成 **NPC 主动来找你** 的统一遭遇管线：选角 → 召唤 → ❗标记 → 交互 → 中央弹窗（世界暂停）→ 抉择 → 结算。

## 关键文件

- `encounter/EncounterRuntime.js` —— 六阶段状态机
- `ui/EncounterUI.js` —— 中央强决策弹窗（逐句推进 + 数字键选项）
- `config/venueAffinity.js` —— 16 场所 × 职业亲和度（选角用）
- `encounter/SubdueSystem.js` —— 处置伤者（共用弹窗）

## 六阶段

`IDLE → SUMMONING → READY → ENGAGED → DONE → IDLE`

- **选角**：两级 —— 规则预筛（场所亲和度 + 距离≤45m + 可用性）→ top3，再 LLM 定选 + 合理性判定（判 false 不投放）→ 降级取规则第一名
- **召唤**：`takeOver` 把 NPC 叫到玩家侧前方 2m，14s 到位超时
- **❗标记**：头顶挂感叹号，走近按 F
- **弹窗**：世界暂停（`anyModalOpen` 含 encounterUI）

## 中央弹窗

- 多段台词逐句推进（点击/空格/回车）→ 最后一句才出选项
- 数字键 1~4 选择，选项按风险配色（低=绿/中=黄/高=红）
- Esc = 稍后再说
- 捕获阶段监听键盘，抢在游戏热键前

## 触发入口

- **故事树抉择节点**：`requestStoryEncounter(storyId, nodeId)`（`deliveryPlanner` 投放时）
- **调试**：`Ctrl+Shift+D` → 👥 遭遇/抉择 → 🎬 触发一场遭遇

## 结算

`applyEncounterOutcome` 统一出口，直接写 economy/reputation/factionSystem（不经金钱镜像）。支持 cash/honor/wanted/affinity/pillar/recruit/toast。

## 处置伤者

伏地重伤者按 F → 弹窗：收服 / 搜身 / 补刀 / 放走（共用 EncounterUI，各自带 onChoice）。

## 配置修改

场所亲和度：`config/venueAffinity.js`；遭遇文案/选项：调用处（main.js / storyData.js）。

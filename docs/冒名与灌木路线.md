# 灌木与冒名路线
门外茶棚西侧增加低矮灌木及遮挡。毒食使 NPC 腹痛 90 秒并前往独立位置，近处捂腹、蹲伏；危险与战斗优先于方便。锦衣客、赵行商遵循相同规则。

Z 蹲行后点选目标行囊。清醒者不可被直接扒衣；点穴制住（30 秒）或击倒后，衣物、钱袋与真实携带物可以逐件搜取，不复制物品，旁人仍可目击。背包选择衣物可穿脱；原主改为素色内衣，主角衣色跟随外袍。目前是粗模衣着乔装，不复制脸部与身高。

穿衣不授予姓名、势力职位或人物情报。赵成的自我介绍/实际路引、锦衣客已透露的化名分别提供知识。刻字人增加有检定的身份名帖选项，未知姓名难度更高；名帖不能代替官印。关口增加冒名检定，与原来的差役服、公文、路引路线并存。

城内近处且视线畅通的捕快会抽查，使用风仪、姓名知识、名帖与累计穿着暴露时间判定。首次留出 15 秒，之后间隔 35 秒；失败解除冒名并增加嫌疑。脱穿不清除衣物累计暴露。正式入职身份不随衣服转移。

验证：现有自动测试及新增衣物一次转移、姓名不泄漏、生病分散目的地、巡查失败、装备转移测试。实景独立预览验证锦衣客与赵行商至灌木均有可行路径，不读取/覆盖玩家存档。

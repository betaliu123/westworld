# 临溪对白与心声改写稿

> 后续修订：玩家反馈本轮台词压缩过度、不像日常说话。现已按 [文风规范](文风规范.md) 取消“心声十五字”等硬限制，并补全人物对白的对象、缘由与语气。下文短句保留为旧审阅稿，不再作为长度范本；当前台词以代码和后续验收记录为准。

> 2026-11-12 执行更新：本稿已获确认并进入游戏实现。具体改动、配音与实玩结果见 [落地验收记录](qa/2026-11-12-对白心声改写落地.md)。下文保留原审阅稿，因此“仅提交文档／拟补表现”等为当时状态，实际完成范围以验收记录为准。

**日期：2026-11-12｜版本：审阅稿 1｜适用：花石纲新章 v2**

本稿落实两项修改：让人物从自身处境说话、让玩家通过现场发现门路；减少交谈入口层级，让提议在同一轮得到回应。增加的细节以小动作、视线、停顿和短心声为主，不把一句说明扩成三段说明。

**本次仅提交文档。游戏代码、判定、物品、存档及配音均未修改。** 旧录音不限制新台词；稿件通过后再按新文本生成对应录音。上一轮举例中的“救役夫后受托传话给青禾”不是本次新增剧情，本稿沿用已有的差费、担保、师承、副账等内容。

建议先看第三节的关口、茶棚、衣架三场，再看第四节的城内续写。文末附现有内容来源和后续落地边界。

## 一、这次改成什么样

玩家先看见一件值得留意的事，听见人物对此的态度，自己把两者联系起来。必要时，主角心里轻轻点一下。

例如，原来是：

> 守卫：有路引报姓名，有差服报差事；有人肯作保也行。花石纲的役夫随队过关。

改成在不同现场逐步得到：

> 守卫：路引展开。叫什么？
>
> 补衣人：六文。袖口刚补过。
>
> 主角心声：（和关上那身衣裳一个样。）
>
> 周大石：人手够了。纲货出了错，谁担着？

这几句话不是连续播放的过场。玩家到哪里、做了什么，才有相应的发现；也可以没听过任何一句，就直接取衣、换装、找守卫。

### 1. 四种文字各做一件事

| 层次 | 承担什么 | 本稿写法 |
| --- | --- | --- |
| 现场细节 | 提供可以被观察的依据 | 守卫看衣领；补衣人护住针线；行商把路引收回左襟 |
| NPC 对白 | 说明要求、顾虑、欲望、回应 | “放你进去，出了事算谁的？” |
| 主角心声 | 对眼前事实作短推测，提示一个关注点 | “（他怕担这个责任。）” |
| 操作与见闻 | 给清楚的按钮、实际代价和已知信息 | “穿戴”；金钱 6 文；“赵成自称东溪人，韩校尉认得他” |

心声不播语音、不做开口动作、不让 NPC 接话。每条不超过十五字，用全角括号。操作键、成功率、物品数量留在操作界面；不能为了文雅把风险藏起来。

### 2. 文稿标记

- **现有规则**：在当前工作区代码中找到对应入口或结算；不代表其场景演出已经验收。
- **拟补表现**：本稿建议增加的动作、停顿、表情或物件细节，不得写成现已实现。
- **需接事实**：拆分对白后，需要分别记录玩家听见、看见或读过的内容；不能只换字而沿用一口气揭晓全部信息的旧标记。
- **条件句**：只有前提成立才能使用；同一场不把所有条件句轮播一遍。

文中角色姓名是制作标注。游戏内仍用玩家已知姓名；尚未相识、未识破的身份不提前显示。

## 二、交谈入口怎样变短

### 1. 保留人物入口，展开后直接看见具体话头

目前常见路径：

> 与周伍长对话 → 交谈 → 方才为何关城门？ → 听一句规则总览。

建议路径：

> 与周伍长对话 → “今日为何封关？” → 周伍长立即回答。

第一次点人物，仍在探索镜头下打开紧凑的二级菜单，不自动替玩家问话。菜单中直接列当前最有用的具体话头；“出示”等通用行动保留独立图标和中文说明。点实际问话后才切到说话人；纯问话不插入动作等待、检定或成功卡。

以无凭据、未听封关原因的玩家为例：

| 展开后的位置 | 内容 |
| --- | --- |
| 具体话头一 | 今日为何封关？ |
| 具体话头二 | 没带路引，能通融么？ |
| 具体话头三 | 你这持刀架势，能让我瞧瞧么？（已有观摩入口时） |
| 物品行动 | 出示图标；仍须选物并确认 |
| 退出 | 关闭图标、Esc、走远 |

有凭据时，相关出示行动前置；已有有效担保提议时，前置“随你进关／这回不劳烦”。不再让玩家从“交谈”里寻找正在发生的事。

### 2. 超过三句，按具体内容折叠

- 每层最多三句纯交谈选项。退出不强占一个对白选项，保留显式关闭；报价和邀约必须另有明确“不买／不答应”。
- 需要折叠时用“关口的盘查”“方才的手法”“那包伤药”等具体话题，不用“打听正事”“聊聊别的”“还有何事”。
- 选话题只展开选项，不播放“你说”，不切镜头、不掷骰、不扣资源。
- 人物已经谈完的事撤下；改变穿戴、拿来物件、发生余波等真实变化，再打开对应话头。已知内容可在见闻中重看。
- 没有新话时收起交谈内容，仍保留有效的出示、送物等行动，不放一个空的“继续”。

### 3. “新鲜事”不再固定占第一项

优先顺序为：正在质问或求助的事 → 尚未答复的提议 → 玩家手中相关物件 → 眼前冲突 → 具体人物话题。

只有人物确有一条未听过、且其本人有理由知道的消息，才出现问消息的选项。标题不能提前泄露消息内容：玩家只看见茶娘望向关口，就只能问“你在看门口？”；听她提到锦衣客以后，才可以问“那位客人常来？”

### 4. 提议必须在原地接上

> 补衣人：六文。袖口刚补过。
>
> 同轮：**付六文买下／这身先不买。**

> 锦衣客：我可以替你作保。这份情，你可记得？
>
> 同轮：**记得，劳烦了／这回不劳烦。**

听见报价、问清内容、打开行囊都不结算。确认时重查真实条件；取消、换人、走远不能执行上一段的交付。涉及挑选物品时，选物是同一段对话内的必要步骤，不要求退出后重新问候。

## 三、关外逐场改写

### 01｜关口：他守的是责任

**现有依据**：封关冒泡、`gate_rules`、`g_plead`、凭据与差服应答。

**现有原句节选**：

> 应奉局的花石纲要过关。路引对姓名，认得本人的更不能冒名。没凭据，随役夫队过关，或请人作保。

**拟补表现**：当值守卫把身体挡在通道一侧，目光先落在玩家手上。另一人若正在接岗，就先完成实际交接；不为说一句台词凭空换岗。

#### A. 封关现场

只在花石纲实际占用关口、玩家可见可闻时，由在场且能开口的值守者说一次：

> 韩校尉：退开。黄旗先过。

周伍长值守时换为：

> 周伍长：让开车道。花石纲先行。

如果车队未在此处或已停止通行，改用“今日查验，路引备好”，不制造一支不存在的过关队伍。

此刻不跟心声。先让玩家看清自己为什么被挡住。

#### B. 玩家主动问封关原因

**玩家可选**：今日为何封关？

> 韩校尉：应奉局押纲，关上须查得紧些。
>
> 周伍长替代句：上头押着花石纲。今日查得紧。

若玩家尚无凭据，应答后原地保留：

- 没带路引，能通融么？
- 我先去别处看看。

第二项只结束此段，不自动行走。没有未答事项就结束，不补一句“还有何事”。

**玩家选通融**：

> 韩校尉：放你进去，出了事算谁的？
>
> 周伍长替代句：没凭据，我担不起。先退到边上。

探索恢复后，在没有其他更紧急反馈时可出一次心声：

> （他怕担这个责任。）

这是对语气的推测，不解锁“锦衣客担保”或所有入城路线。

#### C. 玩家已经听说有人担保

选项才出现：**若有人替我作保呢？**

> 当值守卫：让作保的人当面来。

这句只说明手续。不能提前写出“锦衣客有权担保”，也不让点击问话直接完成入城。

#### D. 先拿凭据、后见守卫

打开二级菜单便能选凭据，不要求补问封关原因。

> 当值守卫：路引展开。叫什么？

姓名已知时可选：**赵成，东溪人。**

姓名未知时只显示冒险应答的真实能力、成功率及风险，不在选项里赠送正确姓名。

| 实际结果 | 守卫台词 | 可选心声 |
| --- | --- | --- |
| 验认放行 | 名字对上了。收好，进去。 | （借来的名字，还得记牢。） |
| 姓名答不上 | 自己的名字，也要想这么久？ | 不补心声，留空间给盘问 |
| 守卫熟识赵成，面貌不符 | 赵成我认得。你是谁？ | 无 |
| 守卫已收到报失 | 这张路引已报失。哪里来的？ | 无 |
| 原主在场，能正常开口并当面认出 | 赵成：我的路引，怎在你手里？ | 无 |

最后一行不是“原主在附近”就必播。被绑、哑穴、睡眠、重伤或其他无法主动揭穿的状态不能开口；原主位置被别的证据确认时，按实际证据另写。

**必须保留**：确定放行或确定识破按事实表达，不加假骰子悬念。未知身份、谣传与亲眼认人仍分别处理。

### 02｜茶棚：她在做生意，也在护住自己的人

**现有依据**：宋家两文差费、茶食交易、门路线索、女儿青禾的故事。

**现有原句节选**：

> 两文差费总算交清了。劳你替我们挡这一回，青禾的去留，我们还得自己想明白。

**拟补表现**：茶娘把一只空碗归到桌沿，话说到应奉局时，手停一下。只用现有茶棚和茶具即可；不以长篇旁白代替动作。

#### A. 初次靠近

有茶食在售、茶娘不在危险或忙于急事时，可有一次短招呼：

> 宋茶娘：吃口热的么？

不是强制对白。玩家直接选人物，初始话头来自眼前事实：

- 沏一盏茶。（价格、库存照当前商品）
- 今日生意可还做得？
- 方才催你什么？（仅已亲耳听见催缴）

玩家选“今日生意可还做得”：

> 宋茶娘：茶还卖着，差费倒先催上了。

此句需茶娘实际还有未处理的差费。听完直接接“什么差费？”或告辞，不跳回“新鲜事”。

#### B. 差费提议

**玩家**：什么差费？

> 宋茶娘：应奉局催的，两文。茶棚也躲不过。

一小段停顿后，在同轮给出：

- 这两文，我替你垫上。〔金钱 2 文〕
- 我身上也紧，帮不上。

已经知道差费的玩家再来，可以直接选垫付；“听过说明”不是付款能力的锁。

确认付款、钱已放下但尚未被收取时：

> 宋茶娘：劳你破费了。

只有差费已真实结清，才可以接：

> 宋茶娘：这笔算清了。多谢你。

明确拒绝时：

> 宋茶娘：赶路也要盘缠，我知道。

不自动扣好感、不让她阴阳怪气地催玩家行善。确有现成的负面关系时另走对应回应。

**制作边界**：当前差费入口已有放钱和援助标记，但不能仅凭标记写“符祥已收钱”。付款、收取、关系反馈须按同一实际时序衔接；本稿不预先许诺即时到账。

#### C. 青禾的话，只说到她知道的地方

玩家只有已听茶娘提到女儿、已见有关名册内容，或得到明确介绍时，才出现相关问题。未见过名册，不能问“为何册上有青禾”。

**玩家**：你担心的是青禾？

> 宋茶娘：她想往京里去。我却怕她走远。

**玩家可接**：她自己怎么说？

> 宋茶娘：你见着她，听她自己说吧。

可选心声：

> （这话，还得问问她。）

这条建议补为母女话题的自然接话，不增加“已替她作决定”的状态。若茶娘尚不知道女儿的志向，第一句改为“应奉局惦记着她。我放不下心”，不能读女儿的心。

#### D. 门路信息不打包倒出来

按茶娘掌握且尚未说过的事实，每次选择一条，给到明确对象即可：

| 玩家已有的观察或问题 | 茶娘说的话 | 主角可选心声 |
| --- | --- | --- |
| 看见茶娘留意仍在场的锦衣客，问“那位客人常来？” | 不常来。关上的人倒肯听他说话。 | （不妨听听他怎么说。） |
| 主动问驿舍；衣服仍在架上可交易 | 补衣人在后头。那身皂衣刚补好。 | 无，留玩家自己看衣架 |
| 主动问纲队；车队仍可接洽 | 随车的人归周大石管。我替他应不得。 | 无 |
| 玩家身上已经穿着差役服 | 衣裳齐整。你是来接差的？ | （她先认了这身衣裳。） |

末行只发生于茶娘亲眼看见穿戴、不知玩家是假扮时。如果她已目击偷衣或识破，就用对应质疑，不能突然忘记。

**反向顺序**：先偷到衣服再来，不再发“去衣架找差服”；若玩家主动追问差事，则仅提供当前已成立的差事情报。新章未接入的“公文催三回加成”不在稿中假装可用。

### 03｜衣架与补衣人：衣服是货，名字是另一回事

**现有依据**：衣架可独立购买／偷取；六文；收进行囊与穿戴分开；问领口得知陈小乙。

**原文冲突**：有的台词称衣服“寄补、要交还”，实际又允许补衣人出售。本稿按现有可买规则统一为“可出售的旧差服”，不新增替别人卖寄存物的情节。实物原主与转移履历另保留，不凭改词改归属。

#### A. 不交谈也看得见

**拟补表现**：衣架上的差服展开挂着，袖口的补线比旧布稍浅；补衣人在一旁穿针。领口只有近看才能辨出的旧字痕，不从远处浮出姓名。

第一次看清衣服，且此前见过关上同类衣服时：

> （和关上那身衣裳一个样。）

没看过关口衣着时不说“和关上相同”，可只用：

> （袖口是新补的。）

玩家可以按现有通用操作取衣。看过心声、先问补衣人都不是必要条件。

#### B. 询价与买下

**玩家**：这身旧衣，卖么？

> 补衣人：六文。袖口刚补过。

原地接：

- 付六文买下。
- 这身先不买。

购买成功才说：

> 补衣人：收好。补线别使劲扯。

拿到但尚未穿上：

> （衣服到手，还没穿上。）

只在玩家确实需要此提示、且穿戴引导尚未出现时显示一次，并在装扮按钮旁给“穿戴”提示。已有穿戴操作不再用对话菜单做第二套。

拒绝时：

> 补衣人：成，我先收着。

不收钱，不挪走衣服制造限时恐慌。

#### C. 问姓名

**前提**：玩家已近看领口、取得衣服后查看，或从可靠介绍知道领口有字。

**玩家**：领口这几个字，怎么念？

> 补衣人：陈小乙。原先替驿站跑腿的。

心声可选：

> （衣裳旧了，名字还在。）

听完才记录姓名。穿衣、持有衣服、远看模型均不自动学会“陈小乙”。若玩家已从瘸张得知姓名，不重复这段问答。

补衣人亲眼见过偷取，玩家又拿这件衣服来问：

> 补衣人：先说这衣服，怎么到了你手里？

接现有来历、归还或冲突处理，不提供若无其事的服务。只看到玩家穿旧差衣、并无识别或目击证据时，不能直接指控偷窃。

#### D. 穿差役服首次见守卫

> 当值守卫：县里的？报个名。

已知姓名才出现：**陈小乙。**

已掌握真实差事情报时，可把它并入玩家这一句应答；未知时不能选出准确的公文名目。未穿衣服时不出现“以差役应答”，背包里有衣服也不算。

| 结果 | 对白 |
| --- | --- |
| 当前事实允许放行 | 陈小乙，进去。别误了差事。 |
| 身份信息不足，实际盘问未过 | 来历说不清，先别往里走。 |
| 具体矛盾已被发现 | 使用对应矛盾的质疑，不能统一说“衣服不像” |

**边界**：这次不恢复 v1 的公文奖励、假名梁远和两文脚钱。现有 v2 检查不读取“县衙三催”作为加成；若日后要让差事知识影响判定，必须另行设计同一套预览与结算。

### 04｜赵行商：他说自己，不替玩家选目标

**现有依据**：实际路引、已知姓名、韩校尉熟识赵成、丢失与报失状态、偷窃目击。

#### A. 现场细节

**拟补表现**：只有路引仍在赵行商身上时，他在经过守卫附近或整理衣襟时摸一下左襟。不是每隔几秒机械摸一遍。

> 赵行商：货可别碰。绳结还没收紧。

这句只在现场有他的货、确有收绳动作时使用。普通初见不凭空追加买饼、久等、明早出城等经历。

玩家看清他在保护一件东西：

> （他护着左襟。）

这时只引起注意，不直接得知里面是路引；探查仍走现有规则。

#### B. 问名字

若货上“赵”字已经能被看见：**货上这个赵字，是您的姓？**

没有可见字样则用：**敢问怎么称呼？**

> 赵行商：赵成。东溪来的。

同轮可问：**常走这道关？**

> 赵行商：韩校尉认得我。今日也没放松查。

心声：

> （韩校尉认得他的脸。）

姓名与“韩校尉认得他”分开记录；只听第一句不能得到第二项。换了值守者，也不能据此推断新值守者一定不认得他。

#### C. 拿到路引后的提示

偷取成功不等于读过凭据。先给真实物品反馈；查看内容后，才显示可读内容。若当前道具仅支持“他人的路引”而没有读名入口，本稿不凭心声补姓名。

- 已得姓名、原主没发现、还未过关：（纸能借，脸却借不了。）
- 路引丢失已被玩家亲眼看到或听到：（他开始找了。）
- 已亲耳听见报失：（这张路引留不得久。）

第三句表示处境，不提示“赶在某秒前必成功”，也不抹掉已经生效的报失。

### 05｜周大石：名额关系到他的差事

**现有依据**：初次拒招；六文通融、实际搬石、按当前外观开放的说情；同意后穿挑夫装束随队过关。

**拟补表现**：周大石先看一眼货车，再看玩家的肩背。货车或试力石不存在、损坏时，不做对应动作。

**玩家**：还缺抬箱的人么？

> 周大石：人手够了。纲货出了错，谁担着？

原地列出当前有效的既有做法，不退出再找：

- 六文茶钱，劳你通融。〔金钱 6 文〕
- 让我搬这块石头试试。〔真实能力、成功率、难度及体力代价〕
- 周大哥，替我留个位置可好？〔仅现有说情条件成立时〕

玩家可以关闭离开；这里是拒招后的商量，不是必须另外占一个“拒绝招募”的选项。

**选试力**：

> 周大石：搬起来，再放稳。别伤了腰。

真实完成动作并成功：

> 周大石：行，算你一个。换好短褂跟上。

实际失败：

> 周大石：放稳。眼下这份活，你还扛不住。

动作中断不给名额，也不说成功句。成功只发一次现有短褂；此前已持有的有效衣服继续有效。

**已获同意、尚未穿对衣服**：

> 周大石：这身不便上工。短褂穿好了再来。

心声只在第一次需要时：

> （衣服在包里，还没换。）

只在包里确有短褂时用；没有时不说。相关物品直接在装扮里可用。

**已经穿好挑夫装束、首次来谈**：

> 周大石：衣裳倒齐整。谁让你跟这班的？

仍可原地走现有通融、试力等方式。不退回换衣引导，不增加先接任务或等时辰的条件。

**已获同意且可以动身**：

- 跟这班进关。
- 我还有点事，稍后来。

确认后才进入现有随车过程。危险、缺货封车、押运者未到场分别说当前原因；不把“稍后来”当拒绝后永久封路。

**现有边界**：当前实现是取得周大石同意后随队，不是任意穿短褂便必过。稿件不把现实规则润色成更宽的承诺。说情的开放条件本次不改；台词不增加性暗示，也不把服饰风格写成犯罪理由。

### 06｜锦衣客：话里留分寸，担保要讲清

**现有依据**：亲眼见过善意且未见过伤害等条件；担保债；入城后追问；副账委托和引荐玉符。

旧问候说“挑柴的被翻三遍担子、轿子径直进城”，当前不能仅靠固定录音证明这些事发生过。本稿取消这类没有现场依据的过去式。

#### A. 初见

玩家主动问：**阁下也在等进城？**

> 锦衣客：坐着，也能看见些事。

**拟补表现**：他说完才把视线从关口收回。若此刻已离开茶棚，则不用这条台词。

同轮可接：

- 方才关口的事，你怎么看？〔玩家确实见过，且他也有视线〕
- 敢问如何称呼？〔自我介绍信息需接入已知身份，不提前泄露宗室〕

自我介绍建议：

> 锦衣客：姓赵，闲舟。出门用这个名字。

如果暂不接新的姓名知识节点，保留“锦衣客”的称呼，删掉这一问，不用字幕单方面揭名。

#### B. 担保由具体旧事接上

亲眼看见玩家垫差费的版本：

> 锦衣客：方才那两文，我看见了。
>
> 锦衣客：若还进不了关，我替你作保。

亲自受过照看的版本：

> 锦衣客：方才劳你照看。
>
> 锦衣客：若还进不了关，我替你作保。

不给没看见的旁人补记忆；没有照看也不说“劳你照看”。两种原因不叠播。

同轮先把条件说清：

> 锦衣客：这份情，你可记得？

玩家选择：

- 记得，劳烦了。
- 人情要怎么还？
- 这回不劳烦。

追问时：

> 锦衣客：我有事相托，你再听听。不是卖身契。

继续只留接受与拒绝。担保执行成功才记人情；不能在听见提议时就把玩家送进城。

拒绝：

> 锦衣客：也好。路由你自己走。

接受并真实完成担保以后，探索时可有：

> （门开了，人情留下了。）

**拟补表现边界**：锦衣客起身、走到值守者面前、守卫让路，是建议补足的演出。当前担保规则可结算，不等于这些动作已完成。

#### C. 入城后不问他已经知道的事

| 入城事实 | 重逢第一句 |
| --- | --- |
| 他本人担保 | 进来便好。关外那份情，先记着。 |
| 他确曾看见玩家破门 | 门是砍开了。后头的事，想过么？ |
| 他不知玩家用何方式 | 你也进来了。关上没再拦你？ |

只有第三种情况才有“如实说门路／隐瞒”等选择。不能本人刚作保，转身又问玩家怎么进来的。

不同入城路线的表述仍只根据他的实际知识，不因角色内部状态知道水路、易容或盗窃。

### 07｜杜老捕与瘸张：让提示成为人与人的往来

#### A. 杜老捕的药和手法

**现有依据**：观摩、托存的伤药、送回、实际跟练。保留现有条件，不用一句交谈直接升档。

玩家选择观摩时：

> 杜老捕：看这里。不是戳，是送。

**拟补表现**：在现有练习目标上演示手指接触和收力；只在演示真的发生后，才说以下接话。

> 杜老捕：驿舍存着一包伤药。替我取来，可好？

同轮：

- 我替你取。
- 眼下走不开。

答应不发药。玩家此前已实际拿着同一包药，则直接出现“这包伤药，可是你要的？”，不让去驿舍重取。

补衣人交药时：

> 补衣人：杜老捕存下的。封口别弄散。

真实交回杜老捕后：

> 杜老捕：药送到了。来，试试方才那一手。

同轮给“跟着练／稍后再练”，前者启动身体练习。拿到药、还药、听讲均不等于已经学会。

学成后的可选心声：

> （要认准，不是使蛮力。）

按钮旁另给实际用途引导。以后回来只保留有效回访与练习入口，不重复托药、赠物或教学奖励。

#### B. 瘸张卖消息

**现有依据**：一份干粮换一条未买过的消息；四类已有内容。

> 瘸张：有吃的么？换你一句有用的话。

原地显示至多三项，其他按具体话题分支展开，不假装四项一起塞满。

| 购买内容 | 改写台词 | 保留的信息边界 |
| --- | --- | --- |
| 水门 | 西边水门第三块板，早朽了。水可不浅。 | 得到朽板情报，不获得破坏或游水能力 |
| 行商 | 赵成，东溪人。路引收在左襟。 | 只记这些具体信息，不保证冒名可过 |
| 驿舍 | 那身旧皂衣，领里缝着陈小乙。 | 得知姓名，不得到衣服，也不自动穿上 |
| 纲队 | 周大石管着名额。肯不肯添人，问他。 | 得知接洽对象，不得到入队同意 |

选择“拿干粮换这条消息”即为明确购买确认，按现有真实物品处理。报价可用“干粮 1 份”图标数字；人物不用读数字标签。

已买过的消息去见闻重看，不重复扣粮；钱粮不足明确显示，不用“机缘未到”掩盖缺什么。

### 08｜水门与刻字摊：让玩家自己拼起来

#### A. 水门

**拟补表现**：朽板有与其他木板不同的缺损，水流从缺口过去；只有模型和碰撞实际支持，才表现相应变化。

未听情报、第一次近看且可辨朽处：

> （这块木头糟了。）

听过瘸张消息、实际找到对应位置：

> （他说的是这一块。）

踩入危险深水、尚可自行退出时：

> （水比看着深。）

都不代替移动、攻击与生存规则。破坏后真实能通行才提示新通路；没有目击者就不让远处守卫喊“就是你”。

#### B. 刻字人

> 刻字人：刻字，还是修印？

初见只给普通业务和现有可购货品，不主动报出“我是无相门，可以卖毒”。

玩家已探查到有效针囊证据，才出现：**袖里那副针囊，我见过。**

> 刻字人：眼睛倒尖。话轻些。

原地接具体问题，按已有解锁：

- 这手改扮的本事，肯教么？
- 柜里那包散，怎么卖？
- 我不多问。

迷毒散仍有库存才报：

> 刻字人：五文。收好了，别混进伤药。

同轮给“买一包／不买”。成功购买后：

> 刻字人：东西给你。用在哪儿，你自己担着。

不再教玩家去污染茶娘的茶壶、认准某人的包子或别被看见。物品用途在物品说明和实际操作上明确呈现。

易容膏购买后：

> 刻字人：照着见过的脸敷。过些时辰便褪。

若玩家又问“这便能认作那人？”：

> 刻字人：脸像，话可未必像。

心声可选：

> （还得知道该怎么应话。）

使用时长写实际值，不让含糊的口语替代数值。衣物、面貌、姓名、证件继续分别判断。未学会对应能力时，购买材料不被写成已经学会易容。

## 四、城内已有内容的同尺度改写

以下把同一写法延伸到已有的关键交谈，供一并审阅；不新增上一轮举例中的任务链。

### 09｜宋青禾：问她，不替她回答

**现有依据**：自己的进京意愿、出示押运名册、同意顶替与赴艮岳的分支。

没有任何相关知识的初见，不能直接问“你想随花石纲进京？”；可通过已经存在的相识场景或人物介绍进入。这里给出取得话题后的正文。

**玩家**：你娘很挂心你。〔仅茶娘确实表达过〕

> 宋青禾：我知道。可京里的曲子，我想亲耳听。

**玩家可接**：

- 你想自己去？
- 我只是替她捎句话。〔仅确有托话，不因听她担忧就算受托〕
- 不说这个了。

第一项：

> 宋青禾：是。别替我答应，也别替我回绝。

心声：

> （她有自己的打算。）

**已有名册但没读**：选项“请她看这册子”，打开前不提里面有她的名字。

她实际翻看到自己姓名时：

> 宋青禾：这里有我的名字。
>
> 宋青禾：写上去，也该先问过我。

同轮可问“你还愿去么？”，或收回名册。出示与交付分开，浏览后不会把名册永久交给她。

**顶替提议**：只在双方相关信息已谈清、允许讨论的事实条件成立时出现。意愿未成立：

> 宋青禾：这是我的路。我还没说要让。

已有真实同意时：

> 宋青禾：这件事，我答应。举止还得学稳。

立刻接现有跟练或暂缓；只有完成教学才说“教过你了”。本稿不把当前“出示后即可同意”的粗略结算，宣称为已经完整实现的同意过程。后续须把“不愿／再想想／同意”的依据写清，再对接此组台词。

### 10｜桥头：银戒的归属和苏晚的意愿分开说

**现有依据**：归还银戒须验来历、劝沈砚让路、苏晚的心愿与授艺。

**拟补表现**：苏晚身体朝向可离开的方向；沈砚如果实际挡路，站位要真让出通道，不能只说“桥让开了”。

> 苏晚：我要过去。让一让。

玩家选“她想走，先把路让开”：

> 沈砚：……好。你走你的。

保留原有真实关系结算。若苏晚已离开或这里本就没有挡路，撤下这段，不凭空演一场冲突。

**持有银戒时**，“给沈砚看银戒”可直接出现在相关行动里，不先问新鲜事。

> 沈砚：是我的。你从哪里得来的？

按真实获得经过给回应；不能所有来路都说“路上捡的”。明确确认归还后才转移，一次即可。

> 沈砚：收回来了。多谢。

这里不补“她一定会回心转意”。若玩家亲耳听过苏晚拒绝，归还后可有：

> （还了戒指，不算答应亲事。）

**玩家问苏晚**：往后想去哪里？

> 苏晚：有地方唱自己的曲子，就去。

听过、帮她保留选择且当前授艺条件成立后：

> 苏晚：想学这段？先听我吹一遍。

同轮接“听她示范／改日再学”。观摩和跟练仍是动作，不用一段纯对白把乐器升档。

### 11｜阿青：药性通过当下的活解释

**现有依据**：研药、救治欠情、药材购买、实作配药。

**拟补表现**：她将待研的药与成药分开放，谈到分量时用手挡住玩家多加的一撮；这个动作只在真实配药步骤中发生。

**未欠救治人情，玩家主动问能否帮忙**：

> 阿青：这碗药还没研好。替我搭把手？

**已欠她一份伤药**：

> 阿青：上回那份药，替我研这一碗便是。

两种前提不混用。原地选择“帮着研药／眼下不便”，确认后才操作药案。

完成研药后：

> 阿青：细了，正好。

真的偿还一份欠情时再补：

> 阿青：上回的药钱，清了。

重复帮忙若没有新欠情，不重播“清了”，也不重复加关系。

可选心声：

> （药要细，分量更要准。）

**药材报价**：

> 阿青：两文一份。药案可以借你。

同轮“买一份／先不买”。买到的是药材；实际配好之后才出现成药，不让对白提前宣布制作成功。

毒性用途保留在已学知识与物品说明中。普通救治时不突然讲一遍下毒教程。

### 12｜旧账房：先听人说，再看账写

**现有依据**：狱中证言、身上原账、取账与献账。只在实际可交谈的情境开放，不用文稿给玩家穿墙取物。

**拟补表现**：有账时，旧账房护住衣襟；账已不在他身上就不做这个动作。对白镜头取栏杆内侧，能看见说话人的脸。

**玩家**：为何关着你？

> 旧账房：账抄了两份，数却不一样。
>
> 旧账房：我多问了一句，就到了这里。

同轮接：

- 不一样的数，记在哪里？
- 你还留着那本账？〔仅已经知道他留账〕
- 我先不问了。

第一项：

> 旧账房：花石纲的副账。我留着原本。

只有账确在他手中才如此说；否则按实际去向回应。

**玩家**：肯给我看看么？

满足现有交付条件时：

> 旧账房：给你。我盼有人肯查。
>
> 旧账房：我说的话，得拿账去对。

同轮“接过原账／先由你留着”。确认后才真实转移。

此刻心声：

> （先看看账里写了什么。）

随后给行囊内真实的“翻阅”入口。没读不能得到账目细节；读过再来不会重复解锁。原来关于四方用途的长段说明，拆成玩家主动追问：

**玩家**：你盼谁接手？

> 旧账房：顾钦差，或那位锦衣客。我盼他们肯查。

只表明他的愿望，不承诺这些人一定能平反。其他方的用途由该方亲口谈，避免囚犯像结局导览员一样一次报齐所有阵营。

### 13｜献账：先听对方要它做什么，再决定交不交

**现有依据**：四方收原账、各自凭书、一次性声望与赴艮岳资格。下列文字不更换奖励、不保证沉冤昭雪，不宣称完整赴京演出已实现。

初始入口直接写：**这本副账，你打算怎么用？**

| 收账人 | 第一轮：自己的目的 | 第二轮：具体提议 |
| --- | --- | --- |
| 锦衣客 | 我想知道，谁把这笔银子改了去处。 | 原账交我封存。荐书给你，赴艮岳查账。 |
| 顾钦差 | 先核经手人，再对这几笔账。 | 原账封存。我出荐书，荐你赴艮岳核账。 |
| 符祥 | 外人拿着这本账，容易惹事。 | 交来吧。给你随纲勘账的帖子。 |
| 林青舟 | 役钱报了全数，人却没领足。〔仅他已核过相应内容〕 | 原账留在会里。给你凭书，赴艮岳核账。 |
| 段赤川／梅掌舵 | 扛货的不能白扛。扣了多少，得算清。 | 账交赤砂堂。赴艮岳核工的名额，给你。 |

对未读、未看过内容的人，不能提前让其说账内确数或具体扣项。林青舟尚未核阅时第一句改为“我想拿这本账，对一对役钱”。其他人也是表达目的，不等于已证明侵吞者。

第一轮和第二轮相连，不要求玩家重新点人。提议后直接两项：

- 交出原账。〔明确写出收件方、实际势力声望变化及所得凭书〕
- 原账我再留一留。

若对方没有看过实体原账，要先通过同一段出示流程确认物品，不让只凭玩家自称就发奖。

**符祥这条额外保留一句代价**，置于确认之前：

> 符祥：旧账房的事，我可没应你。

只有此前已知旧账房和原件关系，才补心声：

> （交出去，他便没了原账。）

这不是不可见的惩罚藏在文艺句子里；确认处仍说明原件交给谁、交后不能向另一方重复记功。

实际交付、发书后：

> 收账人：账收下了。凭书拿好。

紧接“凭书赴艮岳／暂留临溪”，不经“新鲜事”重找入口。角色的后续职责写在该方已有凭书与任务记录里，避免一次塞进感谢词。

## 五、心声的投放规则与可直接使用的短句

心声是可选的轻提示，不是新的自动讲解频道。上文每场列的是候选，不意味着每段对白结束都播放。

### 1. 什么时候说

1. 先有观察、证言、实际取得或结算，再产生心声；心声不创造证据。
2. 同一事实的一条心声档内只播一次。拿取、丢下、重穿、读档不重新刷。
3. 一个现场初次停留最多一条；建议全局至少间隔二十秒。此数是本稿的表现建议，不是现有实现说明。
4. NPC 正在说话、检定、交战、受伤急报、详细面板开启时不争抢空间。高优先级事件打断后重查事实；已过时的句子直接丢弃，不排队补播。
5. 玩家已经在做相关动作，或已成功完成该路线，不再提醒去做。
6. 门路未发现时，不以“你还没试过水路”提醒。可让仍在附近且确实知道情况的人提供合适话题；玩家选择听才记录。
7. 使用现有情境信息区域，不新增独立悬浮框；所有心声静默。

### 2. 条件对照

| 心声 | 必须已发生 | 绝不能顺带得到 |
| --- | --- | --- |
| （他怕担这个责任。） | 亲耳听到守卫对责任的拒绝 | 所有担保人名单 |
| （和关上那身衣裳一个样。） | 看清差衣，并见过关上同类衣着 | 姓名、差事、官职 |
| （衣服到手，还没穿上。） | 持有衣服、尚未穿上、需要首次引导 | 自动穿戴 |
| （衣裳旧了，名字还在。） | 已实际辨认或听清衣领姓名 | 新的职权或路引 |
| （他护着左襟。） | 亲眼看到对应动作 | 包内物品全列表 |
| （韩校尉认得他的脸。） | 听过有来源的熟识信息 | 所有守卫的认人网络 |
| （他开始找了。） | 实际目睹或听见寻找行为 | 偷窃被识破的结果 |
| （门开了，人情留下了。） | 因该人担保实际入城且欠情已记录 | 自动接下后续委托 |
| （这块木头糟了。） | 近看或探查得到朽木事实 | 破坏、通行已经成功 |
| （这话，还得问问她。） | 已听到母亲一方的真实说法 | 青禾的隐藏愿望 |
| （还了戒指，不算答应亲事。） | 实际还戒，且听过苏晚的态度 | 苏晚原谅沈砚或恢复亲密 |
| （先看看账里写了什么。） | 持有原账、尚未翻阅 | 账内内容、犯人身份 |

## 六、任务与见闻一起改，避免对白藏了、日志却全说了

### 1. 任务摘要只陈述已知的下一步

| 当前事实 | 现有问题 | 建议摘要 |
| --- | --- | --- |
| 刚开场 | 固定“先问守卫”，容易被理解为必须先对话 | 关口封着，尚未获准入城。 |
| 只听过封关原因 | 一次写出担保、役夫、水路所有答案 | 花石纲先行，关口正在查验凭据。 |
| 只拿到差役服 | 易混同已经换好身份 | 旧差役服已收进包裹。 |
| 已穿差服，不知姓名 | 要提示缺口，但不赠名字 | 身着差服，尚不知衣领旧名。〔仅已发现领口字迹〕 |
| 已穿差服且知姓名 | “衣服与姓名已对上”可能被误读为保证通过 | 身着差服，已知陈小乙之名。 |
| 已知角色能作保 | 不自动表示对方已经答应 | 可与锦衣客商量担保。 |
| 已知周大石管名额 | 不把先聊任务变成能力门槛 | 周大石管着这班役夫。 |
| 只听旧账房口供 | 不应记成拿到或读过副账 | 旧账房称留有原账，可继续追问。 |
| 已拿原账未读 | 不泄露内容 | 原账在行囊中，尚未翻阅。 |

已听过的路口消息各自保留来源，可主动追踪或取消；不因为把“新鲜事”撤下就丢掉线索。探索 HUD 不常驻展开整份攻略。

### 2. 必须说清的数值仍然说清

六文衣价、两文差费、六文通融、五文迷毒散等按当前实际值展示。所有风险行动的能力、成功率与难度来自实际判定，不手写一个有气氛但不准确的概率。

购买、拒收、已知物品、确定识破不加随机悬念。行动结果用实际增减，不用额外奖励来配合“人物记住你”的台词。

## 八、配音与实现边界

### 1. 旧录音的处理

- 不为复用录音保留不自然或不符合事实的句子。改过台词、人物归属或表演参数都生成新内容哈希。
- 固定人物音色仍沿用 `voice-cast.json`；此稿不建议把人物统一成系统朗读。
- 没改的句子正常复用；旧句不删文件也不能被新字幕调用。
- 心声、旁白、制作备注、数值提示全部静默，不送去配音。
- 每句的前提随台词一起审：尤其是“我看见了”“钱收下了”“我教过你”“你替她说过话”。
- 本次不启动生成。通过后先生成关口、茶棚、衣架的一小批并试听，确认口吻和接话节奏，再扩到城内。

### 2. 不仅换字符串的部分

| 修改 | 后续需要接通的东西 | 本次状态 |
| --- | --- | --- |
| 首层直接出现具体问题 | 现有人物二级菜单、通用行动和对话镜头协调 | 仅方案 |
| 拆开姓名与熟人信息 | 按实际听完的句子分开记忆，取消不视为听完 | 仅方案 |
| 心声的观察依据 | 可见动作、来源事实、档内去重和节流 | 仅方案 |
| 差费的“放下／收取／结清” | 与实体钱堆状态一致，不提前报到账 | 仅方案 |
| 锦衣客当面担保 | 已有规则之外的行走、到场、值守回应 | 拟补表现 |
| 青禾的不同意／再考虑 | 需要由真实意愿和经历驱动，不能读完名册就必同意 | 设计边界，未实现声明 |
| 公文情报 | v2 当前未读取旧版加成；不能靠改词恢复 v1 路线 | 明确不作实现承诺 |
| 现场细节 | 摸衣襟、护账、补线、视线等需真的出现 | 拟补表现 |
| 城内未完成的大演出 | 船行、宴席、完整拜师与赴京场面 | 不因本稿描述而视为完成 |

关系归因、证据、物品流转、真假身份与奖励仍以统一世界规则为准。本稿不另造一套“为了台词成立”的结算。

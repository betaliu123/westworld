# 茶棚实体投毒与日程

- 茶壶位于城外食摊旁的独立小桌。走近，从图标背包或底部快捷栏拖迷毒散到壶、盛茶的杯或包子粗模；命中需在触及范围且无遮挡，按身法检定。失败保留药粉，成功消耗一份，目击者可能制止。靠近食摊时棚顶让开视线，便于选中实际包子。
- 宋茶娘的初始点移出摊位碰撞，读旧档时只纠正她嵌入碰撞的非法位置；正常日程使用绕桌路径并预留转角余量。她照顾自己的吃饭、休息和危险，再执行取茶与轮流服务。
- 壶中的每批茶有 6 份。宋茶娘先到壶边取一份，带到桌边再分装入杯，数秒后在座的客人才会喝。杯里原有的茶不会因壶后来被投毒而追溯变毒；毒性随该份茶水与存档保留。空壶补新批次有间隔，旧杯不会自动被洗白。被亲眼看见投毒的批次不再被掌柜主动服务。
- 送出的食物转入 NPC 背包，优先考虑新收到的食物，但不会收到立即消耗。值守者需实际完成换班并到用餐处。吃前按机敏 × 0.6%（最高85%）识毒，一份食物对同一 NPC 只检查一次；认出的留在原处，不食用，不凭空指认玩家。
- 玩家与 NPC 吃下或喝下有毒物均扣25气血并产生25秒不适；拿到物品本身不掉血。客人有拿杯、干粮粗模，宋茶娘有手持壶。当前均为程序化粗模。

验证：茶水取用/分装/延迟消费、旧存档毒性、毒食送礼优先级、机敏识毒与不重复掷骰、远距/隔挡拒绝、玩家饮茶不重复结算、掌柜已知毒性、连续120秒绕桌服务。浏览器实测快捷栏投壶与背包拖拽入口。

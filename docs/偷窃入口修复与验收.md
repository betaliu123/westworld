# 偷窃入口反馈修复

2026-11-11。针对苏晚行囊的钱袋显示 78% 成功率、点击却无法执行的问题。

## 原因与改动

新章的妙手粗通只能取外露物件，解开系紧的钱袋需要入门。原面板只检查距离、警觉和衣物限制，技能门槛到执行时才检查；错误进入江湖见闻，详细面板打开时不易看到。

- `Ecosystem.theftPreview` 统一读取距离、遮挡、戒心、归属、技能门槛和失去行动能力的状态。面板与实际执行共用它，确认时重新检查。
- 不可执行时直接显示具体原因，不再显示可成功的概率。学会后在原面板即时更新；没有新的任务或对白前置。
- 浏览和被拒绝的操作不掷骰、不扣体力、不转移物品。无法反抗者可按原规则搜取，仍保留现场目击处理。
- 删除底部常驻的“Z 起身 · Esc 关闭”一行，保留 Esc 与关闭图标。小窗口滚动时标题和关闭按钮留在面板顶部。

## 验证

- 新增 5 项规则测试，覆盖粗通钱袋拒绝、学会后执行、外露/袖中物品、清醒衣物/倒地搜取、预览后距离/遮挡/戒心/技能变化、重取与读档去重。
- 相关 28 项测试通过，完整测试 442 项通过，入口与修改模块语法检查通过。
- Chrome 中使用仅 localhost 可进入的 `?playtest=theft-qa` 独立存档，未修改正式存档。实际选择钱袋：粗通显示“需要妙手·入门”，无掷骰；升到入门后同一选中物立即可确认，掷骰一次、钱袋余额归零、背包增加一个钱袋。
- 粗通实际点击偷取外露干粮正常触发检定；移动到范围外立即显示距离原因。实际偷取后的目击回应保留，退出对白可继续探索。
- 验证 1280×850、1024×768、800×600。800×600 下滚动后确认按钮和关闭入口均可见。面板正文 14px、确认按钮 16px，计算字体使用文楷及楷体回退。

退出后确认恢复探索、Z 可起身；保存 `docs/screenshots/theft-exploration-1280.jpg`。本地游戏页面未捕获到错误；浏览器扩展自身错误不记为游戏错误。

面板截图位于 `docs/screenshots/theft-requirement-1280.jpg`、`theft-requirement-1024.jpg`、`theft-requirement-800.jpg`。

## 边界

本次没有重做成功率曲线；满足条件后的普通偷窃仍使用原来的“身法 +10”。此前发现的妙手档位、物件与目标难度未接入概率计算的问题仍需单独处理，不能把本修复记为整套数值重做完成。

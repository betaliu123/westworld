# 人物外形清理验收 · 2026-11-11

按本轮反馈取消斗篷：移除圆锥占位网格、装扮槽和新档发放。没有新增斗篷资源。已有存档的物品与旧字段原样保留，装扮界面不再将斗篷作为可穿戴物；没有迁移或重置玩家存档。

开场闪出旧人物的原因是 `character()` 同步创建拼装外形，随后异步加载 GLB 才将其隐藏。现在该入口只创建动作与持物定位节点；删除旧身体、脸、头发、帽子、差役背心、斗篷及方块剑的构造与回退路径。手中可交互的扇子、玉佩、碗等道具仍保留。

主角和 NPC 在正式模型完成加载并应用姿势前保持隐藏。开始游戏等待初始人物与剑资源就绪；加载失败留在开场并提示刷新，不再用旧人物代替。模型检查覆盖主角及八类 NPC，现有 GLB 均可复用；戏面模型的 Tripo 骨骼名称已适配，不再因手势初始化失败退回占位外形。

# 符祥冒名交往与盗纲余波

2026-11-11 更新。旧版“周大石到关口作保”已由发车口令替换。

## 当前行为

- 易容符祥可向周大石发出发车口令；易容周大石可向符祥说已经备妥。无需先接任务，也不再要求带到守卫面前作保。识人预览与执行共用规则；原主在视野中、失货封车、接话人倒地等事实会阻止发车。
- 接话人实际领车/拉车，沿既有路段进关。原主不会被复制成第二位押运人，也不会传送来补齐。玩家靠近真正经过关口的车队后才能通行，仍须通过现场守卫的身份检查；确认口令不传送玩家。
- 保留向周大石借六文及还款。使用真实钱堆，放下和收取分开，一次借款、一次还款。旧版未完带路意图就地结束，已发生的借款和入城记录保留。
- 盗纲纳入现场调查和报案。原主/脚夫短暂反应后能去报官，官差追捕使用绕障路径；严重案件不因玩家收刀就退回普通警告。韩校尉、周伍长、巡街官差和顾钦差均可实际收押，城内认拘也进入牢房。服刑后保留证据，但不会凭同一已结案件再次自动收押。
- 车队转弯后路人重新挑选避让位置，避免旧的让路点横在新车道上。

## 主动余波与边界

- 成功取走且有人目击的纲货产生一条持久余波。每位目击者的指认身份在案发时冻结；没被发现的偷窃只有清点报失，不凭空获得名望或邀请。
- 报信人走到实际人物面前递话，附近清醒且有视线的 NPC 也可转述。官府收到指认后声望 −20，赤砂帮听闻后声望 −8，青竹会听闻后声望 +18。两个非官差、非押运的听闻者形成街坊议论后，地方声望 +20；同一车队每类后果仅一次，保留被目击时的一次地方声望 −15。乔装时这些后果记给当时被认出的身份。
- 林青舟先去消息所指的现场，看到相符身份后靠近、转向、当面招呼。不同意、暂缓或接受均由玩家决定；接受后登记青竹会归属和引荐关系，给一枚真实竹符，不重复发放，不撤销官府调查。未看见玩家时不会全图追踪。
- 旧 v2 存档仅从已有目击身份、严重反应和实际失货恢复调查/余波，不重发原处罚，不迁移 v1，不覆盖正式试玩进度。
- 本轮没有实现完整押送步行队列、帮会战、各派兵力调动、独立高阶入会任务，也没有生成新配音。拘押复用已有入牢表现；不能称为从城门一路步行押到牢房。

## 验证入口

- 自动测试：`npm test`；专项覆盖两边冒名、真实车队行走与过关、转弯避让、绕障追捕、四种官差入牢/出狱、冻结身份、消息视线与失能、主动邀请、拒绝/暂缓/接受、实体信物和读档去重。
- 独立浏览器验收：`http://localhost:8091/?playtest=convoy-aftermath-qa`。右上角仅在该本地测试地址加载布置控件；对话、车队移动、官差攻击与牢房选项仍走正式入口。正式游戏不加载该控件。
- 本轮沿用现有对话和 HUD，没有新增常驻解释文字或图标；删掉原有“带到关口作保/等我亲自说”等选项与对白。

## 浏览器实测（2026-11-11）

- 最终回归：`npm test` 710/710 通过；`npm run check` 和 `git diff --check` 通过。
- 使用独立 `playtest=convoy-aftermath-qa` 存档布置场景，未覆盖正式玩家进度。发车、随车移动、守卫攻击、服刑和邀约回应通过正式游戏入口执行。
- 符祥面貌向周大石发令，通过真实检定后车队进关，并走到城内公所停靠；玩家随车实际走入城内。反向周大石面貌向符祥报备也通过正式选项和检定发车。过程中修复两处转弯避让目标失效和货车边缘碰撞问题。
- 布置已有目击的盗纲现场后，周伍长实际攻击、收押，牢房显示问案与服刑选择；服满后正常出狱。该实测没有将“布置已发生盗窃”冒充为从拾取纲货开始的完整鼠标回放，现场传播及未知嫌疑处理另有规则测试。
- 林青舟在已获悉消息后实际靠近并招呼，交谈同轮显示加入、拒绝、暂缓三项。暂缓后可回来继续，接受后生成一枚竹符与青竹会归属；官府嫌疑仍保留。拒绝分支与重复领取由自动测试覆盖。
- 1280×850、1024×768、800×600 下三项回应与关闭按钮均可见，无相交；800×600 的长入会对白完整显示。新对白计算样式为文楷/楷体回退、16/22px，题字30px，无禁用字体或小于14px字号。浏览器警告与错误记录为空。

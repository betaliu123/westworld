# 入城 NPC 生活与势力线索 · 2026-10-28

本轮根据用户确认的 NPC 交互方案开发，不改为新的策划提案。原存档沿用；`/?preview=gate` 提供独立试玩存档。

## 已接入的循环
- 韩校尉、周伍长轮值。饥饿、体力和已值守时间触发接班；人实际走到关口后交接。离岗者去茶桌吃饭、休息，危险反应优先。
- 城外增加宋茶娘、陈脚商、杜老捕和两张茶桌、木凳、食摊。食摊库存真实有限，购买要付钱并把物品转入 NPC 背包。
- NPC 有真实物品、饥饿、体力、气血和势力归属。食物礼物根据饥饿、信任、冲突和已知毒性判断。拒绝不扣物；接收后由 NPC 日程决定何时吃。
- 玩家与 NPC 共用食物恢复和毒性结算，深水伤害复用同一规则；NPC 会试着上岸，危急中被木质障碍挡住时可攻击障碍，损毁使用通用材质与耐久。NPC 行为不归罪玩家。
- 茶棚近处旁听、问话提供逐条情报。组织界面使用已知投影，只画已知人物与已知联系，传闻用虚线并注明来源。J 或右上角关系图标打开，沿用互斥抽屉。
- 韩校尉/周伍长提供轮值消息；补衣人提供税课线索；脚商提供京中接引传闻；杜老捕提供身法训练和上游人物背景；刻字人辨官印；旧账房提供副账证言。
- 与赵行商谈妥帮工后，他实际走到关前，玩家跟到、现场有可应答的守卫后登记入城，记录欠下的帮工承诺。协议本身不直接瞬移入城。
- 关口担保需要好感与信任，已有犯罪记录不能被好感覆盖。照顾病人能够增加信任。

## 验证与边界
自动测试覆盖礼物拒绝/接受、毒性保存、等换班再吃、不可用替班、溺水、同等食物效果、存档迁移、情报遮挡与未知信息隐藏、商队实际到场、NPC 破坏不归罪玩家。

当前梁中丞、郑税使是本原型中新设计的调查节点，蔡京是最终调查方向；本轮没有制作这几个城内 BOSS 的实体战斗关卡，也不把传闻当作可直接定罪的证据。

当前生活目标采用有限状态与实际位置驱动，尚不是全城经济/复杂长距离计划系统。商人携带真实货包，进城后同行到卸货处支付一次工钱；长途押镖与复杂委托尚未制作。通用技能、特殊桥段仍沿用现有战斗与剧情系统逐步扩展。

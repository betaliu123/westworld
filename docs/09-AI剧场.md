# 09 · AI 剧场

## 负责什么

每天 9:00-12:00 在镇中心大街演一场街头戏：8 棵剧本树、演员选角、玩家可选/自由输入、结局结算（现金/荣誉/通缉 + 报纸/来信/遗留物 + 结构性后果包）。

## 关键文件

- `theater/TheaterDirector.js` —— 总控：选剧本、选角、结算
- `theater/TheaterRuntime.js` —— 剧本推进、区域判定、玩家交互
- `theater/TheaterUI.js` —— 演出 UI
- `theater/Casting.js` / `StageMap.js` —— 选角 / 站位
- `theater/TheaterGlue.js` —— LLM 衔接（free chat 回剧本）
- `theater/ConsequenceSystem.js` —— 后果包（势力/延迟揭示/延迟回报/解锁）
- `config/theaterData.js` —— 8 棵剧本树（154 节点 / 412 台词）
- `config/theaterConsequences.js` —— 每结局后果包
- `factions/GangGroupChat.js` —— 玩家帮派群聊

## 玩家参与判定（重要修复）

`playerEverJoined` **只在玩家真的交互时置 true**（选了选项 / 发了自由输入）：
- 走进 interact 范围**不算参与**（可能只是路过/在屋里）
- 没参与 → 结算**不给玩家任何结果**（不加钱、不扣荣誉、不上通缉、不触发后果包、报纸不写"你做了什么"）

## 后果包（P8）

每结局挂后果包，四类：
- `faction` —— 即时改势力支柱/影响力
- `reveal` —— 延迟 N 天揭示真相（报纸/手机，回头改变意义）
- `delayed` —— 延迟回报（来信/还钱）
- `unlock` —— 解锁隐藏关系标记

至少 1/3 结局带 reveal。日结 Step14.8 兑现到期的揭示/回报。

## 演出流程

`开演(9:00) → GATHERING(演员就位) → 节点推进 → 玩家选项/自由输入 → 结局 → 散场`

- 区域：`outside / sense / interact`（感知 26m / 交互 16m）
- 玩家没来就循环第一幕；天黑/演完散场，演员回去上班
- `unattendedMs` 超时 → 自动推进到结局（玩家不参与则无结算）

## 群聊

玩家帮派群聊（手机）：
- 招募成员自动拉入，新人有公告 + 老人欢迎
- 每天聊 1~2 句，好感高偶尔拍马屁
- 群聊不显示单人对聊选项（知道/聊点别的/收服都隐藏）

## 配置修改

剧本树：`config/theaterData.js`；后果包：`config/theaterConsequences.js`；台词"对谁说"：`config/theaterBeatTo.js`；性别约束：`config/theaterRoleGender.js`。

# 美术视觉与界面规范

> 定位：**界面是画上的题跋与印章，不是叠在画上的面板。**
> 取宋画的克制：大量留白、以线和墨色分层、点一方朱印定焦点。界面服务于场景，能用场景、动作、图形说清的，不写字。

本规范约束玩家可见的一切界面：HUD、对白、面板、结算、标题页，以及场景里的文字（招牌、通缉榜、名字牌）。`AGENTS.md` 中的 HUD 布局、检定展示、对白优先级等规则继续有效，本规范只规定"长什么样、怎么动、写多少字"。

## 1. 调研结论

| 参考 | 可借鉴 | 不照搬 |
| --- | --- | --- |
| 《绘真·妙笔千山》（网易 UX 中心复盘） | 宋式"雅致极简"；用留白和光影代替花纹；小按钮也画成情境小图（乐师代替音量开关）；转场做成"落墨→染色→入画" | 青绿重彩配色（我们是水墨） |
| 《对马岛之魂》 | 默认清屏；以风、鸟、烟等场景物引路，代替小地图和路标；靠近目标才出现小图标 | 武士题材的日式排版 |
| Sumiro（本项目的参考样例） | 纸色底、衬线小字、极少界面元素 | 西文字体与排版 |
| 当前项目现状 | 已有统一的图标入口 `src/ui-icons.js` | 见下方问题 |

已定方案（2026-11-10 确认）：题字用志莽行书；详细面板与结算用浅色纸笺；小地图与罗盘常驻，改为水墨样式。样张：`cc_task/2026-11-10-ui/specimen.html`。

当前界面显得"AI 味"的具体原因：

- **字体混杂且是系统默认字体**：样式表里同时用了微软雅黑、楷体、Georgia、Segoe UI 和 `sans-serif`；场景文字 `textSprite` 用的也是微软雅黑。
- **通用深色卡片**：深灰蓝半透明底、5px 圆角、1px 细描边。全屏都是这一种容器，和水墨场景割裂。
- **配色散乱**：样式表里有一百多种不同颜色值，没有色彩语义。
- **说明文字过多**：常驻的十项按键说明栏、"行动与身体状态变化"一类标签、标题页营销式标语、结算卡标题重复（类别和标题都是"直接行动"）。
- **通用线框图标**：lucide 图标是常见的 App 风格，和笔墨不搭。

## 2. 色彩：墨分五色，一点朱砂

以"纸"为底、以"墨"分层次，彩色只作点睛。

| 变量 | 色值 | 名称 | 用途 |
| --- | --- | --- | --- |
| `--paper` | `#ece3cf` | 生宣 | 面板、对白、结算底 |
| `--paper-deep` | `#d8cbaf` | 旧纸 | 次级底、分隔、禁用 |
| `--ink-0` | `#15140f` | 焦墨 | 标题、关键数字 |
| `--ink-1` | `#2c2a24` | 浓墨 | 正文 |
| `--ink-2` | `#4f4b42` | 重墨 | 次要文字、图标 |
| `--ink-3` | `#7b766a` | 淡墨 | 辅助信息、未激活 |
| `--ink-4` | `#b4ac9a` | 清墨 | 线、底纹、占位 |
| `--cinnabar` | `#a63a2b` | 朱砂 | 印章、危险、警觉、主确认、失败 |
| `--malachite` | `#5f7f5c` | 石绿 | 成功、恢复、正向变化 |
| `--ochre` | `#9c6d3c` | 赭石 | 钱财、珍贵物品 |
| `--azurite` | `#3d6470` | 石青 | 情报、线索、任务追踪 |

- 朱砂面积不超过画面的 5%，同屏只用来标最重要的一处。
- 彩色只出现在印章、数值变化、状态点上，不铺大面积底色。
- 语义不能只靠颜色：成功和失败同时用字形或印章形状区分，比如"成"字方印和"败"字破印。
- 禁止：纯白 `#fff` 大面积底、霓虹色、蓝紫渐变、发光外描边、毛玻璃模糊作为主要质感。
- 浮在场景上的文字不用深色底框：用墨字加一圈纸色晕边；场景偏暗或夜晚时，改用纸色字加一圈淡墨晕边。

## 3. 字体：三种字，各司其职

只使用可免费商用的 SIL OFL 1.1 授权开源字体，转成 woff2 子集放进 `vendor/fonts/`，并附带 `OFL.txt`。

| 角色 | 字体 | 用在哪里 | 规则 |
| --- | --- | --- | --- |
| 题字 | 钟齐志莽行书 Zhi Mang Xing（备选：马善政毛笔楷书） | 游戏名、地名、章节、结算大字、印章 | 每处不超过 8 个字；字号 ≥ 28px；只按实际用到的字做子集（目标 < 200KB） |
| 正文 | 霞鹜文楷 LXGW WenKai | 对白、剧情、面板正文、按钮 | 行高 1.7，字距 .02em |
| 数据 | 思源宋体 Noto Serif SC（SemiBold） | 数值、属性名、成功率、键帽 | 阿拉伯数字等宽（`font-variant-numeric: tabular-nums`） |

- 字号只用这几档：14 / 16 / 18 / 22 / 30 / 44px。最小 14px，不再出现 9 / 11 / 12px 的小字。
- 回退字体只能是楷体或宋体（`KaiTi`、`STKaiti`、`SimSun`、`Songti SC`），不能退回微软雅黑或无衬线字体。
- 叙事里的时间、次数用中文数字（"三日后"）；玩法数值用阿拉伯数字（"+18"、"65%"）。
- 地名牌、章节名、名字签可以竖排（`writing-mode: vertical-rl`）；正文一律横排。
- 场景里的 Canvas 文字（`textSprite`、招牌）和网页界面用同一套字体变量。
- 字体加载：题字字体预加载；正文字体按 `unicode-range` 切片，优先加载常用 3500 字；统一 `font-display: swap`。

## 4. 形制：纸、墨、印，而不是卡片

| 容器 | 用于 | 做法 |
| --- | --- | --- |
| 墨晕 | 对白、交互提示、浮在场景上的信息 | 无边框，径向淡墨（或纸色）渐隐底，边缘不规则 |
| 纸笺 | 详细面板：人物、行囊、传书 | 纸色底加共享纸纹，毛边遮罩，四角不对称 |
| 卷轴 | 结算、章节、地图 | 横向展开，两端有轴头 |
| 印章 | 结果、确认、身份、势力 | 朱文或白文方印，题字字体 |
| 竹签 / 名牌 | NPC 名字、地点标签 | 竖排小签，淡墨描边 |

- 圆角 0–2px；分隔线用手绘毛笔线 SVG（起笔重、收笔轻），不用 1px 实线。
- 不用 `box-shadow` 做悬浮卡片；需要层次时用纸张叠压的贴边阴影，或墨色渗边。
- 全局只用一张纸纹贴图，不叠多层材质。
- 按钮的默认状态是"字加一道墨线"，悬停时墨线晕开，按下时盖印；不用实心色块按钮。

## 5. 图标：笔意图标

- 自绘一套统一的笔意图标：24px 网格，毛笔描边粗细不均，单色墨；有状态时加一个朱砂点。
- 用物件做隐喻，不用通用 App 符号：

| 功能 | 图形 |
| --- | --- |
| 行囊 | 包袱 |
| 人物 / 属性 | 铜镜 |
| 传书 | 带火漆的信笺 |
| 歇息 | 茶盏 |
| 声音 | 铃 |
| 地图 | 卷轴 |
| 交互 | 手 |
| 蹲行 | 足印 |
| 拔刀 | 剑 |
| 检定 | 签筒 |

- 统一从 `src/ui-icons.js` 出图标；lucide 只作过渡，新功能不再引入新的 lucide 图标。
- 继续保留中文 `aria-label` 和悬停说明（AGENTS.md 既有规则）。

## 6. 动效：模拟墨与纸的物理

| 动效 | 用于 | 参数 |
| --- | --- | --- |
| 晕开 | 提示出现、按钮悬停 | 遮罩从中心扩散，160–220ms |
| 墨干 | 提示消失 | 透明度加轻微模糊，400ms |
| 展卷 | 面板、结算打开 | 横向展开，300–420ms |
| 盖印 | 确认、获得、结果揭晓 | 缩放 1.15→1，加 2px 抖动，120ms |
| 落笔 | 数值变化、标题出现 | 描边路径逐笔显现，≤ 600ms |

- 缓动曲线统一为 ease-out；禁止弹跳、橡皮筋、旋转、霓虹脉冲、粒子礼花。
- 支持 `prefers-reduced-motion`：此时只保留淡入淡出。
- 场景级转场（入城、出狱、章节）可以用"落墨→铺色→入画"，不用黑屏淡入淡出。

## 7. 文字纪律：少写字，用图形和动作说话

每一处界面文字都要问一句：**玩家不读这句话，会不会做错事或错过后果？** 不会，就删掉，或换成图标或动效。

**必须保留文字**：剧情、对白、行动后果、关键数值，以及检定的能力、成功率和难度（与 AGENTS.md 一致）。

**禁止**：

- 同一张卡片里重复标题（类别和标题写同一个词）；
- 解释性副标题和标签，比如"行动与身体状态变化"；
- 常驻的按键说明栏：改为首次可用时就地提示，用过几次后不再出现；
- 标题页营销口号、"戴上耳机"一类说明；
- 用一句话复述图标已经表达的意思。

**改写方式**：

- 按键提示：键帽图形加 ≤ 4 字的动词，例如 `[E] 交谈`、`[/] 收刀`。
- 数值变化：图标加数字，例如"剑 +18"；原因写进江湖见闻，不在弹出提示里展开。
- 结算：一个题字大字（"成"、"败"、"险"）加印章，再加一句后果；奖励用图标数值签。
- 状态：气血、体力满值时淡出，下降时再显现；不写"体力充足"之类的话。

## 8. 沉浸：探索时清屏

- 探索时默认只留三样：受损时出现的气血和体力墨条、当前交互提示、需要时出现的方位。
- 任务和见闻在 6 秒内无变化时，淡到 35% 不透明度或收起；有新内容时再晕开。
- 引路优先用场景：被风吹动的草、飞鸟、炊烟、灯笼（参考对马岛）。小地图和顶部罗盘保留常驻，但改成水墨样式：小地图是圆形淡墨舆图加毛边，罗盘是一道墨线加题字方位，不用深色底框。
- NPC 名字只在近处或注视时出现，样式为竖排小签。
- 对白：说话人名用题字小印，正文用文楷，底为墨晕，不用对话框。
- 场景里的招牌、榜文、印信与界面同一套字体和色彩。

## 9. 验收

- 1280×850、1024×768、800×600 三档截图（沿用 HUD 规则）。另加一张"探索清屏"截图：除交互提示外不应有常驻文字。
- 检查计算样式：玩家可见元素不得出现微软雅黑、Segoe UI、Georgia 或无衬线字体；字号不小于 14px。
- 正文与底色对比度 ≥ 4.5:1。
- 断网或字体加载失败时，回退为楷体或宋体，排版不塌。
- 新增界面需对照第 7 节逐条删字，并在提交说明里列出删掉或换成图标的文字。
- 字体体积：题字 < 200KB；正文切片首屏加载 < 600KB。

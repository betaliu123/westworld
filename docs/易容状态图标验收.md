# 易容状态图标（2026-11-11）

- 易容状态移至底部饥饿、困倦所在状态组，装扮入口之前。笔意面具图标由统一图标模块输出，外围圆环表示该次易容剩余时长比例，顺时针从十二点起显示；无闪烁或循环动画。
- 悬停和中文无障碍名称显示“易容 · 人物姓名 · 余 N 分钟”。删除原右侧常驻身份文字，衣着身份仍可在装扮入口悬停及装扮面板查看。
- 新易容记录本次总时长，读档沿用。旧记录仅按已有时长公式显示比例，不修改到期时间，不进行历史装扮迁移。时间与装扮面板共用事实，卸妆、识破或自然到期后隐藏。
- 无饥饿/困倦时易容仍可独立显示；所有状态消失后状态组隐藏。对白、检定沿用现有 HUD 让位规则，详细面板打开时不显示易容图标。

验证：23 项现有装扮及冒名测试通过，`npm run check` 通过。额外执行断言检查满时、半程、序列化读档、旧记录不迁移、到期及卸妆。独立 `playtest=disguise-status-qa` 实测半程圆环、状态组独立显示、卸妆与自然到期隐藏，没有覆盖正式存档。

1280×850、1024×768、800×600 实测状态栏与蹲行、任务及角色信息不相交；小窗口对白时状态栏收起、关闭按钮可见。状态组使用文楷/楷体回退，标签14px，无新增禁用字体或小于14px文字。浏览器警告和错误记录为空。

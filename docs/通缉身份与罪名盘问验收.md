# 通缉身份与罪名盘问验收

2026-11-11。本轮把燕七专用入口改为按官差所知通缉记录判断的通用入口，优先于普通事发地盘查。

## 事实与决策

- `src/wanted-records.js` 统一投影榜文、拘传文书、亲眼目击和已经当面收到的报案。记录包含 `id`、`subject`、`status`、`jurisdiction`、`knownBy`、`source`、`charges`；罪名项包含 `code`、`label`、`detail`。新增人物通缉可写入 `s.law.warrants`，无需新增人物专属对白分支。
- 燕七的既有钱袋案作为临溪榜文事实：许行商报失钱袋，指认燕七曾近身，案由为盗窃嫌疑。官差知道榜文不以玩家先接任务或读榜为前提。
- 只有当前官差亲历或实际接到的证言才可用。单独发现尸体不能凭空生成凶手身份；已冻结的目击身份不因后来卸妆追溯改变。
- 官差质疑明确说出认定身份、案情与罪名。回应为狡辩、到案核问、拒绝到案。狡辩预览与结算同一公式；亲眼目击的案情明确禁止以认错人搪塞，不包装成概率。
- 同一官差、同一身份及同一组案情保存回应结果。取消不掷骰；脱穿或重新易容不刷新同案狡辩。失败、拒绝触发实际追捕；重新接触不再无限抽取检定。
- 实际易容的一刻按距离、朝向、遮挡、意识与实时场景位置记录目击。官差亲眼看到改脸时直接识破、卸妆，并把冒名行为与原主案件区分；看不到变装过程的官差仍按自己认定的面貌处理。
- 到案对白完整结束并重查现场后才收押，取消不扣风仪。拘押保存口供身份、罪名和案件编号，接回现有县狱及出狱流程。冒名收押不会清除真正原主的榜文。
- v2 增量字段按需初始化，无历史装扮迁移。保留旧燕七调用的兼容包装；新入口使用通用案情。未改人物声音。

- `tests/wanted-identities.test.js` 覆盖知情边界、其他身份与罪名、冻结归因、尸体无证据、目击易容的视线条件、直接目击禁止狡辩、概率一致、重复与读档、真实追捕、拘押和取消，以及拒绝后重新接触。
- Chrome 使用独立 `?playtest=lasso-qa` 存档，未重置玩家进度。通缉面貌可从普通现场盘查入口被优先接管；实际点击到案进入县狱并能接回出狱流程。另一个测试案由正确说出伤人嫌疑；拒绝后用实际移动按键离开，捕快追赶并发生位置变化，未掷骰。

## 实现边界

到案复用现有拘押与三日出狱机制；尚未增加完整徒步押解、按罪量刑、审判或跨城通缉传播。本轮实现的是官差知识范围内的身份判断、具体案由对白、回应记忆、追捕与拘押记录。

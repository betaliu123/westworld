# 04 · 声望与执法

## 负责什么

玩家在镇上的名声：荣誉值（善/恶）、通缉度（0~5 星）、帮派声望，以及执法者（警长小队）如何追捕、逮捕玩家。

## 关键文件

- `systems/Reputation.js` —— 荣誉 / 通缉 / 帮派声望
- `entities/Sheriff.js` / `SheriffSquad.js` —— 警长实体 / 小队
- `systems/CorpseReactions.js` —— 路人对倒地者反应（含报官）

## 声望

- **荣誉**（honor，-100~100）：善行升、暴力降
- **通缉**（wanted，0~100 → 0~5 星）：犯罪行为升，随时间衰减
- 通缉等级决定追捕强度：3★→2 人、4★→3 人、5★→5 人，开枪伤害也更高
- 摆脱方式：疾跑 / 开车 / 绕出视野；被贴身抓住 → 逮捕（罚款 + 清通缉）

## 逮捕

`onArrested()` 清空通缉。逮捕由警长接触玩家触发。

## 路人对倒地者的反应

`CorpseReactions` 每 0.5s 扫一遍：
- 看到尸体/伤者：吓一跳（SHOCK_LINES）、走近绕开、胆小者跑+可能报官
- **尸体 vs 伤者分开**：伤者报官意愿减半，医生/牧师/酒保会上前救人
- 只有玩家在尸体 ≤18m 内才可能被当成凶手报官

## 配置修改

声望参数在 `config/gameData.js` 的 `REPUTATION`；反应台词在 `CorpseReactions.js`。

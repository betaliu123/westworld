# 锦衣客与 NPC 探查

原 traveler ID 保留，避免破坏存档、关系、持有物和中毒状态。初见是锦衣客；机敏探查只解锁可见特征、状态和真实包裹。风仪检定可得出门用名赵闲舟，抵达听雨楼后再揭晓宗室身份。未解锁不在信息卡及势力图泄密。

交谈：问入城、说自己的遭遇、凭观察询问身份、根据税课线索交换消息、告别。邀约自动进入任务：茶凉了。折扇、白玉佩、封好的信是真实物品，可偷、送、掉落。密信需持有后拆阅；出示税课凭据也能触发邀约。

离场沿茶棚、关口、城内街道到听雨楼南侧真实行走，同行两人跟随。死亡、中毒、点穴、危险打断行走；不传送或销毁角色。随从按普通视线目击规则护卫，不凭空得知犯罪。暂用收拢的折扇和玉佩粗模；没有专门的开扇、敲栏动画。

任意 NPC 菜单增加探查：首次机敏检定，失败冷却 30 秒且不自动敌对；成功持久解锁，之后查看不掷骰。个人信息为只读，取物仍从蹲行偷窃入口执行独立检定。目标小卡片与详细面板互斥。

自动回归涵盖探查成功一次、失败冷却、未知身份投影、旧存档物品去重、两段身份揭晓、邀约及行走目标、密信所有权与拆阅。浏览器实测从探查检定进入图标包裹，关闭恢复目标小卡片。

# 场景音乐与音效

2026-11-10：首批 Seed Audio 成品已接入实际游戏。此前只有人物配音进入游戏，环境小样停留在试听页，攻击仍使用振荡器提示音。本轮替换该路径。

## 本轮覆盖

| 声音 | 素材与播放条件 |
| --- | --- |
| 探索配乐 | 新生成 40 秒琴箫主题，进入游戏后淡入；卖艺时退下，倒地时减弱 |
| 街巷、茶棚 | 新生成 20 秒模糊人群底声；随地点混合，夜间降低，不含清晰循环台词 |

| 竹笛演奏 | 两条 24 秒 Seed 竹笛独奏；乐器等级 0–2 用生涩版，3–4 用娴熟版，跟随玩家实际吹笛动作与卖艺播放 |

材质目前分三类，石材暂借用金属硬碰撞，收刀暂复用降低音高的出鞘声。NPC 独立脚步、不同地面、火焰、完整战斗音乐尚未逐项制作；本轮不等于所有行为已具备专属录音。

## 混音与生命周期

`src/world-audio.js` 与人物配音共享一个 AudioContext。浏览器收到开始/继续、键盘或点击手势后解锁声音；总开关控制音乐、环境、音效、对白。

- 配乐、环境以 1.4 秒重叠淡化循环接缝，并按位置平滑调整；不是声称素材原曲天然无缝。
- 人物实际开口时，配乐降至常态的 28%，人群 36%，溪水 50%；结束后恢复。卖艺时配乐降至零。
- 暂用区域混音与事件距离衰减，尚未实现完整方向定位及隔墙遮挡。
  NPC 新增反应单独检查视线与墙体、距离、存活和失声状态；这不代表原有全部环境声已经支持遮挡。反应同时最多一组，人物离开或松绑等使现场失效时停播，正常对白优先。
- 静音、切到其他标签、离开页面及时停止。恢复后重新接入环境，不补播过去的攻击或提示。
- 音效首次未载入时跳过，不排队迟到播放；失败加载不每帧重试。单次音效限制并发和重复触发。
- 玩家存档不变，未增加常驻声音 UI。

## 2026-11-11 补录与河中异响修复

- 本次限量生成三条：`flute-poor`（24 秒，气息不稳、音准偏移、断句）、`flute-good`（24 秒，稳定连音与自然换气）、`creek`（30 秒，平缓连续流水，提示词排除密集鸟鸣、机械脉冲和急促敲击）。笛声两档按既有乐器等级选择，不新增掷骰，不修改赏钱、成长或听众结算。没有技艺数据的旧版回归角色使用生涩版。
- 笛声只有实际演奏时播放，浏览菜单不播放；收笛、动作结束、倒地、进入对白或处于水火伤害中停止。静音、切页、离场沿用总开关。迟到资源只供仍在进行的动作使用，不补播结束的演奏。相邻笛声片段留 0.2 秒换气，不把两条独奏交叉叠成合奏；探索配乐快速退下。
- 河里的“机关枪”可由持续掉血每帧触发衣甲受击音造成：原受击音冷却仅 65 毫秒。本轮扣除本帧水火环境伤害后再判断物理受击，受击声音另加 0.6 秒冷却；保留真实血量下降、受伤表现和倒地。水中同时受击仍可播放击打声，水中移动不再播放石板脚步。
- 成品为 48 kHz 双声道 PCM16；笛声各约 −23 dBFS RMS，流水约 −29 dBFS RMS，峰值均低于 −3 dBFS。提示词、参数、哈希、原始文件随清单保存。技术验收覆盖解码、电平、循环与生命周期；模型的具体音色、跑调程度与流水听感仍以试听为准。未新增 NPC 独立演奏声源或涉水/呛水专属拟音。

```powershell
python tools/seed_sound.py --only flute-poor flute-good creek --limit 3
```

试听页增加“乐器水平”和三条补录原音；“开始吹笛 / 收起竹笛”替换旧的“卖艺时淡出配乐 / 恢复探索配乐”测试按钮。游戏 HUD 没有新增文字或按钮，既有玩家存档不做迁移。

## 生成和维护

离线工具：`tools/seed_sound.py`。成品、原始文件和含完整提示词的 `manifest.json` 在 `assets/audio/world/`。清单同时记录参数哈希、时长与来源；浏览器只播放成品，不调用生成模型。

```powershell
python tools/seed_sound.py --only wood --limit 1
```

默认每次只跑一条，指定 `--only` 控制补录范围；相同请求命中本地文件缓存，不重复计费。修改提示词或参数会更换哈希，重新生成。原始输出保留，成品做裁静音、短渐变、RMS 电平归一化和峰值限制，输出 PCM16 WAV；这不是 LUFS 母带处理。

调用现有雷火网关 `/openspeech/api/v3/tts/create`，读取本地 `LLM_API_KEY`，不把凭证放入前端或清单。请求模型 `seed-audio-1.0`，`text_prompt` 指定场景、材质、时长与避免的声音，`audio_config` 为 `format: wav`、`sample_rate: 48000`、`enable_subtitle: false`。协议参考：[Seed 音频生成 HTTP](https://docs.volcengine.com/docs/doubao-voice/audio-generation-http?lang=zh)。

## 试听与验收

2026-11-12：试听页新增“人物反应”九个按钮；游戏按实际 NPC 性别选非语言素材，既有人物台词配音保持原配置。生成仍是显式离线批次：

```sh
python tools/seed_sound.py --only npc-gasp-male npc-gasp-female npc-pain-male npc-pain-female npc-alarm-male npc-alarm-female npc-murmur-male npc-murmur-female npc-murmur-mixed --limit 9
```

成品与完整参数保存在原场景声音清单，运行时没有 SeedAudio 或 TTS 生成请求。反应声音的 66 项回归、独立存档实景结果和首批音色边界见 [NPC 反应音效验收](qa/2026-11-12-NPC反应音效.md)。

打开 `/audio-world-preview.html` 可对比城门、街巷、溪边以及昼夜，逐个听新音效，并验证锦衣客开口时背景声降低；此页不会新生成对白。正式入口仍是 `/?preview=gate`，刷新后点继续游戏并开启声音。

自动测试覆盖混音权重、循环调度、静音/切页、迟到资源、脚步、事件去重及成品清单。浏览器验证只能证明播放与调度正常；音色、节奏和重复感以实际试听反馈继续调整。

## 2026-11-11 夜间声景

新增 music-night（夜泊）、night（街巷夜风）、night-inn（客栈夜阑），原音和参数一并写入 world/manifest.json。19 时至次日 6 时集市总线归零，夜曲替代白天音乐；客栈室内 19 时至 2 时保留轻杯盏声，室内风与溪水衰减。三个样本通过 `python tools/seed_sound.py --only music-night night night-inn --limit 3` 离线生成，游戏不生成素材。

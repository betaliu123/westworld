# 场景音乐与音效

2026-11-10：首批 Seed Audio 成品已接入实际游戏。此前只有人物配音进入游戏，环境小样停留在试听页，攻击仍使用振荡器提示音。本轮替换该路径。

## 本轮覆盖

| 声音 | 素材与播放条件 |
| --- | --- |
| 探索配乐 | 新生成 40 秒琴箫主题，进入游戏后淡入；卖艺时退下，倒地时减弱 |
| 街巷、茶棚 | 新生成 20 秒模糊人群底声；随地点混合，夜间降低，不含清晰循环台词 |
| 溪水、鸟鸣 | 复用此前认可的 20 秒 Seed 溪畔素材，靠近城西水道增强 |
| 拔刀、空挥 | 独立短素材；动作触发，不把挥空当命中 |
| 木材、衣甲、金属受击 | 按真实命中对象材质播放；点穴不使用刀锋声 |
| 脚步 | 实际落地移动触发，蹲行更轻；跳跃悬空、传送不播行走声 |
| 铜钱、检定、察觉 | 钱币/木响/金属短素材做轻量提示，替换旧电子提示音 |

材质目前分三类，石材暂借用金属硬碰撞，收刀暂复用降低音高的出鞘声。NPC 独立脚步、不同地面、火焰、完整战斗音乐尚未逐项制作；本轮不等于所有行为已具备专属录音。

## 混音与生命周期

`src/world-audio.js` 与人物配音共享一个 AudioContext。浏览器收到开始/继续、键盘或点击手势后解锁声音；总开关控制音乐、环境、音效、对白。

- 配乐、环境以 1.4 秒重叠淡化循环接缝，并按位置平滑调整；不是声称素材原曲天然无缝。
- 人物实际开口时，配乐降至常态的 28%，人群 36%，溪水 50%；结束后恢复。卖艺时配乐降至零。
- 暂用区域混音与事件距离衰减，尚未实现完整方向定位及隔墙遮挡。
- 静音、切到其他标签、离开页面及时停止。恢复后重新接入环境，不补播过去的攻击或提示。
- 音效首次未载入时跳过，不排队迟到播放；失败加载不每帧重试。单次音效限制并发和重复触发。
- 玩家存档不变，未增加常驻声音 UI。

## 生成和维护

离线工具：`tools/seed_sound.py`。成品、原始文件和含完整提示词的 `manifest.json` 在 `assets/audio/world/`。清单同时记录参数哈希、时长与来源；浏览器只播放成品，不调用生成模型。

```powershell
python tools/seed_sound.py --only wood --limit 1
```

默认每次只跑一条，指定 `--only` 控制补录范围；相同请求命中本地文件缓存，不重复计费。修改提示词或参数会更换哈希，重新生成。原始输出保留，成品做裁静音、短渐变、RMS 电平归一化和峰值限制，输出 PCM16 WAV；这不是 LUFS 母带处理。

调用现有雷火网关 `/openspeech/api/v3/tts/create`，读取本地 `LLM_API_KEY`，不把凭证放入前端或清单。请求模型 `seed-audio-1.0`，`text_prompt` 指定场景、材质、时长与避免的声音，`audio_config` 为 `format: wav`、`sample_rate: 48000`、`enable_subtitle: false`。协议参考：[Seed 音频生成 HTTP](https://docs.volcengine.com/docs/doubao-voice/audio-generation-http?lang=zh)。

## 试听与验收

打开 `/audio-world-preview.html` 可对比城门、街巷、溪边以及昼夜，逐个听新音效，并验证锦衣客开口时背景声降低；此页不会新生成对白。正式入口仍是 `/?preview=gate`，刷新后点继续游戏并开启声音。

自动测试覆盖混音权重、循环调度、静音/切页、迟到资源、脚步、事件去重及成品清单。浏览器验证只能证明播放与调度正常；音色、节奏和重复感以实际试听反馈继续调整。

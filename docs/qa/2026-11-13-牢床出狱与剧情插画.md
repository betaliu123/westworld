# 牢床出狱、剧情插画与场景声音

本地实现与独立存档验收；未发布线上，未改玩家存档。

## 玩家可见变化

- 收押、刑满出狱、首次入职六扇门、接受锦衣客查账委托后，展示对应插画。插画任意位置可点击继续，也支持 Esc、空格、回车；关闭使用既有笔意图标。插画等待对白与动作结束，不在演出层发奖。已关闭场景记入存档；旧档已经发生的入职和合作不补播，未关闭的插画读档后可继续。
- 出狱图按反馈修正左手：自然垂在身侧；去掉背包、腰包、手提包，保留破旧衣袍、斗笠与蓬乱头发。未揭露王爷身份时，合作插画文字仍使用锦衣客称呼，不泄露王府身份。
- 两张牢中草铺成为真实可点击物件，提供“躺下歇息”“睡到出狱”。后者先走到床边、躺下、短暂入睡，再执行原有三日服刑转场；中止或被打断不提前出狱。床被毁仍保留原有服刑出口。
- 死亡账房不再提供旧案问话，也不再用残留冲突挡住休息。睡到出狱不会凭空获得他的口供。牢中任务提示改成草铺引导。
- 被通缉且靠近玩家已察觉的盘查区时，危险配乐渐入；距离拉远后逐渐淡出。隐藏案件不通过配乐泄露。拘押期间播放牢中配乐，关闭街声。真实乔装识破结算触发短促的尴尬音效；预览、解释成功、取消不播放。音乐、音效继续共用总开关、切页停声和对白压低机制。

## 素材

声音通过显式离线命令 `python tools/seed_sound.py --only music-danger music-prison recognition --limit 3` 生成，模型 `seed-audio-1.0`。危险配乐 40 秒，牢中配乐约 37.55 秒，识破音效约 1.47 秒；48 kHz 双声道，检查无削波。成品、原始音频及提示词/参数/内容哈希保存在 `assets/audio/world/` 与其 `manifest.json`，游戏运行时只播放静态音频，不调用付费生成。

## 验证与边界

- `npm run check` 通过；全量 Node 测试 **1121/1121** 通过；关闭图标接入后补跑相关测试 **36/36** 通过。
- Edge 本地独立键 `?playtest=prison-milestones-qa`：用测试夹具安排入狱和账房剩余气血，再用实际 `/` 拔刀、鼠标攻击造成死亡；鼠标点击草铺打开菜单、躺下、Esc 起身；中途取消“睡到出狱”日期不变；完成后仅增加三日，死者仍死亡、无口供奖励。
- 出狱插画未关闭时读档能继续，关闭后再读档不重播、不再次服刑；入职和合作调用真实结算函数触发两幅图。本轮未重新走完整入职、查账任务链。
- 1280×850、1024×768、800×600 的牢床菜单与插画检查通过：按钮和关闭入口在屏内，字体符合既有规范，字号不低于 14px。保留探索清屏截图。新增界面用一幅图、短题字和一句话，不增“下一步”文字按钮；牢床省去没有决策意义的归属说明。
- 浏览器确认牢中配乐循环存在、盘查区危险配乐渐入/离远淡出、静音后循环清空；最终浏览器错误为 **0**。识破音效的结算触发、距离、重复抑制与静音通过单元测试验证。

# 装扮场景冒泡

本轮将实际穿衣、戴斗笠之后的反馈接入探索场景。装扮面板关闭后，附近能看见玩家的 NPC 短暂转向，并用现有带姓名短冒泡回应。浏览面板、取得衣服、重复点击同一件衣服都不触发。衣物、面貌、凭据和势力身份继续分别结算。

## 离线台词

- DS 服务：`https://ai.leihuo.netease.com`，模型 `deepseek-v4-flash`。用户在本次会话明确同意发送十位 NPC 的简短人设、六类装扮条件与写作约束。
- 初批 264 条、返修批 288 条；额外数量包括模型多写的变体及重复键。两批原始候选均保存在 `docs/offline/2026-11-11-appearance-barks/`。
- 最终 `assets/appearance-barks.json` 为 240 条：10 位人物 × 6 类装扮 × 4 种措辞，每句 8–28 字。
- 人物：韩校尉、周伍长、宋茶娘、赵行商、周大石、刻字人、温素笺、锦衣客、顾钦差、符祥。
- 条件：差役/官兵服、挑夫短褂、裙装、商旅衣着、普通布衣、斗笠。应奉局管事服等未匹配类型不套用别的身份措辞；未配置人物只有短暂注视。
- Codex 对候选逐句语义审校，修改 162 句，删除 12 个模型额外重复键；原文、修改后文本及原因见 `review.json` 和 `edited-lines.json`。没有标称真人审校已经完成。
- 删去未经观察的腰牌、账册、行囊、天气、过往经历与身份结论；删去没有接话入口的要求/邀约，以及将裙装与能力高低关联的措辞。不存在称呼玩家固定性别的句子。
- 提示词、模型、温度、token 上限、thinking 参数、输入与内容哈希按批留档。返修第 1 批复用了格式错误的已返回正文，usage 为 null；另外两次格式错误没有保留 token 用量，因此不声称费用或总 token 精确可核。
- `python tools/appearance_barks.py generate` / `revise` 才调用模型；`compile` 只读取已审核记录。运行时仅加载静态 JSON。此轮没有生成或修改声音。

例句：宋茶娘见差服：“差爷……见这衣裳，我就顺口叫了。”；温素笺见布衣：“布衣也好，书页里又不看人衣裳。”；锦衣客见斗笠：“笠檐一遮，倒有几分江湖气。”

## 触发与边界

- 读取实际仍在玩家身上且未损毁的衣物与斗笠；从装扮、背包或剧情入口改变真实装备，都由同一观察器识别。
- 同时只选距离最近的一位合格观察者，范围 5 米，检查朝向、遮挡、可见性、身体状态和危险反应。只有屏幕内的说话锚点能消耗反馈。
- 冒泡与江湖见闻的说话人使用现有已知信息投影；未知姓名仍显示“？？？”，不因一句装扮感想泄露真实人物姓名或秘密身份。
- 原主当面识破、熟人盘问、通缉、余波、正式对白和战斗优先。普通装扮冒泡不掷骰、不改变关系、声望、物品、姓名知识、权限或奖励。
- 关闭面板才播放。收到队列不算已读，实际显示时才记忆并写一条江湖见闻；离开、换装或失去行动能力时作废未显示的旧句。
- `appearance.outfitFeedback` 保存待播装束、各观察者已看过的装束与 18 秒全局间隔。反复穿脱同一组合不能对同一人刷屏；读档保留记忆。旧档只建立当前穿戴基线，不补造以前的观察。试玩键独立。
- 此批针对衣物与斗笠，单独易容仍走既有认人/盘问流程。没有重做全屏装扮面板，没有给人物虚构新差事或免检资格。
- 沿用 `npc-speech` 与 `placeWorldSpeech`，没有新增正式 HUD、固定位置提示或字体/色值。删去解释性系统提示的需要，以转向和一句短回应表达效果。

## 验证

- 50 项针对性测试通过（装扮反馈、现有装扮规则、无行动能力者识破规则、冒名人情与身份权限）。
- 主入口/世界/模拟器语法检查通过；台词完整键、条数、长度、禁词和来源记录校验通过。
- 新增测试覆盖：取得与穿上分离；奖励不变；旧档基线；待播/已读存档；重复穿脱；距离、背对、遮挡和隐身；睡眠、重伤、拘押、点穴、哑穴、恐慌、交战；真实盘问优先；旧队列作废；面板关闭后才调度；实际显示后才记忆。
- 浏览器画面验收未完成。内置浏览器报告连接不可用；备用 Computer Use 在首次读取 Chrome 状态时，因无法可靠确认当前浏览器 URL 而终止。遵守终止要求后未再操作浏览器。
- 因此不声称 1280×850、1024×768、800×600 的遮挡/字体/浏览器错误检查已经通过，也没有生成“探索清屏”截图。`tests/appearance-barks-preview.html` 提供三档 iframe，内部 `appearance-barks-qa` 独立试玩可用正式装扮按钮验收，不覆盖玩家存档。

修改仅限本轮台词包、生成/审校资料、反馈模块、主入口少量接线和专用测试。工作区并行存在的身份后果、配音等改动不属于本轮交付。

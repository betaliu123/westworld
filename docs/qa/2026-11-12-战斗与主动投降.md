# 战斗与主动投降验收

2026-11-12，本地新章 v2。使用 `?playtest=combat-surrender-qa` 独立试玩存档，未重置玩家正式进度。

## 实际行为

- 挥刀命中后保留伤害、身份归因、目击与案件，先进入现场冲突，不自动打开问责。
- 武者在自身或亲近者遭袭时还击，官差按职责介入；普通人和旁观者逃离，受重伤的还击者也会逃。脱险后沿既有当面报案链求援。套索拘传沿用原有专门反应。
- `G` 与场景中的「投降」按钮共用入口。附近有看得见、能说话并知悉冲突的人时可用；优先官差。取消未命中的出招、停止移动并收刀，对方实际走近才进入问责。
- 隔墙、过远、失能、失声或重伤者不能接收投降。主动离开或重新攻击会取消交涉；关闭问责恢复冲突。投降本身不掷骰、不回血、不清证据，赔款与辩解次数不因重复打开或读档重置。
- 获准的十秒缓息真正暂停参与者行动，时间到或离开即恢复；同一前因不能重复申请。
- 气血低本身不弹问责或远程拘押。官差仍可在近身攻击实际造成伤害后制服玩家；向官差投降的问责页提供到案选项，接既有收押与牢房流程。

## 界面与实现边界

- 新入口只保留手掌图标、`G` 键帽和「投降」两个字；接应中显示「停手交涉」。解释放在悬停说明与中文 aria-label，不新增常驻说明段落或独立 fixed 面板。
- 投降按钮使用现有纸墨变量、正文与数值字体，服从详细面板和对白互斥；没有引入新的图标库。
- 复用既有问责选项、伤害、案件及拘押流程；未新增全过程押送动画、全城全知通缉、所有 NPC 独有的临场投降台词。没有附近合格接收者时，不会远程打开问责。
- 这轮 UI 验证覆盖战斗、长问责、蹲行和探索；没有据此宣称全项目的全部任务/人物面板组合都完成重新验收。

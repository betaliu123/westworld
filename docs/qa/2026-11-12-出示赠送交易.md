# 出示、赠送、交易验收（2026-11-12）

## 同日续修：面板内反馈与人物动作

出示、赠送、询价和成交现在保留同一个行囊面板。移除了操作开始时的关面板、通用动作镜头摇移、结束后重开面板，以及成功后自动切入对白镜头的过程。面板高度保持稳定，等待和反馈切换不使它上下跳动。反馈只落在面板内，不再同时复制到场景冒泡；开始操作会清理旧冒泡。现有配音仍使用人物声线；离开、换物或后续动作会使旧声音失效。

归还物品的来历问答留在原面板。真正的来历检定沿用统一检定组件，但组件嵌入当前面板；概率、实际掷骰、递交与奖励规则未改。后续剧情回应仍可从面板主动选择。接触前关闭或移动会中止；已经交付后的关闭不会回滚或复制物品。

主角使用独立的双手托展示物姿势，赠送时向前递出，手臂使用骨骼 IK 并逐渐收回。NPC 在正常状态下转向主角，使用查看／思考姿势，再进入交谈表现；危险反应、失去意识和距离／遮挡检查优先。没有让 NPC 因交谈而忽略危险，也未声称新增每种物品的手持模型。

## 行为与覆盖范围

| 用途 | 已接通的行为 | 结算约束 |
| --- | --- | --- |
| 出示 | 名册验看、路引、引荐信物、王府腰牌、原账与失物辨认 | 实物留在玩家手中。验看与收存分别记录，不把拿到原账当作已经读过。 |
| 赠送 | 副账献交、银戒归还、送药、名册交接、食物换消息任务、普通赠物 | 真正接触时转移一次；归还先认物、再问来历；穿戴、毒性与原主记录随实体保留。 |
| 交易 | 普通物品换钱或换 NPC 的实际库存，食物换已配置情报，副账换对应路线凭书 | 先报价，再明确成交。重查钱数、库存、身份与所有权；取消和过期报价不扣物。原主不会花钱买回认出的失物。 |

任务按钮改为打开行囊的入口：`ch_ledger_commit`、`ch_return_ring`、`ch_list_show`、`g_present`、`if_identity_handover`、`ap_medicine_give` 和 `ap_news_*`。实际交付还会核对所选实体，不通过任务按钮自动挑物。

统一检查距离、遮挡、双方存活、接收者意识、冲突状态与确定的身份矛盾。递物动作在接触时结算；接触前移动、受伤、Esc、物品不在手中、目标失去接收条件均中止。接触后已经完成的转移不因跳过表现而撤销或重复。

## DS 与特殊物品

- 错物、普通物件与拒绝交易先即时显示本地反馈；DS 只在给定的拒绝／追问意图中选择并补一句话。不会决定钱物、概率、放行、奖励或罪名。面板关闭、对象或选物变化、读档、进入另一动作后，过期回复不补播。
- 请求不发送物品毒性、原主、偷窃历史或真实易容身份。离线、超时、格式不符和越界文本使用本地反馈。
- 王府腰牌由现有锦衣客实际持有，v2 存档只补建一次，不复制已转移的腰牌。只承认“持有王府腰牌”，不授予王爷身份、姓名知识或势力职权。
- 当值守卫验牌时检查现有通缉／报失与原主当面否认。不能主动观察或说话的原主不作揭穿者。放行与拒绝均是确定结果。
- 十条特殊反馈已完成一次显式离线 DS 生成，并逐条核对规则事实；候选原样保留了输入句子。模型、参数、提示词、哈希、候选及 Codex 校对记录见 [离线批次](../offline/2026-11-12-item-responses.json)。按项目 AGENTS 的“离线台词批次需记录模型参数并人工检查”，候选仍标记 `humanReview: pending`。运行使用规则附带的本地文本，没有自动导入候选，也没有声称完成人工审稿或新增录音。

## 持有记录与追查

每位实际接触者保存物品、当时认定的行为者、面貌、衣着、时间及因果编号。卸妆不会重写旧记录。

先前持有记录只有与真实报失关联，且负责官差自己看过或与知情者近距离、无遮挡交谈时，才成为该官差掌握的持有线索。它提高核问风险，不能直接生成偷窃目击、扣通缉或全城共享知识。危险或无法观察、开口时不传播。

关联会产生 `item_inquiry` 本地余波候选，接入既有夜间 DS 选择与当面余波入口。回应要求核对经手记录，也可暂不回应；不重复发奖、不清除已有证据。AI 将持有说成亲眼偷窃或揭露身份时，改用本地核问句。

## 界面删减与边界

删除原有“选物后确认交给某人”的整段说明与单一提交按钮，改为“出示／赠送／交易”；作用说明放在悬停提示。沿用图标背包、关闭图标、现有纸色与墨色变量，没有引入新字体、色值或图标库。

通用交易目前是同一递物动作中的钱物结算，没有把它写成已完成可偷取的钱堆演出；茶钱等已有实体付款继续沿用原系统。新增追查是已有调查与余波机制中的线索关联，不是自由生成案情或自主定罪。没有新增船行、宴席、完整拜师、高阶动作或声音内容。测试使用独立存档，没有覆盖玩家进度；旧服务须重启后才会加载新增的 Python 接口分支。

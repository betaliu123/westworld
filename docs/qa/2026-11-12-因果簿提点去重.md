# 因果簿提点去重

截图中的同一次来访在开始时生成“上前提点”牌，听完时又由通用发牌逻辑生成线索牌。两张牌共用对白，同时“再度相逢”和“当面提起”过程记录也被全部列出；不是线索获得了两次。

- 完成提点时更新原牌，使用实际话题、线索摘要及听完时刻，保留原编号和因果来源。完成的牌移到记录末尾，避免长来访刚完成就被历史裁剪。
- 普通因果簿把同一次完成提点的过程记录折入线索牌，保留因果跳转锚点；显式推演视图仍能检查底层记录。
- 旧档不改写。仅在人物、对白、前因、完成时刻和明确完成记录一致时折叠旧双牌；不凭相同措辞合并不同人物或不同次交谈。
- 取消、未完成或中断不假称获得线索。物品、关系、声望与线索结算未增加。
- 默认界面撤下这次交谈重复的“上前提点”“再度相逢”“当面提起”记录，保留话题、说话人和完成时间；未新增视觉样式、颜色或图标。

验证：

- 修复前新增回归用例稳定复现两张牌，修复后通过。
- 全量 `node --test --test-reporter=dot tests/*.test.js` 通过。随后补充长来访历史排序保护，最终相关 51 项回归通过，包括读档、重复回调、取消、不同人物/时间/前因、真实余波与旧档只读投影。
- 1280×850、1024×768、800×600 的旧双牌与新交谈各检查一次，均只显示一张线索牌，无溢出、小于 14px 字号或禁用字体；关闭入口可用。刷新续档后仍只有一张。
- 游戏页面错误为零；浏览器扩展自身的超时不计作游戏错误。试玩使用独立 `playtest=causal-ledger-qa`，未读取或覆盖正式玩家存档。

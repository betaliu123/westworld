# 倒地押送

官差的实际命中将主角气血打到零后，先在原地播放倒地并停留；现场官差收刀、走近、俯身控制、押起，再共同走一小段，最后墨色淡出转入东北县狱。途中气血仍为零，不能借调息跳过拘押。牢房坐标、刑期、线索和原有拘押结算沿用现有规则。

原先“官差命中后气血不高于 25 就立即入狱”改为真正归零才进入上述流程。主动自首沿用现有流程。

押送前保存官差认定的行为者和案情；最后转场时才结算一次风仪损失。中途读档重接演出，已入狱读档不重演、不重复扣除。官差失去行动能力、与玩家失去接触或无法走到玩家身边时中止，保留原有证据，回到倒地调息入口。

表现边界：这是现场短距离押送与省略路程的转场，不是完整步行到县狱，也没有新增绑绳实体或拘押物品。押起复用倒地骨骼姿态反向采样，官差俯身及押送手势采用骨骼叠加。没有新增长期提示文字或结果卡；被捕期间不显示普通倒地的“按 R 调息”提示。

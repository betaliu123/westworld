# 易容识破依据修复

## 现象与定位

周伍长、符祥的「身份识破」对白使用「耳后膏痕」等检定失败台词，玩家无法判断实际触发的是目击换脸还是易容检定失败。

- 两人都不在赵行商的熟人关系中；私下易容为赵行商，仅靠近或交谈不会触发熟人盘问。
- 当面使用易容膏会记录目击：距离不超过 6 个场景单位、朝向满足视野、无遮挡、人物可见且能正常行动。目击者不需要认识原主，后续接触时可以确定识破。
- 另复现了错误路径：周伍长目击燕七面貌的行为，玩家远处换成赵行商后回来，警觉更新仅凭再次看见玩家就写入 `identifiedSerial`，导致没有目击换脸也确定识破。
- 用户截图未包含当时的存档和完整操作过程，因此无法据截图确定两次遭遇具体来自哪条路径。

## 修复

- 警觉更新只接受实际记录的面貌转换作为认人依据，核对转换前后面貌及本轮序号；不能在后来见面时补造目击。
- 私下重涂同一张脸不会洗掉对该面貌的追踪，也不会因此凭空识破易容。旧事件归因、通缉与关系记录保留。
- 确定识破区分「亲眼见过易容」与「已揭穿此轮面貌」。前者明确说「我亲眼看见你换了面貌」，后者只说明已经识破；均不再抽取「膏痕露馅」台词。
- 原主当面识破、熟人同时看见原主和冒名者的规则保留；普通盘问仍使用原有概率与检定表现。

## 验证

新增 `tests/disguise-recognition.test.js`，覆盖：

- 周伍长、符祥不认识赵行商时的自动接近与主动交谈。
- 听过传闻后的盘问、取消不掷骰、预览与结算一致、成功与失败、通过后的免重复盘问期。
- 当面易容及读档后的确定识破和实际对白。
- 遮挡、背对、距离、不可见、睡眠、受制不构成目击。
- 旧警告、交战、搜索、返回状态下，私下换脸后再见面，以及读档继续。
- 真正目击换脸仍识别；旧事件不改归因；旧识破记录不虚构目击原因。

身份、盘问、通缉、余波、交互相关 89 项测试通过；战斗、案件、NPC 日常、配音与纲车余波相关 52 项测试通过。修改文件语法检查和 `npm run check` 通过。

本次验证为规则与交互控制器回归，未进行浏览器场景截图验收。未改 HUD 布局，未生成新配音，未迁移或回滚玩家存档中的历史结算。

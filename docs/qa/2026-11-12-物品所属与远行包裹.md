# 物品所属、六扇门公物与茶棚远行包裹（2026-11-12）

本记录已按后续要求更新：包裹移至树左侧，场景箱子、包裹及其散落物取消取物检定；NPC 随身扒窃和身份盘问仍用各自原有规则。

## 已实现

- 场景物品的操作面板统一保留“所属”，不会再被箱子、床、门等专用操作覆盖。六扇门箱标明公物和顾钦差看管；茶棚包裹标明宋茶娘。未知物主不泄露真实姓名，玩家自己放下的物品显示属于自己。
- 开箱与取物使用同一事实检查：距离、遮挡、物主视线、行动能力、当前面貌及实际权限。浏览不掷骰、不转移物品。未获准当面开箱时，顾钦差出声、转身走近并伸手制止，箱子不打开；重复点击短期不重复喊话或处罚。
- 视线外按 Z 蹲行可以打开查看；确认取物后直接转移，不掷妙手骰、不播放取物检定、不扣检定体力或增长熟练度；接现有现场目击、问责与调查。实际阻拦、隔墙、距离及物品已不在仍会阻止转移；无人目击不凭空增加通缉。取走的实体保留原主、转移方式、目击者、行为者及因果编号。箱子已打开也不能绕过后续检查，破坏箱子后的散落物仍有主。
- 六扇门正式成员须携带有效腰牌；衣服本身不授权。六扇门人物或王爷的面貌走实际认人规则，原主当面、已揭穿、过期、双人在场等矛盾不被身份权限覆盖。需盘问时接现有质疑、解释、检定、回答，通过后返回箱子；没有任务前置，也不自动开箱或领取。应奉局名头不提供六扇门公物权限。
- 女装旧木箱换为茶棚树左侧的布包：露出罗裙衣角、布结和展开的包布，打开后显示现有衣服与药盒。坐标为 (-14.5, 29)，物主为宋茶娘，说明为给女儿准备的远行衣物；原屋内木箱及碰撞移除。茶棚外桌同步改为宋茶娘所有。
- 保留原物件 ID linxi-wardrobe-chest、库存实体与 stocked 状态；旧档只迁移容器的位置、外观和剩余物品所属，已取得的衣物不回收、不补货。伤害、毒性、已有物品流转记录不重置。

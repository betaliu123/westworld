# 小地图跟随玩家

原小地图将世界原点固定在画布中央，比例为每单位 2.5 像素。164 像素画布的圆形裁剪只能容纳原点周围约 32 单位；玩家在南侧、溪边等位置时，自己的标记会被裁掉，地形也一直停在城镇概览。

改为以当前受控角色的实际位置为中心，北方始终朝上。玩家用带纸色晕边的墨色朝向箭头表示；建筑、河道、NPC、已知势力驻地、盘查范围、事件和寻路终点使用同一坐标投影。地图事件点击使用上一帧实际绘制位置，并换算 CSS 缩放尺寸，避免移动后点击错位；事件更换或在圆形裁剪外时不会误开事件。

地图只改显示，不修改世界位置、判定、盘查半径、存档或未知据点条件。保留现有右上角布局；没有新增常驻文字，原来的玩家圆点改成朝向箭头，方向说明仅放在辅助功能名称内。事件圈取消渐变脉动，使用现有墨色规范的静态圆圈；寻路目标使用石青。

# 符祥候人与溪边线索

在新章纲车仍候人、符祥可接话且实际持有名册时，首次点击符祥的对话入口直接播放：

> 宋青禾怎么还没到？她常去西边溪畔，这队人都等了许久了。

同一轮提供「我帮你去找找」「告辞」。选择找人后播放玩家回应，随后沿真实道路自动走向溪畔卧石后；移动仍可中止寻路。告辞不接行动，再次交谈保留找人选项，不重复播放候人话。已听候人缘由或已听青禾心事后，候人冒泡撤下。

新增两张本地门路线索：

- 黄旗下候人：茶娘、老捕、行商可提供，指向车旁的符祥。
- 石后的哭声：茶娘、老捕、补衣人可提供，指向卧石后的固定可达位置；卡面、台词与目标不揭露青禾身份。

正常打听与主动来访提点共用候选，完成对白后才登记线索。两张牌均可直接选择前往，记录来源、目标与下一步，并复用任务追踪/取消追踪。不同人物不重复发同一线索。直接问符祥会将溪边线索更新为寻访宋青禾；亲口听完青禾心事后完成记录。先找青禾再找符祥，不要求补接找人。冒名青禾仍走原有核名随车入口。

本轮复用现有对白、任务区和寻路表现；省去首次符祥交谈前的选话题步骤，没有新增面板或按键说明。找人不会替青禾答应随车，不给物品、好感或奖励，也不自动得知她不愿随车的心事。新台词使用现有内容哈希及字幕回退，不改变人物音色，未批量生成配音。

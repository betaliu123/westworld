# NPC 战斗动作与右侧投降入口

本轮替换战斗时的旧摆臂表现，并将投降入口移到右侧。试玩使用 `playtest=combat-surrender-qa` 独立存档，没有重置玩家正式存档。

## 实现

- 从作者页面下载 Quaternius Universal Animation Library Standard，CC0。来源、原始授权和可重复转换命令见 `assets-src/animations/quaternius/RETARGET.md`。
- 七种实际骨架分别转换戒备、追击、逃跑、挥击、拳击、受击和受惊；校正 A/T 绑定姿势、手腕扭转和手指随动。赤锋、差役、符祥不再套用其他模型的日常动作包。
- 武器绑定真实右手，以掌心、手指方向确定握点和剑锋朝向。实际脚底接地修正只作用于视觉模型。
- 拔刀受惊短暂停步、抬手防护；目击冲突先反应再逃离。受击打断挥击，再回到当前战斗或逃跑状态。实际气血下降才触发受击，不用动作预演伤害。
- NPC 复用主角的可中断挥击时钟。每次挥击 1.12 秒，约 0.5 秒接触；接触时重查距离、朝向、遮挡，每刀至多一次结算。退开、隔墙、受伤、失能、进入对白或投降可打断。
- 移除挥空时的方块粒子雨；真实命中只留短促墨色接触反馈，沿用实际受伤音效与主角受击动作。
- `G 投降` 置于 `hud-context-stack` 的右侧子行；移除纸色底板、大边框和按键阴影，保留手势图标、14px 键帽文字、中文 aria-label、悬停说明与键盘焦点。交涉中文字缩为“交涉中”，对白期间隐藏。

## 验证

- 本轮战斗、NPC 动作、主角动作、投降和介入流程的 68 项针对性测试通过；动作资源额外检查实际模型哈希、有效四元数、无水平根位移及剑锋朝外。
- `npm run check` 通过。此前一次完整回归 910/910 通过；并行工作继续增加/修改测试后，最后一次全量快照为 913/919，6 项失败位于其他剧情与配音检查，详见 `cc_task/2026-11-12-npc-combat-motion/final-full-tests.txt`。未修改这些正在变动的剧情与配音实现。
- Chrome 独立试玩用实际 `/`、左键命中、`Z`、`G` 和点击投降：受害者进入战斗、茶娘真实逃离、NPC 反击实际扣血；投降后接问责，未立即按攻击键就弹问责。
- 1280×850、1024×768、800×600 均检查。投降按钮透明背景、无阴影、正文 14px，分别居右；1024 宽时 x=921.64，800 宽时 x=697.64，按钮约 86×34。与交互、蹲行、属性区、快捷物品及右下技能入口不相交。800×600 问责选项可滚动，关闭按钮可见。
- 实机验收未捕获游戏页面错误。浏览器插件自身日志未计作游戏错误。

## 边界

这是共享战斗基础动作，并未制作每种门派、长枪、短刃的专属招式。仍沿用现有武器模型；特殊非 Mixamo 戏曲骨架保留原表现。长袍、宽袖仍使用现有蒙皮，不等于完成布料模拟或所有服装的穿插修复。未复制或发布主角未经确认可再分发的本地动作源。

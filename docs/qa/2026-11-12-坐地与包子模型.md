# 坐地与包子模型

- 瘸张白天回到原落脚处闲坐；周大石候车、用饭可坐地，纲车行进时恢复站立行走。无凳处打盹使用屈腿坐姿，有凳、床铺沿用各自姿态。
- 坐下约 1.1 秒，普通日程移动前先起身约 0.65 秒；受击、死亡、点穴、捆绑、落水、危险和实际移动优先。姿态只作用于可见骨骼，不移动碰撞根节点，不发放恢复或奖励。
- 周大石坐下时货担落在身旁，仍读取其实际持有物；坐姿对白下调镜头焦点。
- 包子统一使用单一可射线命中的褶皱面团模型，覆盖摊位、手持、落地。摊位资源加载后对实际表面做射线定位，消除悬空；尺寸调整为约 0.20 米直径。未修改物品归属、消耗、毒性、检定与付款规则。
- 新增可见文字仅在独立验收页，不给正式游戏增加说明或按钮；未修改声音。

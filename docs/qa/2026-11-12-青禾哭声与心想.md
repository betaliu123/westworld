# 青禾哭声与心想（2026-11-12）

## 实现

- 青禾在溪边石后独处、未听过她的心事且尚未同意随车时，坐姿增加抹泪与轻微抽泣动作。使用本地 SeedAudio 非语言哭声，短段间隔约 26 秒；声源跟随实际人物，距离衰减。小石块允许声音绕行，建筑和墙体仍阻挡。
- 石外听到哭声时，少侠心想「（石头后有哭声……奇怪，或许可靠近看看。）」。已经看见她时改为「（那位姑娘在低声抽泣……过去问问吧。）」，不提前透露姓名。
- 青禾说明想去京城听曲、却不愿被花鸟使催着随这一趟黄旗车走。听完才记录她的意愿与名册线索；取消对白不记录。追问改为「那你自己如何打算？」，避免重复问已答过的意愿。
- 退出对白后，少侠心想「（她不愿随车走，名册却记着她……若能扮作她的模样，或许可以冒用她的身份，混入车队。）」。车队已经出发、玩家已入城或青禾已同意同行时不再提示。
- 两类心想沿用现有静默心想与存档去重，不配主角声音、不新增按钮或常驻 HUD 文字。提示不授予易容、姓名、名册或青禾的同意；冒名通行仍检查原路线的实际条件。
- 进入交谈、切页、静音、危险、失能或离开听闻范围时停声；更高优先级的受伤、警报反应可以打断。静音保留文字线索。听过旧版心事的存档不重新哭泣，可以补问一次新的随车顾虑。

## 音频

- 显式离线命令：`python tools/seed_sound.py --only npc-qinghe-cry --limit 1`。
- 成品 `assets/audio/world/npc-qinghe-cry-8fd7045ad1e73431.wav`，原音为同名 `-raw.wav`；提示词、模型 `seed-audio-1.0`、请求参数及哈希保存在场景音频清单。
- 处理后 2.195 秒，48 kHz 双声道 PCM16，峰值约 −3 dBFS、RMS 约 −22.88 dBFS，无削波样本。游戏只播放本地成品，不调用付费生成接口。没有更改人物配音分配或批量补录对白；新对白按现有内容哈希匹配，缺录音时保留字幕。
- 已验证资源可解码载入及播放调度；具体音色与哭声表演以实际试听反馈为准。

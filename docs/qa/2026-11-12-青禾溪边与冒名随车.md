# 青禾溪边与冒名随车（2026-11-12）

## 已实现

- 新章可在易容成宋青禾后，直接到符祥身旁选择「报上姓名，随黄旗车队进城」，不要求先问茶娘、接任务或取得青禾同意。
- 按用户补充设定修正：符祥只知道名册上的姓名，不认识青禾的面貌。普通情况下预览「姓名与名册相符 · 必定通过（100%）」，执行不掷骰、不插入身份盘问。亲眼换脸、已揭穿仍阻止通行；只有他确实听过的传闻才可能引出盘问，不能全城共享。茶娘与原主自己的认人能力仍保留。
- 符祥持名册候人时短念「名册上这个宋青禾，约好的时候到了，怎么还没来？」及「叫她认着黄旗来会合，莫非寻错了地方？」；获准随行、已经发车、封车、缺名册或无法值守时不使用这些句子。青禾的溪边第一句自语为「认着黄旗，随车去汴京……他们只说得这样轻巧。」。使用纲车上原有的真实黄旗，不新增导航浮窗。
- 符祥必须实际持有名册，货车完好、货物未被封存、两名押运人可行动且在车旁，才可发车。玩家作为名册随行人加入，不替代符祥或周大石的工作。
- 核名成功即授予过关许可、移除门栅与关口阻挡，不传送玩家。符祥先实际步行去公所，周大石另行拉车，玩家不必等车到门前。符祥与当值守卫必须都可接话、距离足够且无遮挡；已揭穿身份与待处理盘问仍阻止放行。收据冻结宋青禾身份、符祥及实际听见招呼的守卫、对应因果。
- 同一轮接符祥招呼与守卫确认；再问守卫时显示「现在可以进关了？」并给出放行后的回应，不再要求路引或担保。没有亲历核名的另一名守卫只回应关门已开，不凭空知道宋青禾身份。旧新章已获准但仍在车旁等候的存档按同一现场条件补放行，不重复记录因果、奖励或转移位置。
- 青禾默认在溪流东岸石后独处。坐下后交替托腮发呆、俯身拨水，涟漪随实际手部位置出现；短自语使用现有附近冒泡与冷却规则。石头有实际碰撞、遮挡和耐久，侧边留有接近路径。
- 旧新章存档中的青禾会自行步行前往，不重置伤势、关系、物品。危险、束缚、交谈等打断优先；饥饿时仍可去购买实际吃食，之后返回，夜间在岸边打盹。
- 修复随车试玩发现的转弯阻塞：两名押运人转弯时避开车角扫过的范围，计入人物到点前的停车余量；保持碰撞，不让车穿人。

# 临溪对白、心声与现场细节改写

2026-11-12。对应 [审阅稿](../临溪对白与心声改写稿-2026-11-12.md)，适用花石纲新章 v2。改动已写入当前工作区，未部署或提交。工作区同时有其他功能更新，本记录只说明本次改写与实际验证结果。

## 玩家现在会遇到什么

| 场景 | 已落实的变化 |
| --- | --- |
| 关口 | 首层直接问封关原因；守卫说职责和顾虑，不一次列出入城答案。责任心声需要先听过对应答复。 |
| 茶棚 | 烦心事、差费、女儿与门路分开问；两文报价同轮接受或拒绝。钱放下与差费收清分别记录；锦衣客确实在场看见才有相关担保话头。 |
| 衣架 | 六文报价后直接买或不买；确认购买后角色走近衣架取衣，获得与穿戴分开。衣服增加袖口补丁、针脚和领口布签。 |
| 行商 | 自报姓名与“韩校尉认得我”分成两次获知。路引仍在他身上时才护住左襟；取消对白不记已听，也不会永久撤下未听完的话题。 |
| 纲队 | 周大石先说缺不缺人、谁担差错；通融与实际入队沿用真实条件，不靠听过提示解锁动作。 |
| 锦衣客 | 按目击差费或受过照看来接担保；同轮选择和追问。确认后沿现有导航步行至守卫身边，等玩家跟上，当面作保；听完守卫回应才放行，主角不传送。 |
| 杜老捕、瘸张 | 托药、交药和消息台词缩短；物品、信息、已学会的技艺继续分别记录。消息仍需真实的一份食物，动作教学沿用现有实作。 |
| 水门、刻字摊 | 第三块朽木有可见破损差异，靠近看得见才有短心声；针囊身份、询价和买药分段，同轮明确拒绝。 |
| 青禾 | 想去京城、反对被擅自填名、看名册与讨论替行分开；加入暂缓回应，讨论同意记录具体约定。 |
| 桥头 | 沈砚的烦恼与苏晚的意愿各自表达；劝让路启动真实移动。归还戒指不等于婚事答应，心声检查实际归还经历。 |
| 阿青 | 研药的帮忙与还欠情使用不同前提；购买草药、接受研药与拒绝均同轮回应，研药仍启动操作流程。 |
| 旧账房 | 先讲遭遇，再问原账所在，再决定接账；已经拿走原账时承认当前事实。护账细节只在原件确实随身时出现。 |
| 四方献账 | 六扇门、应奉局、青竹会、赤砂帮分别说明要账的用途；实体原账、出示与正式交付仍走统一物品规则，具体回报保留在选项中。 |

首层的“交谈”中转被移除；超出三句的话头按内容折叠。报价不再要求退出、重新问候后再找购买入口；菜单返回、关闭沿用现有笔意图标。导航不发奖、不掷骰、不播放填充对白。

## 心声与动作

新增心声按真实见闻、可见距离与遮挡判断，均使用全角括号、十五字以内，保持静默。按档保存已读与地点去重，共用二十秒间隔；对白、检定、战斗和详细面板优先。受打断的心声重新检查事实，不排队补播旧情境。

旧版关卡阶段驱动的长篇自语在 v2 停用。当前短心声涵盖守卫责任、差服相似、拿衣未穿、旧名、护襟、熟人认脸、担保人情、朽木、女儿意愿、还戒边界与原账未读。

补衣、护襟、护账、擦杯使用现有角色骨架与手部目标；布料、针、账页及服装细节为项目内程序生成模型，无外部下载素材。动作让位于移动、危险、失能、授艺和正式演出。当前是粗模和上肢动作，不包含精细手指、布料模拟或面部表演。

担保的两句对白使用关外机位，避免城门栏杆挡住说话人。到场未完成的担保可在取消、离开后返回或读档后恢复；失能、受伤过重、冲突、距离和视线均重新检查。

## 配音

继续使用 `assets/audio/voice-cast.json` 中的人物固定音色。本轮三批共生成 70 条录音；当前章节离线清单 170 条，全部命中缓存。未改句子复用，修改文字按内容哈希索引；旧文件保留，但不会配给新字幕。心声不在声音清单中。

一批请求遭遇服务 504，已复用成功文件补齐余项。记录见 [最终缓存计划](dialogue-rewrite/voice-final-plan.json)、[补齐批次](dialogue-rewrite/voice-completion.json)、[音频解码检查](dialogue-rewrite/audio-check.json)。这 170 条是本批明确清单，不代表所有动态对白及全部身份组合都有离线录音。未逐句人工听审，不以解码成功代替发音与情绪表演评价。

## 验收证据

- 当前工作区 Node 全量回归：855 / 855 通过。与本次直接相关的章节、对白、师承、献账、纲队与声音测试：91 / 91 通过；包含新增 9 项改写测试。
- Python 配音缓存测试：6 / 6 通过；170 条清单录音完整解码、有效时长、非静音与索引时长检查通过。
- 浏览器使用独立 `playtest=dialogue-rewrite-qa` 存档，接口离线兜底，未写入正常玩家存档；[结果](dialogue-rewrite/browser.json)中没有浏览器运行错误。
- 实际点击验证：关口具体问题直接可选；姓名对白取消后仍可重问；姓名与熟人信息分别听完才记忆；六文报价后明确拒绝不消费；确认买衣后走到衣架取物、不自动穿戴；持衣读档不重复扣钱。
- 担保实玩通过真实按键跟随：锦衣客步行约 6.66 个场景单位，三人到场，听完才放行，主角坐标不跳变。单元验证另覆盖失能、遮挡检查、远离、取消、读档与重复完成。
- 1280×850、1024×768、800×600 的对白卡与关闭入口可见；探索截图和可见 DOM 字体检查通过，无小于 14px 字号及被禁用的字体。

## 演出边界

船行、赴京、宴席和完整高阶拜师没有因这次改稿变成完整场景。阿青拦住多加药粉的精细接触、逐件改衣和更多表情停顿也未作新演出验收；本次落实的是明确话头、事实条件、短心声、已有实作流程和上述现场动作。城内分支通过规则回归，浏览器重点实玩关外主链，未把每一城内分支都标为逐场视觉验收。

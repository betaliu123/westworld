写法约定：
- 剧本只写**关键节拍**和必须由人定下的台词。其余反应由模板台词库和实时生成补足，并遵守文风规范。
- 方括号里是触发条件，圆括号里是动作或旁白，全角括号里是主角内心。
- 每一处"可以做什么"都由通用动作完成，剧本不列选项菜单。
- 主角沿用现有男性主角，NPC 按"对方眼中的主角"称呼他。

## 序 · 花石纲

（晨雾里，汴河上一串纲船吃水很深，船头插着黄旗。岸上民夫拉纤，号子拖得很长。）

题字：宣和四年 · 秋

（临溪关前，两扇关门正在合拢。主角背着行囊走到门前。）

**韩校尉**：关门！纲船过完再放人。

（一匹白马踱到关前。马上的人穿黄袍，袖口绣着折枝花。他手里提着一只空鸟笼。）

**符祥**：韩校尉辛苦。今日进出的人，一个个看仔细些。
**韩校尉**：是。

（符祥的目光掠过茶棚，停在灶台边的宋茶娘身上。）

**符祥**：茶娘，你家闺女呢？
**宋茶娘**：早许了人家，下月过门。
**符祥**：许了谁家？听雨楼的柳掌柜说，她还没有婆家。

（他笑了笑，打马进关。关门在他身后合上。）

**韩校尉**：（对主角）你。路引。
[没有路引] **韩校尉**：没有就站到边上去。今日不比往日。

（主角退到路边。）

（门不开，总有别的开法。）

> 序幕结束后不再给任何指引，玩家自由行动。纲队每日辰时、申时各过关一次，错过可以再等。

## 第一幕 · 临溪关

### 场景与在场人物

- **关口**：韩校尉、周伍长；纲队过关时，符祥、监工、民夫也在。
- **茶棚**：宋茶娘、锦衣客、杜老捕。
- **驿舍**：补衣人；衣架上挂着寄补的差役服。
- **路边**：赵成，在等饼，路引揣在左襟。
- **刻字摊**：刻字人。
- **码头与水门**：纲船、船工；水门第三块闸板已经朽了。
- **西郊乞丐窝**：瘸张。

### 茶棚

**宋茶娘**：客官吃茶。今日门上不好过，花鸟使在点人。
[问起花鸟使] **宋茶娘**：点花，点石，也点人。去年东村的绣娘进了园，就没再出来。
[问起女儿；需要好感，或者听到过序幕的对话] **宋茶娘**：青禾在镇上帮工。……你问她做什么？
[白喝了她的茶] **宋茶娘**：这一盏算我请的。下一盏，可要见钱。

**锦衣客**：这茶粗，水却是好水。可惜了。
[问身份] **锦衣客**：赵闲舟。闲人一个，舟也是借来的。

**杜老捕**：后生，腰直起来站，才像个差人。

### 观摩：杜老捕出手（点穴的入口）

[纲队过关时，有一个民夫脱队往茶棚后面跑，监工在后面追]

（杜老捕放下茶碗起身，两指在那人肩后一送，那人就僵住了。）

**杜老捕**：跑不掉的。歇口气，再想。
**监工**：多谢老爷子！
**杜老捕**：不必谢我。他腿上有伤，你们走慢些。

> 写回的事实：主角亲眼见过点穴（观摩）。杜老捕对监工态度冷淡，对民夫心软，这是拜师时可以接上的话头。

**拜师** [见过点穴，且杜老捕好感或信任达到门槛；门槛靠帮忙获得，比如替他从驿舍取药、在纲队面前护住那个民夫]

**杜老捕**：想学？先替我把这碗药端稳了。
（主角端碗。旁白：药汤一滴没洒。）
**杜老捕**：看见了？不是戳，是送。先认穴，后认人。点错了人，比点错了穴麻烦。
→ 学会点穴入门。
[学成后，主角用点穴伤了无辜，被他得知] **杜老捕**：我教你的东西，你用在这里？

### 西郊乞丐窝（落脚处之一）

**瘸张**：来了就坐。这里不问名字，名字值钱。
**瘸张**：一个饼一句话。两个饼，我说实话。

瘸张能卖的消息，每条只卖一次：
- 水门第三块闸板，去年就朽了。
- 赵成那胖子，路引揣在左襟，睡觉都按着。
- 驿舍衣架上那身皂衣，是县里差爷寄补的，明早来取。
- 纲队里的民夫，脸都是黑的。

[歇息] **瘸张**：那草堆归你了。夜里别翻身，压着人。

**眼力拜师**（入门）[在乞丐窝歇过一夜，并且至少买过他一条消息]
（瘸张蹲在路边，看过路的人。）
**瘸张**：看人先看鞋。鞋底磨哪边，人就往哪边歪。
**瘸张**：那个挑担的，左肩低，担子里有铁器。你去看看。
（主角探查那个挑担的人，验证他说得对不对。）
→ 学会眼力入门。熟练要找杜老捕：**杜老捕**：看人身上有什么不难。难的是看出他在怕什么。

### 开局的三门野路子

主角开局粗通点穴、妙手、眼力。入城前第一次使用时，用主角内心点出"会，但不精"：
- 点穴失手：（手生了，没送到穴上。）
- 妙手只能蹲着从背后取：（站着伸手，太显眼。）
- 眼力只看出个大概：（包裹沉，是什么看不出。）

拜师之后，同一件事的变化要让玩家看得见：从背后变成可以正面出手，定身更久，探查能看到包裹里的具体物件。

### 阿青：主动救治

阿青是这个世界里会主动跑向伤者的人，不只救主角。

**日程**：每日清早出关到西郊采药，辰时后回临溪镇，在街边替脚夫敷药。所以入城前后都可能遇到她。

**她会赶来的条件**（全部由本地规则判定，不等 AI）：
- 主角气血低于四成，或者倒地；
- 她亲眼看见，或者有人告诉她：茶娘、瘸张、周大石，或者任何好感不低、正好看见的人，会跑去找她；
- 她自己没有危险，没有被定住，也没有在救另一个伤得更重的人。伤得更重的人优先，哪怕那人是被主角打伤的；
- 主角没有正在和人交战；交战中她只会远远站着等。

**演出**：她沿真实路径小跑过来，蹲下，打开药箱，包扎，气血实际回升，伤口止血。主角如果走开，她会追两步，然后放弃。

**台词**：
| 情形 | 台词 |
| --- | --- |
| 第一次 | **阿青**：别动。血还没止住。 |
| 包扎时 | **阿青**：我娘说，伤口会骗人，不疼的地方才要紧。 |
| 包好后 | **阿青**：药钱先欠着。下回替我采一把车前草。 |
| 第二次及以后 | **阿青**：又是你。这回是谁的刀？ |
| 主角刚伤了别人，她先去救那个人 | **阿青**：你等着。他比你重。 |
| 主角背着海捕文书 | **阿青**：我只管伤，不管案子。别在我这儿躲。 |
| 主角拒绝医治、走开 | **阿青**：……随你。 |

**欠情与收益递减**：
- 每次救治都记一笔欠情（车前草、药钱，或者替她跑一趟腿），会真实出现在人物卡上。还清之前，她仍然会来，但话越来越短；欠到第三次，她会要求先还一件，否则只简单止血、不再细治。
- 同一天最多主动来一次。
- 救治两次以上，等于完成了医毒的"观摩"；还清一笔欠情，就满足了"结交"。之后她会说：**阿青**：能救人的药，换个分量就能害人。你记住分量。→ 可以拜师。

### 门路一 · 身份（衣服或路引，加上名字）

**取得**：从衣架偷差役服；点穴或打倒赵成后搜身；在赵成的饼里下泻药，等他去灌木丛时取走路引；或者直接偷他左襟。

**补衣人**：（被问起时）这身是县里差爷寄补的，明早来取。
**赵成**：（自我介绍）赵成，东溪商帮的。饼还没好，人先饿了。

**盘查**

| 情形 | 台词 |
| --- | --- |
| 持路引，答对原主姓名 | **韩校尉**：叫什么？——**主角**：赵成。——**韩校尉**：……过去。下一个。 |
| 持路引，不知道姓名，检定成功 | **韩校尉**：过去。 |
| 持路引，不知道姓名，检定失败 | **韩校尉**：自己的名字都要想？这路引是你的？ |
| 守卫认识原主 | **韩校尉**：赵成我认得，比你胖一圈。 |
| 穿差役服 | **韩校尉**：县里新来的？杜老捕没提过你。 |

- 韩校尉喝了下过药的茶离岗后，周伍长接班：**周伍长**：校尉肚子闹了，今日我看门。叫什么？周伍长不认识赵成。
- 被识破后，称呼当场改口：从"差爷"变成"你"。

### 门路二 · 担保（锦衣客）

[锦衣客亲眼看见主角做过至少一件不为钱的事，例如护住民夫、替茶娘付账、把东西还给失主；并且没有看见主角伤害无辜]

**锦衣客**：方才那一下，不为钱吧？
**锦衣客**：我缺个牵马的。进了城，各走各路——也许不。

（主角牵马走到关前。）
**韩校尉**：这位是？
**锦衣客**：我的人。
（他袖中露出一角白玉佩。韩校尉的脸色变了。）
**韩校尉**：……过去吧。

> 写回的事实：主角欠锦衣客一个人情。

[锦衣客看见主角伤了无辜] **锦衣客**：身手是好的。下手的地方，不太讲究。（不再提出邀请。）

### 门路三 · 夹带（民夫队或水门）

**混进民夫队**：需要一身破衣，可以从乞丐窝换，也可以跟民夫换；脸太干净会被监工多看一眼。

**老民夫**：（主角挤进队伍时）后生，脸太干净了。抹把泥。
**监工**：低头，跟上！
[符祥在队前点人，主角离他太近] **符祥**：这个后生，抬起头来。——检定：妆扮，加上衣服是否合身、脸上有没有泥。
[被识破] **符祥**：民夫的手，可没这么白。

**水门**：知道闸板朽处的人可以破闸，需要膂力或工具；夜里更安全。会弄湿衣服，也可能呛水，按落水规则结算。

（闸板断裂，水门那边铜锣大作。）
**韩校尉**：水门！有人从水门进去了！
> 写回的事实：临溪镇戒备上升；如果有人看见主角，发出海捕文书。

### 门路四 · 强闯

**韩校尉**：关门！拿人！
[主角打赢] **周伍长**：（倒在地上）你跑不出临溪。
> 写回的事实：海捕文书，画像粗糙，衣着与主角当时一致；六扇门的路变难；赤砂帮会对主角另眼相看。

### 二、当街求婚（桥头）

之后，苏晚在河畔柳树下独自奏曲。这是**乐器的观摩入口**：
**苏晚**：你站了半天。听得懂，还是没地方去？
[关系达到门槛] **苏晚**：气别全吹出去，留一口给下一句。→ 学会乐器入门。
[赠乐器] **苏晚**：这支旧了，音还准。别拿它敲人。
[主角偷了她的乐器，后来被认出] **苏晚**：笛子认人。你吹一声，我就知道是哪支。

### 四、截纲船（码头）

在场：林青舟带着青竹会的人；段赤川、周大石和脚夫；纲船监工；稍后陆捕头赶到；符祥的黄封名册放在船头箱里。

**林青舟**：那船上装的不是石头，是一路的人命。
**段赤川**：截一船石头，痛快。百万漕工衣食所系，你截得起？
**林青舟**：你们扛的是饭碗，我知道。可这饭碗，是砸了别人的家换来的。
**段赤川**：少跟我讲道理。卸不完货，弟兄们今晚喝西北风。

主角可以：
- 帮青竹会割缆、掀跳板；
- 帮赤砂帮护船；
- 去叫陆捕头；
- 趁乱从船头箱里偷走符祥的黄封名册，册上有宋青禾的名字；

## 名号与名气（补全总纲未定项）

- 每个地界的名气为 0 到 100，墨点门槛为 10 / 25 / 45 / 70 / 90。Demo 中有两个地界：临溪关和临溪镇。
- 名气在某个地界达到 25 时，AI 提出名号候选，规则校验它依据的事实后生效。
- **第三个收束目标"名动临溪"**：临溪镇名气 ≥ 70，临溪关名气 ≥ 25，并且已有名号。达成后，符祥送来艮岳赏奇宴的请帖，成为进仙界的第五条门路。这样三个收束目标最终都汇到同一个结局。

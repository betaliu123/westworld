# 限时盘查提示与范围验收

日期：2026-11-11。承接套索与事后报案系统，新增玩家可见的盘查时限和范围反馈。

## 已实现

- 官差接报后的现场调查使用同一个持久截止时间，当前基础时限为 150 秒模拟时间，包含赶赴现场的时间。对话等暂停模拟时不继续扣时；读档延续剩余时间。
- 玩家在近处、无遮挡看见正在调查的官差，或被当面盘问后，才获知该现场。未察觉的远处报案不会提前在地图暴露。
- 已获知的调查显示笔意令牌图标、“官差盘查”和剩余分秒。范围内提示“逗留可能被盘问”，离开后切换“已离开盘查范围”；解释失败造成真实延期时，短暂显示“盘查延长”。
- 小地图以朱砂虚线红圈、淡色填充与四向短刻线标出现场。圆心取事发位置，半径与真实盘问区域共用 8 个世界单位，避免显示与判定不一致。多个调查分别显示，状态提示优先展示玩家所在区域。
- 截止时间到达后关闭调查，红圈移除，短暂显示“盘查结束”后清屏。官差昏迷或被捆绑也不阻止到期处理。已过期的对白选项不能再掷骰。
- 调查结束保留证据、通缉及既有后果；有明确证言转入追捕的案件不受这项现场盘查倒计时清除。

## 界面约束

提示放入既有 `hud-context-stack`，与附近交互和蹲行提示共同排布；对话和详细面板打开时由共享布局隐藏。未新增独立固定坐标、弹窗或常驻说明栏。

状态使用自绘令牌图标；文案仅保留状态、剩余时间和一句后果，地图用边界图形表达范围，不加入重复图例标题。字体采用现有正文与数值字体，字号为 16 / 14px，色彩取现有朱砂与墨色变量。

# 赴艮岳门路与声望传播验收

2026-11-12。本轮为本地实现与独立存档验收，未部署。

## 玩家体验

- 主页开局描述改为“临溪关前，花石纲先行，行人暂候。”
- v2 入城后保留“赴艮岳”主线，初始目标为在临溪打听门路。询问与追踪不绑定阵营，不要求先接任务才能取得或交付物品。
- 锦衣客、花鸟使明确承诺以花石纲副账原本换取赴艮岳门路。听完才能记下提议，同轮可选择追查或另寻门路。追查目标根据真实情报和物品状态更新，不自动揭露县狱线索。
- 原账交给一方后，其他献账阵营的分支关闭；锦衣客与六扇门属于同一查案方。购买运石队名额、正常获荐仍是独立可选门路。确认启程后不再覆盖已选结局。
- 六扇门常规荐举需要声望 50、真实引荐或交案功劳、案件了结且门内资格有效。实际押送燕七交案获得 30 点六扇门声望，垫付脚夫工钱的消息传到六扇门后获得 20 点，可在不献账时完成这条路线。
- 赤砂帮可支付 1000 文购买运石队通行票，也可凭声望 50 和帮中人情求取名额。名额不等于入职，也不能销案。
- 凭据为实体物品，记录领取时身份；须实际携带，重复领取与重复扣款无效。交接被移动、受伤、Esc 或新对白中断时不结算。

## 界面取舍

任务卷轴置于江湖录“事”的前部；足迹与名号默认折叠。只投影已经听到的门路，显示当前条件、消息来源和寻访图标。宽屏两列，小屏一列滚动；已关闭的献账分支划去并写明“原账另有所托”。

删去了重复的“线索”标题、主线重复解释，以及献账确认中的长凭据名称；凭据用途由前一句 NPC 提议说明，确认选项保留真实声望数值和分支关闭后果。寻访使用现有笔意罗盘图标，带中文 aria-label 与悬停说明；不增加固定 HUD 区域。

## 声望归因

声望读取目击与实际转述中的行为者，不由通缉数值反推身份。未被识破的易容行为不会在卸妆后改记到玩家名下；无人知道是谁做的失窃不能凭空发放帮派声望。

案件消息按距离、遮挡、人物意识状态与传播延迟流转，重复转述不重复结算；证据加强只补差额。六扇门对犯罪扣声望，传闻轻于目击或当面证言。赤砂帮认可盗取官物、对抗官面等胆量与手段，侵害帮众或脚夫扣声望，伤害普通平民不加声望。既有花石纲盗运余波沿用专属传播链，帮派认可改为 +12，不与通用案件重复结算。

服刑不会自动恢复已经损失的势力声望。地方名声与势力声望分别计账；数值由本地规则决定，AI 不决定奖励或揭穿身份。

## 实现边界

本轮完成入城后的持续目标、门路条件、凭据、献账冲突与结局记录。实际船行、仙山场景、到达后任务未实现。购票在现有递送动作结束时扣钱并给票，尚未迁移为可被截取的钱堆交易。没有生成新的离线配音，使用现有字幕及按内容哈希匹配的声音机制。

v1 不接入新目标；旧 v2 补录遵循真实提议与交付，过期任务追踪恢复到主线，玩家主动取消追踪仍保留。旧版锦衣客提议若未明确承诺赴苑，可重新询问新版提议，不重复授予信物或奖励。

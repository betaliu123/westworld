# 玩家打字辩解实验

2026-11-11。首轮范围：v2 易容身份盘问，以及通缉问话中的“试着辩解”。现场调查、余波问责和一般聊天暂未接入。

## 玩家流程

人物先质疑 → 选择“自己编一句” → 输入至多 120 字 → “斟酌这句” → 看意图、能力、成功率与难度 → “说出口” → 原话字幕、既有检定与人物回应。可以修改、返回固定选项、Esc 或关闭。分类和浏览不切动作镜头、不掷骰、不扣资源。

通缉问话的第一层仍为“试着辩解／随官差到案／拒绝到案”；辩解话题下一层提供自编与原有固定说辞。每层至多三项。输入嵌入共享对白纸笺，不新增固定位置 HUD。

## AI 与规则的边界

- `/api/reply-intent` 固定调用 `deepseek-v4-flash`，temperature 0、max_tokens 60、thinking disabled、JSON 输出。仅发送玩家拟说的话，不发送存档、人物秘密、成功率、骰子或关系图。密钥沿用服务端配置。
- AI 只允许返回一个字段 `intent`：identity（冒认身份）、connection（搬出熟人）、weakness（示弱）、clothing（说明衣着）、explain（解释来由）或 unknown。额外字段、非法类别和格式错误均拒绝。
- 身份盘问复用 `disguisePreview` / `checkDisguise`。identity、connection、explain 映射普通解释；weakness 只有真实低气血或实际病症才能采用现有伤病说法；clothing 只有真实穿戴物才能采用衣着说法。编出的伤病、熟人、官职、证件不会变为世界事实。
- 通缉问话统一复用已有狡辩公式和案件记忆。没有新增示弱奖励或关系加成。通过仍保留通缉与证据，失败仍触发真实追捕；已回应的同案不能靠改写一句话重掷，读档保留。
- 原主、已识破或亲眼目击等确定性证据不开放打字绕过。提交前重新核对面貌、现场、距离、遮挡、身体状态和当前案情；概率变化时先更新预览，需再次确认。
- 原话按纯文本显示并进入既有江湖见闻。通缉回应另在原有案件回应记录保存原话与意图；不会据此创设借口中提及的关系或许诺。自编句仅显示字幕，本次没有生成新声音或改变人物音色。

## 生命周期与降级

客户端十秒超时，服务端上游八秒超时；每分钟最多十二次、同时最多两次分类。异常、超时、离线和 unknown 都保留草稿，允许重试或返回原有选项，不代替玩家做动作。修改、取消、返回、关闭或被另一段对白替换会使旧回包失效；连续点击不重复请求或结算。中文组词期间不提交，输入框回车只换行。

## 验证

- 29 项针对性 Node 检查通过：含原有身份/通缉边界与新增分类、异步草稿、实际概率、取消、重复、旧档、同案证据变化和注入输出检查。两项 Python 检查覆盖接口请求、输出白名单、来源、限流与离线行为。
- 真实 DS Flash 五条虚构样例全部匹配预期，耗时约 0.55–1.17 秒；包含荒诞熟人说辞与要求直接成功、发钱的指令。仅证明这批样例，不能据此保证任意文本都分类正确。参数与结果见 `cc_task/2026-11-11-typed-reply/live-classification.json`。

## 实现边界

这是受约束的意图分类实验。NPC 接话仍来自本地已有结果对白；没有让 AI 即兴生成完整审讯、核实任意人名、兑现借口中的交易，或决定结果。纯文字的谎话可能被误分类，玩家在确认前可修改或返回固定说辞。

界面用图标保留返回和关闭；撤下输入状态中的选项编号、固定回应列表和键盘说明，只保留字数、规则预览及当前一步按钮。人物与案由沿用现有对白上下文。

# 10 · 手机与报纸

## 负责什么

玩家的随身信息中枢：手机（联系人/聊天/任务/股市/群聊）+ 报纸（镇上新闻）。以及消息治理（限流/去名字/分类/未读徽章）。

## 关键文件

- `ui/Phone.js` —— 手机 UI
- `ui/Newspaper.js` —— 报纸 UI
- `systems/MessageGovernor.js` —— 消息治理
- `systems/PhoneData.js` —— 手机数据（联系人/消息）

## 手机

打开：`Tab`。四个 tab：**👥 联系人 / 📋 任务 / 📈 股市**。

### 联系人聊天
- 每个 NPC 联系人可聊，快捷回复 + 自由输入
- **自由输入走 DS flash**（`respondPhoneChat` → `npcChat.respond`），LLM 挂了退化成关键词
- 聊天页头显示**好感度**（💖亲近/😊友善/😐普通/😒冷淡/😡厌恶 + 数值）
- 收服按钮（输入框上方）→ 远程收服（说服力按好感+名誉，低于当面）
- 未读徽章：手机标题挂红点数字

### 帮派群聊
- 招募成员自动拉入，有公告+欢迎，每天闲聊/拍马屁
- 群聊隐藏单人对聊选项和收服按钮/输入框

### 股市 tab（P13）
- 复用 StockMarket 渲染进手机容器，不用去银行也能炒股

## 报纸

- 玩家行为（抢劫/撞人/善举/置业）登报
- DS 生成股市新闻（`StockNewsService.settleDaily` → `newspaper.publishCustom`）
- 新头条弹提示，未读徽章

## 消息治理

`MessageGovernor.admit(msg)` 在投递时：
- **限流**：每 NPC 每天按优先级限条数（普通 2 / 低 1），紧急（人命关天）不卡
- **去名字**：剥 LLM 消息开头的"名字："前缀
- **分类**：urgent/task/money/faction/gossip/general
- **未读徽章**：有未读就挂数字

## 配置修改

手机布局：`index.html`；快捷回复：`Phone.js`；消息治理：`MessageGovernor.js`；报纸模板：`config/gameData.js` 的 HEADLINE。

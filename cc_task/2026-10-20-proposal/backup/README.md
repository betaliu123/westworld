# 江湖有回声 · 可玩原型

独立的 Three.js 武侠小镇，原西部项目无需启动。此版本优先验证自由操作与人物因果闭环。

## 启动

双击 `启动游戏.cmd`，或在此目录运行 `python serve.py`，访问 http://localhost:8091/ 。

项目不需要 npm install 或编译。Three.js 0.160.0 已作为本地依赖随项目保存，许可见 vendor/THREE-LICENSE.txt。

## 第一条试玩路线

1. 选择江湖游侠、风流书生或仗义刀客，进入临溪镇。
2. 向前走，靠近三人求婚现场，先听他们说话，按 E 主动介入。
3. 先从交谈、吃喝、示好、助兴、冒险行事、告辞等气泡分类中选择，再展开具体做法；推荐行为置前并标记，32 种做法均可分页找到。概率来自真实属性和关系。
4. 选择后收起气泡，角色播放交谈、拱手、鼓掌、伸手、饮酒、大吃、舞剑等对应程序动画，镜头短暂推近偏转，动作结束才显示结算。不会预告后续的日期、模板或结局。
5. 每个游戏日约四分钟，也可点击“歇一夜”。冲突中不能直接休息。
6. 后续由熟人飞鸽传书传达；点击信里的地点沿街寻路，到场不会自动弹窗。不看信，自己路过也能看见事件。
7. 喜宴、寻戒、对质、私下谈心、故人相托、和解均能继续产生选择和结果。

试试另一种路线：偷戒成功会带着戒指进入追查，失手会被目击、降低关系并留下嫌疑。主动归还会真正移除物品。不要把读档重新掷骰当作同一条测试记录。

## 操作

- WASD 行走，Shift 疾跑，空格跳跃。
- 左键首次只预备，三秒内再次点击才攻击；三秒不出招、Esc、交互或切出窗口会收势。J 直接攻击；右键拖动转镜头，滚轮调整距离。
- E 打开/收起分类气泡，Esc 关闭，Tab 打开飞鸽传书。气泡打开时 WASD、跳跃和右键镜头仍有效，走远自动收起；选动作时会重新检查距离。
- 动作使用当前简模的程序姿态动画（非外部动捕）；进食含碗和小凳，奏乐有竹笛。镜头轻推可被右键/滚轮接管，播放时仍可行走。
- 行囊查看属性、好感、物品与过去经历。
- 气血耗尽可按 R 调息；也可使用“歇一夜”。复活结束当前追击，人物回到各自地点，好感、记忆与故事后果保留。

普通 NPC 会行走、转身回应、逃跑、反击或倒地；捕头会追赶有嫌疑的玩家。普通人物也能结交、送茶、赔罪、问消息、做风仪或膂力检定。宴席客人是同一套真实 NPC，并非纯装饰。连续打碎三张宴席桌子和选项里的搅局使用同一套后果。

## 判定与 AI 边界

基础检定：D100 ≤ clamp(属性 + 40 − 难度 + 关系修正, 5, 95)。普通善意动作可必成，费用不足不可执行。界面展示的概率和实际结算使用同一函数。

AI 从现有合法行动中按能力、经历、风格推荐；在受约束的兼容后续中选择下一幕。AI 不控制随机数，也不能改写已发生的得失、物品归属或数值。网络失败时回退到本地画像推荐。真实发生的攻击、桌子破坏不会再掷一次骰子来否认事实。

服务端从本目录 .env 读取 LLM_BASE_URL、LLM_MODEL、LLM_API_KEY。浏览器只访问本地代理。客户端不包含密钥。服务器绑定 127.0.0.1。

## 文件分工

- src/data.js：人物、出身、八种场景、候选动作与来信。
- src/simulation.js：独立于画面的状态、检定、物品、关系、行为记忆、事件调度和存档数据。
- src/world.js：场景、角色、镜头、移动、寻路、攻击碰撞与反应表现。
- src/main.js：界面、操作接线、AI 推荐、音效、浏览器存档。
- serve.py：静态服务器与模型代理。
- tests/simulation.test.js：关键因果与边界回归测试。

## 当前原型范围

一座小镇、三种出身、八名命名 NPC、一条多分支故事链、八种场景模板。建筑与带关节角色为程序生成的风格化模型；动作是程序姿态动画，并未接入 AI 动作文件。声音包括合成提示音，中文台词使用浏览器系统语音，有中文语音包时可用。

尚未实现多人同步、任意 NPC 动态选角、多条长线 StoryTree 互相抢占、少女背叛长线、完整经济循环和商用品质战斗。本版验证的是可自由行动、检定与事实一致、世界后果持续、消息不打断游玩的可玩闭环。

## 验证

运行 `node --test tests/simulation.test.js`。实际浏览器已经验证：行走、疾跑、跳跃输入、出招命中、NPC 反击、脱战休息、随机检定失败、关系结算、次日来信、沿街寻路、到场不弹窗、AI 推荐、刷新后恢复进度。语音取决于本机浏览器安装的中文声音。

## 交互与移动修正

NPC 使用最短角度平滑转身、步幅夹紧防止越过目的地，行走权重和求婚跪姿渐变。女性角色移除了重叠内层衣摆，并调整阴影偏移减少表面闪烁。复活与首击预备逻辑保留。

## 人物属性与当场反馈

右上角「人物属性 · C」或 C 键打开属性、气血/体力精确值、盘缠、阅历、声望、嫌疑、NPC 好感与状态；数值实时更新。新结算包含人物头顶对白，并在经历记录中保存。开赌得手时结清赌约并获得 30 文庄钱，失败不收钱；两种情况均有冒犯当事人的社会代价。吹笛、舞剑、作诗成功分别获得 16 / 18 / 12 文赏钱。所有结算不可重复领取。

## 行动规则与 NLP 反应

`src/action-contracts.js` 为全部事件行为逐项定义成功事实、失败事实、动作与本地对白；不再用 kind 通用文案代替具体行为。规则结算收益、代价与检定，NLP 不得修改金钱、物品、骰子。所有检定都有阅历收益；关系、物品、报酬按行为区分。角色目前仍使用简模程序动作，多个语义相近行为共享动作类型。

`/api/director` 的 reaction 模式接收当前行动、判定事实、NPC 性格、前后关系、近期记忆和受限制的后续候选。回应经校验后进入 NPC 头顶对白与持久记忆，后续模板选择作用于未发生的 pending 事件。秘密取物不向角色暴露作案者。新的行为、重开存档或事件已到来时，过期回应不能改写新的因果。

网络慢时约 5.5 秒启用该行动的本地对白；迟到的有效反应仍可补充记忆并影响尚未发生的下一幕，不在现场重复播放两套对白。人物属性的经历记录标记“AI 推演”或“本地演出”，可核对实际来源。

验证：`node --test tests/simulation.test.js`；可选真实模型联调 `node tests/live-reactions.mjs`（使用虚构测试人物经历，会产生 API 调用）。最近一次联调记录在 `reaction-smoke-results.json`。

NPC 闲逛改为固定目的地与到点停留，接近玩家时使用 2.8 / 4 米的进入与退出距离，追逐和逃离也使用不同的进出范围。转身限制角速度，行走动作依据实际位移，交谈手势平滑混合，避免边界处反复切换。气泡菜单下移至人物下方，中央圆盘缩成标题牌。


### 底部对话与事件退场
- 底部自由输入及快捷回复；左侧选择附近人物。输入文字时不会触发行走、跳跃、攻击快捷键，Esc 返回游玩。
- `/` 或底部按钮拔刀/收刀；只有拔刀后的左键才攻击。互动、输入、倒地自动收刀。
- 自由回复先按可验证的行为结算（否认、归还、寻找、劝和），然后 AI 根据 NPC 性格、关系、记忆生成冒泡。一般聊天不凭文字修改物品或发钱。问题、假设和拒绝不会自动交出戒指；归还需对沈砚说并真实持有银戒。
- 偷戒成功立即进入寻找。25/50 秒时请求 NPC 决策继续找或散场，离线也在 75 秒封顶退出；回话不会重置时限。无人找回则次日出现“遗失的心意”，双方围绕丢失戒指争吵，传书仅作提醒，无需打开也会发生。争吵 65 秒自行散场，其他无人介入事件 150 秒退场。
- 明确归还会取消寻找/争吵；成功劝和改变后续模板。计时与记忆存档，刷新不会重新无限等待。


### 环境与自主行为试玩
右上角「原地卖艺」开始持续吹笛，再点收起；会消耗体力，附近有空的 NPC 靠近围观，每段按风仪判定打赏/风仪成长。同一听众每天只结算一次；移动离开或体力耗尽停止。
收刀后左键点击树、食摊、摊上吃食或掉落物，仅显示选中目标的操作；远处目标可点「走到附近」。F 打开独立的队伍行囊。果树可摇落最多三枚果子；树木与食摊支持 / 拔刀后正面左键攻击，显示耐久，受损摇晃、倒伏或塌陷。摊子破坏后停止营业，食物掉落，保留物品状态；次日只给完好食摊补货。
食物可购买、偷取、拾取、丢下、食用。试玩行囊赠送两份干粮及两份虚构道具「迷毒散」，可消耗药粉给自己或摊上的食物添加有毒属性。NPC 会饥饿、前往营业摊位购买、食用并产生对应效果；有毒食物使 NPC 受伤求助，之后摊主停业检查，玩家可递水照看。
靠近 NPC 后，在行囊物品下展开「偷偷放入他人行囊」，进行身法检定。成功后物品真正转移，NPC 稍后发现；只有食物会因饥饿被吃，药瓶本身不会自动食用。银戒与原有剧情物品归属同步，悄悄放回沈砚包里被发现后可结束寻找。
本轮覆盖场景中的树木和三座食摊；建筑和其他装饰尚未全量物件化。自由文本目前仍走原对话意图，新增环境行为通过按钮执行。
验证：node --test tests/simulation.test.js tests/ecosystem.test.js


### 街头模板事件
新增八个模板：两帮争路互殴、一曲引客、散落货担、一笔争账、伤后求助、坐下说话、熟客点曲、工钱与人情。
点击右上角小地图的热区查看当前事件并寻路；抵达后按 E 或点击现场阶段标记介入。面板不暂停世界。自主互殴会真实扣除两名 NPC 的气血，有拳击动作和受击反馈；街头卖艺有笛子与围观动作，搬货现场有散落木箱。
事件约一分钟自行收场。互殴可引出伤后求助，劝解成功可转入议和；合奏、打赏会引出熟客点曲；搬货/争账会接到工钱结算。玩家的具体行动分别有检定、成功失败文案与对白，AI 可补充人物反应，既定数值不会被改写。选边帮助某帮会改变双方帮派关系。
新增林青舟（青竹会）、段赤川（赤砂帮），兼容旧存档。街头事件占用的人物暂不被饥饿寻食或玩家卖艺拉走；进度、后续队列和关系存档。事件被暴力打断时中止，过期且不可用的后续会撤下。
验证：node --test tests/simulation.test.js tests/ecosystem.test.js tests/street-stories.test.js

### 自行演出的事件原型
新增抛绣球、比武招亲、集市窃案。当前街头事件结束后，优先安排尚未演出的新原型；同一局每场只演一次。重开从第一天试玩时，第一场会在入场约六秒后开始。
- 南街抛绣球：候场、争球、相识。玩家可在争球阶段接球或让球；缺席时 NPC 自行接球。接球只获得相识机会，姑娘可以拒绝，玩家也可以交还绣球。
- 北街比武招亲：报名、首轮、决胜、评议。NPC 先切磋；报名的玩家可用进攻、闪避、虚招争取得分，未报名则由 NPC 胜出。切磋非致命，获胜不会自动成婚。
- 集市窃案：踩点、下手、追逐、收场。燕七真实转移行商的钱款，陆捕头沿街追堵。玩家可预警、拦截或掩护；追回与逃脱分别保留资金、关系和嫌疑结果，地图热区随逃者移动。
红绸、擂台边界、飞行绣球、钱袋和 NPC 动作均在三维场景中呈现。演员位置、阶段、分数及钱款转移随存档保留；演员受伤、受惊或未能聚齐时事件取消，玩家不参与也会留下结果和人物记忆。
本轮先验证三场演出，强盗潜入、挟持对峙和更多追逐分支尚未加入。


### 双人队伍与选中目标（2026-10-14）
默认新增同行者阿笙。1 / 2 或左侧队伍按钮切换控制；被切离的角色原地等待，正在吹笛则继续。两人独立位置、血量、体力、属性；共享盘缠、行囊和江湖关系。C 查看当前控制角色属性。旧存档自动加入阿笙。
点击「与同伴说话」，可用快捷气泡或自由文本让未控制角色跟随、等待、吹笛、收笛、前往选中物品、拾取地面物品、购买一份选中的食物、摇选中的树。会真的寻路、校验距离、扣钱/体力、转移物品；失败、被买走、无法到达会说明原因。指令经现有 NLP 服务解析为白名单动作，离线使用有限关键词并标注「本地理解」。过期指令、非法动作和缺少目标不执行。
试玩：少侠原地卖艺 → 按 2 控制阿笙离开；少侠继续演奏吸引空闲 NPC，体力消耗和风仪增长归本人，打赏进入共有盘缠。队友只执行单步指令；暂不包含自主战术战斗、远程任意对象指认、多步计划或各自的阵营关系。刷新后保留位置/属性/物品，持续动作和未完成指令结束。
新增 src/party-state.js（存档与指令约束）、src/party.js（切换、随行、寻路执行、对白）；tests/party.test.js 覆盖双向切换的表演资源归属、共用物品与存档、购买结算、目标约束。


### 物件耐久、材质与元素（2026-10-14）
场景物件通过 World.registerObject 注册：灯柱、桌子、运货箱、石块、桥与岸栏、牌坊；树、食摊继续沿用原存档耐久。房屋拆成前后/侧墙、木门、窗、梁柱、招牌、灯笼、瓦顶与台基，各自耐久和材质。门 220、砖墙 900–1200、瓦顶 1600、台基 1800；破坏门/墙只移除该段碰撞，可穿过缺口。桥被毁保留可走的低矮残基，避免角色困在水上。
收刀点选目标，靠近后可「拔刀劈砍」「火攻」「泼水灭火」。/ 拔刀 + 左键仍可直接劈砍前方物件；选中对象在攻击范围和朝向内时优先命中。高处屋顶可火攻，地面刀击只覆盖低处物件。物件选中有金色边框、材质和耐久；受损掉碎片，损毁留下瓦砾。地面物品和摊上食物也可被打坏/烧毁，不能再拾取、购买或食用。
材质：木材物理倍率 1、火焰 2.5，可燃；纸布 1.4/4，可燃；砖石 .55/.08，不持续燃烧；金属 .4/.15；食物 2/3。普通劈砍基础伤害 20，火攻 18，燃烧每秒基础伤害 4。泼水立即扑灭，湿润保持 18 秒，期间火焰伤害为 15%、无法点燃。火攻/泼水各消耗体力 6，本轮是直接可用的试玩能力，尚未接入水壶/火具库存、火焰蔓延、建筑承重坍塌或 NPC 救火。自然地形、河水、远景山体和粒子特效不作为物件血条目标。
材质/耐久/燃烧/湿润保存在原存档，旧存档补齐物件，既有耐久不重置。新增 tests/materials.test.js 覆盖材料伤害差异、灯柱、燃烧与灭火、范围校验、存档迁移、房门独立损毁后的真实碰撞、物品销毁。
